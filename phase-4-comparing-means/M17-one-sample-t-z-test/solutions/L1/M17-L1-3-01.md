# حل M17-L1-3-01

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 5/√10 ≈ 1.5811` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 10-1 = 9` است.
۲. اختلاف را بر SE تقسیم کنید. `t = -3.6/1.5811 ≈ -2.2768`. برای پرسش راست مساحت `P(T ≥ -2.2768)` را بخوانید. مقدار P حدود **0.9756** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.2622 است. حاصل ضرب در SE، نیمه‌عرض 3.5768 را می‌دهد. فاصلهٔ **اختلاف** `[-7.177, -0.023]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
