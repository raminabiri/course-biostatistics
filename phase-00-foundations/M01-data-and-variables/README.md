# M01 — پیش از هر آزمون، داده را بشناسیم

یک همکار، سن و دمای سه نفر را به ما می‌دهد. نخست آن‌ها را در یک جدول می‌نویسیم. بعد همان افراد را در روز دیگری می‌بینیم و درمی‌یابیم شش سطر، همیشه شش نفر نیست. یک خانهٔ خالی هم پرسش تازه‌ای می‌سازد: اگر مقدار را نداریم، نرم‌افزار چه چیزی را حساب کرده است؟
