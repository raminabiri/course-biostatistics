# حل M17-L1-3-08

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 8/√17 ≈ 1.9403` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 17-1 = 16` است.
۲. اختلاف را بر SE تقسیم کنید. `t = 2.7/1.9403 ≈ 1.3915`. برای پرسش چپ مساحت `P(T ≤ 1.3915)` را بخوانید. مقدار P حدود **0.9084** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.1199 است. حاصل ضرب در SE، نیمه‌عرض 4.1132 را می‌دهد. فاصلهٔ **اختلاف** `[-1.413, 6.813]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
