# M06 در Python

در پوشهٔ ماژول اجرا کنید `python3 python/M06_module.py`. `quantiles(x,n=4,method="inclusive")` سه نقطهٔ برش چهار بخش را می‌دهد. پیمانهٔ statistics همراه Python است. در عبارت `[v for v in x if ...]` فقط عددهای خارج از یکی از دو حصار به فهرست نتیجه می‌روند. log2 مستقیماً لگاریتم پایهٔ دو می‌گیرد.
