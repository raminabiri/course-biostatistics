# SPSS | گزارش آماری، ثبت پیشاپیش و بازتولیدپذیری

در Syntax داده و محاسبه را کنار هم نگه دارید.
```spss
DATA LIST FREE / arm n improved.
BEGIN DATA
1 6 3
0 6 1
END DATA.
COMPUTE risk=improved/n.
LIST VARIABLES=arm n improved risk.
```
از File → Save As فایل sps ذخیره کنید. ۱ یعنی برنامه. اختلاف را از دو نسبت بگیرید. برای بازتولید، فایل Syntax را در نشست تازه اجرا و خروجی را از Output نسخه‌دار ذخیره کنید.

**خروجی مرجع:** نسبت‌ها ۰٫۵ و ۰٫۱۶۶۷ و اختلاف ۰٫۳۳۳۳.

محاسبهٔ مرجع با R و Python وارسی شده است. اجرای مستقیم این مسیر در نرم‌افزار در دسترس نبود.
