# M32-E17 | تساوی همگانی

همه رتبهٔ ۶٫۵ دارند. در H ضریب تصحیح صفر است و آماره تعریف نمی‌شود. امتیاز J برای هر جفت بین‌دوزی نیم است و هیچ تغییرپذیری برای استنباط نداریم. گزارش کنید همهٔ مقادیر مشاهده‌شده ۷ بودند و داده‌ها برای آزمون رتبه‌ای اطلاعاتی از تفاوت فراهم نکردند.
