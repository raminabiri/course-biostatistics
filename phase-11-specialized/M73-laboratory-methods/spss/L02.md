# SPSS | خلاصهٔ غلظت–زمان با تحلیل غیرمحفظه‌ای

CSV را وارد کنید. اولین ردیف برای AUC مقدار interval ندارد، چون ردیف پیشین وجود ندارد.
```spss
SORT CASES BY hour.
COMPUTE segment=(hour-LAG(hour))*(conc+LAG(conc))/2.
LIST VARIABLES=hour conc segment.
IF (hour>=2 AND conc>0) logconc=LN(conc).
REGRESSION /DEPENDENT logconc /METHOD=ENTER hour.
```
چهار مساحت غیرگمشده را جمع کنید. برای نیمه‌عمر، ۰٫۶۹۳ را از قدر مطلق ضریب خام hour بردارید و لگاریتم ۲ را بر آن تقسیم کنید.

**خروجی مرجع:** AUC تا ساعت ۴ برابر ۱۴٫۵، Cmax برابر ۸، Tmax برابر ساعت ۱ و نیمه‌عمر انتهایی برابر یک ساعت.

محاسبهٔ مرجع با R و Python وارسی شده است. اجرای مستقیم این مسیر در نرم‌افزار در دسترس نبود.
