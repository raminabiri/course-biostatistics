# M01 — نخستین گام با داده‌های پزشکی و زیستی

برای این ماژول، دانستن آمار یا کدنویسی پیش‌نیاز نیست. از یک جدول سه‌نفری شروع می‌کنیم و آرام پیش می‌رویم.

## نخستین بار است که اینجا هستید؟

**[از اینجا شروع کنید ←](START.md)**

در صفحهٔ شروع، داده را می‌شناسید، نرم‌افزار خود را برمی‌گزینید و نخستین جدول را می‌سازید. خواندن هر پنج مسیر لازم نیست.

## مسیر خواندن

هر درس پیوند گام بعد را دارد. برای خواندن دوره نیازی به گشتن میان پوشه‌های GitHub ندارید.

## درس‌ها را چگونه بخوانم؟

- **تازه‌کار:** بار نخست تنها بخش مقدماتی و تمرین‌های ۱ تا ۵ هر درس را انجام دهید. بخش متوسط و پیشرفته برای بازگشت بعدی است.
- **آشنا با پایه‌ها:** بخش متوسط و تمرین‌های ۶ تا ۱۵ را هم دنبال کنید.
- **متخصص و پژوهشگر:** بخش پیشرفته و تمرین‌های ۱۶ تا ۳۰ را برای بررسی تصمیم‌های پژوهشی بخوانید.

برچسب سطح و مخاطب کنار هر تمرین آمده است. روی «پاسخ» بزنید تا تنها پاسخ همان پرسش باز شود؛ پیوند بازگشت شما را به همان پرسش برمی‌گرداند. این ماژول چهار درس و ۱۲۰ تمرین دارد: برای هر درس ۵ ساده، ۱۰ متوسط و ۱۵ پیشرفته.
