# حل M17-L1-3-11

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 7/√20 ≈ 1.5652` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 20-1 = 19` است.
۲. اختلاف را بر SE تقسیم کنید. `t = -2.7/1.5652 ≈ -1.7250`. برای پرسش چپ مساحت `P(T ≤ -1.7250)` را بخوانید. مقدار P حدود **0.0504** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.0930 است. حاصل ضرب در SE، نیمه‌عرض 3.2761 را می‌دهد. فاصلهٔ **اختلاف** `[-5.976, 0.576]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
