# SPSS | درس عملی 2 — طرح آمیخته و کنتراست

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین wide.csv](../data/wide.csv)

[دادهٔ تمرین practice.csv](../data/practice.csv)

time را در Repeated Measures تعریف و group را Between-Subjects Factor بگذارید. در Contrasts یا با محاسبهٔ تغییر، مقایسهٔ ازپیش‌تعیین‌شده را اجرا کنید.

### گام‌های اجرا و کنترل

از Transform → Compute Variable، Target Variable را change و Numeric Expression را `t2c0 - t0c0` بگذارید. در Analyze → Compare Means → Independent-Samples T Test، change را Test Variable و group را Grouping Variable بگذارید. Define Groups را با ۱ و ۰ پر کنید تا تفاضل گروه یک منهای صفر باشد. ردیف Equal variances assumed، t≈۳٫۰۲۸ و df=۱۰ را می‌دهد.

**خروجی مرجع R و Python.** کنتراست تغییر گروه۱−گروه۰، t=3.027500، P=0.012731.

**خودآزمایی.** آیا فرد اول گروه ۰ را با فرد اول گروه ۱ جفت می‌کنید؟
