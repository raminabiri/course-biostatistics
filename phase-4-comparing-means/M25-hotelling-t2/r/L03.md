# R | درس عملی 3 — بردار تغییر زوجی

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

اسکریپت R را اجرا کنید. خط L3 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

[فایل کد](../r/M25_workshop.R) را باز کنید. y-as.matrix(...) پاسخ‌های متناظر قبل را از بعد کم می‌کند.

**خروجی مرجع R و Python.** زوجی T²=37.195995، F=17.998062، P≈0.000007312.

**خودآزمایی.** اگر پاسخ دوم بعد برای یک بیمار مفقود باشد؟
