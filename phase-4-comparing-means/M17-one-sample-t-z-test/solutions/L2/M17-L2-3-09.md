# حل M17-L2-3-09

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 5/√18 ≈ 1.1785` دقیقه. در این سؤال σ معلوم فرض شده است.
۲. اختلاف را بر SE تقسیم کنید. `z = 3.6/1.1785 ≈ 3.0547`. برای پرسش دوطرفه مساحت `2 × P(Z ≥ 3.0547)` را بخوانید. مقدار P حدود **0.0023** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 1.9600 است. حاصل ضرب در SE، نیمه‌عرض 2.3098 را می‌دهد. فاصلهٔ **اختلاف** `[1.290, 5.910]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
