# کدبوک دادهٔ ماژول M07

## فایل `M07_survey.csv`

**مطالعه:** پیمایش سلامت عمومی ۲۰۰ بزرگسال در یک شهرستان (شهری و روستایی). **واحد تحلیل:** فرد. داده‌ها ساختگی‌اند.

| متغیر | شرح | کدها | نوع |
|---|---|---|---|
| `id` | شناسه | 1 تا 200 | — |
| `sex` | جنس | `F` = زن، `M` = مرد | اسمی |
| `age_group` | گروه سنی | 1 = ۱۸–۳۹، 2 = ۴۰–۵۹، 3 = ۶۰ و بیشتر | ترتیبی |
| `region` | محل زندگی | `urban` = شهری، `rural` = روستایی | اسمی |
| `education` | تحصیلات | 1 = ابتدایی یا کمتر، 2 = متوسطه، 3 = دانشگاهی | ترتیبی |
| `smoking` | وضعیت سیگار | `never` = هرگز، `former` = سابق، `current` = فعلی | اسمی/ترتیبی |
| `flu_vacc` | واکسن آنفلوانزا در سال گذشته | `yes` / `no`؛ **خالی = پاسخ نداده** (۸ نفر) | دوحالتی |
| `chronic` | بیماری مزمن (دیابت، قلبی، ریوی، کلیوی) | `yes` / `no` | دوحالتی |
| `self_health` | سلامت خوداظهاری | 1 = عالی، 2 = خیلی خوب، 3 = خوب، 4 = متوسط، 5 = بد؛ **خالی = پاسخ نداده** (۵ نفر) | ترتیبی |
