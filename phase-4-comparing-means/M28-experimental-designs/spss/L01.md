# SPSS | درس عملی 1 — بلوک و مربع لاتین

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

در GLM Univariate برای block، متغیرهای u و w را Fixed Factors بگذارید. در Custom Model فقط اثرهای اصلی را وارد کنید. برای latin، v را هم اضافه کنید.

**خروجی مرجع R و Python.** بلوک: F تیمار=8.977099، P=0.009027. مربع لاتین: F=28.822222، P=0.000583.
