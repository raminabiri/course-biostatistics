## مسیر R

۱. در RStudio، پوشهٔ همین ماژول را به عنوان Working Directory انتخاب کنید. از `Session → Set Working Directory → Choose Directory` کمک بگیرید. در Console، با `getwd()` مطمئن شوید نام آخر پوشه با M12 شروع می‌شود و با `list.files()` وجود پوشهٔ r را ببینید.
۲. از `File → Open File` فایل [تمرین R](r/M12_simulation.R) را باز کنید. فایل را در جای فعلی نگه دارید تا مسیر داده و شکل‌ها برقرار باشد.
۳. در Console فرمان `source("r/M12_simulation.R")` را وارد کنید و Enter بزنید. برای دیدن یک فرمان در لحظه، نشانگر را روی خط مربوطه بگذارید و Run را بزنید. خط خواندن داده یا تعریف متغیر را اول اجرا کنید.
۴. ستون simulated_se به‌ترتیب نزدیک ۱۰، ۴٫۴۷ و ۱٫۸۳ است. شکل در figures ذخیره می‌شود. برای نگهداری متن خروجی، آن را از Console به یک فایل متنی منتقل کنید.

## مسیر Python

۱. در VS Code با `File → Open Folder` پوشهٔ همین ماژول را باز کنید. همان مفسر Python که در M01 انتخاب کردید به کار می‌رود. فایل [تمرین Python](python/M12_practice.py) را باز کنید.
۲. اگر بسته‌ها در محیط M01 نصب نیستند، از Command Palette گزینهٔ `Python: Select Interpreter` را بزنید و مفسرتان را انتخاب کنید. ترمینال قدیمی را ببندید و `Terminal → New Terminal` را بزنید. در ترمینال `python -m pip install numpy` را اجرا کنید. اگر فرمان M01 برای شما python3 بود، همان را به جای python بگذارید. سپس برای نصب‌های بعدی نیز همین محیط را نگه دارید.
۳. دکمهٔ `Run Python File` بالای فایل را بزنید یا در ترمینالِ پوشهٔ ماژول، `python python/M12_practice.py` را اجرا کنید. پاسخ‌ها در Terminal ظاهر می‌شوند و شکل‌های Python، در درس‌های دارای شکل، در پوشهٔ ماژول ذخیره می‌شوند.
۴. اگر `ModuleNotFoundError` دیدید، اول مفسر انتخاب‌شده و مفسر ترمینال را یکی کنید. اگر فایل داده پیدا نشد، مطمئن شوید پوشهٔ data را همراه فایل برنامه دارید. خطوط چاپ‌شده را با خروجی مورد انتظار درس مقایسه کنید.

## پیش از کار در Excel، SPSS یا Prism

- **Excel.** برای CSV، یک کارپوشهٔ خالی باز کنید. از `Data → From Text/CSV` فایل را انتخاب کنید، در پیش‌نمایش Delimiter را Comma بگذارید و Load را بزنید. هر ستون باید جدا دیده شود. اگر فرمول با ویرگول پذیرفته نشد، جداکنندهٔ آرگومان را مطابق تنظیم Excel خود عوض کنید. در پایان با `File → Save As` یک نسخهٔ xlsx ذخیره کنید.
- **SPSS.** از `File → Import Data → CSV Data` فایل را انتخاب کنید. سطر اول نام متغیرهاست و جداکننده ویرگول است. پس از وارد کردن، ستون‌های عددی را در Variable View بررسی کنید. از `File → Save As` برای ذخیرهٔ دادهٔ sav و از پنجرهٔ Output برای ذخیرهٔ نتایج spv کمک بگیرید.
- **Prism.** از `File → New Project` شروع کنید. نوع جدول را طبق تمرین انتخاب کنید. هنگام انتقال جدول از CSV، عنوان ستون‌ها را جدا از خانه‌های عددی بگذارید. نتیجهٔ تحلیل در Results و نمودار در Graphs دیده می‌شود. از `File → Save As` برای ذخیرهٔ پروژه کمک بگیرید.

اگر درس دادهٔ آماده ندارد، جدول جدید بسازید و عددهای خود درس را وارد کنید. در SPSS برای تمرین‌های محاسباتیِ بدون فایل، می‌توانید `File → New → Syntax` را باز کنید، دستورهای داده‌شده را منتقل کنید و `Run → All` را بزنید.

## Excel

۱. **درس ۱۲.۱.** در A2، `=-10*LN(1-RAND())` را وارد کنید. آن را تا E2 کپی کنید تا نمونهٔ پنج‌نفری بسازید. در F2، `=AVERAGE(A2:E2)` را بزنید. A2:F2 را تا سطر ۵۰۱ بکشید. ۲۵۰۰ مقدار فردی و ۵۰۰ میانگین دارید.
۲. **درس ۱۲.۲.** در H2 بنویسید `=10/SQRT(25)`. در H3، `=STDEV.S(F2:F501)` را وارد کنید. H2 دقیقاً ۲ است و H3 برای n=۵ باید نزدیک ۴٫۴۷ باشد. H3 یک برآورد شبیه‌سازی است.
۳. **درس ۱۲.۳.** فایل [میانگین‌های ثابت](data/M12_sample_means.csv) را وارد کنید. در کارپوشه سه ستون n1، n5 و n30 دارید. از Insert، Histogram را جدا برای هر ستون بسازید. در Format Axis پهنای بازه را برای هر سه برابر بگذارید. انحراف معیار هر ستون را با STDEV.S بخوانید. برای ذخیرهٔ شبیه‌سازی تصادفی خودتان، از Copy و Paste Special → Values کمک بگیرید.

## SPSS

۱. **درس ۱۲.۱.** در Syntax تازه قطعهٔ زیر را اجرا کنید. INPUT PROGRAM دادهٔ ساختگی می‌سازد. هر سطر یک نمونهٔ پنج‌نفری است. ستون avg5 میانگین آن سطر است.

```spss
SET SEED=120.
INPUT PROGRAM.
LOOP sample_id=1 TO 500.
  COMPUTE wait1=-10*LN(1-RV.UNIFORM(0,1)).
  COMPUTE wait2=-10*LN(1-RV.UNIFORM(0,1)).
  COMPUTE wait3=-10*LN(1-RV.UNIFORM(0,1)).
  COMPUTE wait4=-10*LN(1-RV.UNIFORM(0,1)).
  COMPUTE wait5=-10*LN(1-RV.UNIFORM(0,1)).
  COMPUTE avg5=MEAN(wait1 TO wait5).
  END CASE.
END LOOP.
END FILE.
END INPUT PROGRAM.
EXECUTE.
```

۲. **درس ۱۲.۲.** در `Analyze → Descriptive Statistics → Descriptives`، avg5 را انتخاب کنید. در Options، Std. deviation را نگه دارید. SD خروجی تقریب تجربی SE میانگین است. مقدار مرجع ۱۰/√۵ است.
۳. **درس ۱۲.۳.** فایل [میانگین‌های ثابت](data/M12_sample_means.csv) را وارد کنید. در `Analyze → Descriptive Statistics → Explore`، n1، n5 و n30 را در Dependent List بگذارید و در Plots هیستوگرام را بخواهید. برای مقایسهٔ دیداری، پهنای بازه و دامنهٔ محورها را در نمودارها همسان کنید.

## Prism

۱. **درس ۱۲.۱.** جدول Column با سه ستون بسازید. فایل [میانگین‌های ثابت](data/M12_sample_means.csv) را باز کنید و بدنهٔ n1، n5 و n30 را به جدول منتقل کنید. هر خانه یک میانگین نمونه است. در Column statistics برای هر ستون N=500 را بررسی کنید.
۲. **درس ۱۲.۲.** SD ستون n5 را در Column statistics بخوانید. SD بین میانگین‌ها همان تقریب تجربی SE است. اگر نرم‌افزار SEM هم چاپ کرد، آن مقدار خطای استانداردِ میانگینِ ۵۰۰ میانگین است. برای پرسش درس SD را بخوانید.
۳. **درس ۱۲.۳.** از Analyze و Frequency distribution برای هر سه ستون کمک بگیرید. بازه‌ها را با پهنای یکسان بگیرید و نمودارها را روی مقیاس قابل مقایسه بگذارید. از n1 به n30، نمودار باید جمع‌وجورتر شود.
