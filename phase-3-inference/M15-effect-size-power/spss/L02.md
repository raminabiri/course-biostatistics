# SPSS | درس عملی 2 — ریسک و شانس

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

در یک ردیف فعال، با Compute Variable سه متغیر rd، rr و oratio را با `.30-.20`، `.30/.20` و `(30/70)/(20/80)` بسازید. مقادیر Data View را بخوانید.

### مقایسه را با رخداد کم تکرار کنید

در A از ۱۰۰۰ نفر ۳۰ رخداد و در B از ۱۰۰۰ نفر ۲۰ رخداد داریم. نسبت خطر همچنان ۱٫۵ است، اما اختلاف مطلق از ۱۰ واحد درصد نمونهٔ اول به ۱ واحد درصد می‌رسد. نسبت شانس (۳۰÷۹۷۰)÷(۲۰÷۹۸۰)≈۱٫۵۱۵ است. بنابراین یک نسبت یکسان می‌تواند تغییر مطلق متفاوتی داشته باشد.

در هر Compute مربوط به خطر، جمع رخداد و بی‌رخداد را جدا برای هر گروه بسازید. در خروجی، ضریب ۱۰۰ را فقط هنگام نمایش اختلاف به واحد درصد به کار ببرید.

**خروجی برای مقایسه.** RD=۰٫۱، RR=۱٫۵، OR≈۱٫۷۱۴.

**خودآزمایی.** چرا نباید نسبت شانس را «۱٫۷۱۴ برابر خطر» گزارش کنیم؟
