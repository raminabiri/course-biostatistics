# کارگاه گام‌به‌گام M23

این کارگاه ادامهٔ [شروع M01](../../phase-0-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio پوشهٔ ماژول را از Session → Set Working Directory → Choose Directory انتخاب کنید، سپس فایل [M23_workshop.R](r/M23_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M23_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M23_workshop.py](python/M23_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M23_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

[دادهٔ بلند](data/practice.csv) · [جدول پهنِ آماده برای Excel، SPSS و Prism](data/wide.csv). در جدول پهن هر سطر یک فرد است. t2c0 یعنی زمان ۲ در شرط صفر. در Excel از Data → From Text/CSV و در SPSS از Import Data → CSV Data کمک بگیرید. سرستون‌ها را از ردیف اول بخوانید و جداکننده را ویرگول بگذارید.

## تمرین 23.1

**خروجی مرجع R و Python.** تعامل زمان×شرط F=4.152956، P=0.029502.

### Excel

عرض زمان×شرایط را در PivotTable بسازید. در سه ستون، تفاضل شرط ۱ و ۰ را برای هر زمان ثبت کنید. ToolPak مدل دو عامل تکراری کامل ندارد. برای آزمون این کنتراست از روش یک‌طرفه M22 کمک بگیرید.

### SPSS

GLM → Repeated Measures. time با سه سطح و condition با دو سطح تعریف کنید. از CSV پهن استفاده کنید و t0c0 تا t2c1 را بر اساس شمارهٔ time و condition هریک به خانهٔ متناظر در Define منتقل کنید. تعامل time*condition را بخوانید.

### Prism

در Grouped، زمان و شرایط را مطابق صفحهٔ طراحی وارد کنید و در Two-way ANOVA هر دو عامل را matched تعریف کنید. هر زیرستون شناسهٔ یکسان دارد.

### R

اسکریپت R را اجرا کنید. خط L1 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

### Python

اسکریپت Python را اجرا کنید. خط L1 را با عدد کنترل مقایسه کنید. این فایل به SciPy و NumPy متکی است.
