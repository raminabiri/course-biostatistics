# SPSS | درس عملی 2 — شیب و تعامل تعدیل‌شده

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

[دادهٔ تمرین change.csv](../data/change.csv)

در Univariate، a و b را Fixed و baseline را Covariate بگذارید. Custom model شامل a، b، a*b و baseline، سپس در تحلیل جدا a*baseline را برای بررسی شیب اضافه کنید.

### گام‌های اجرا و کنترل

هر ۲۴ ردیف را فعال کنید. در Analyze → General Linear Model → Univariate، مدل a، b، baseline و a*b را بسازید. در Tests of Between-Subjects Effects سطر `a * b` و ستون F را بخوانید. ردیف Error باید df=19 داشته باشد. برای سنجش شیب گروه‌ها یک تحلیل جدا با جملهٔ `a*baseline` اجرا کنید؛ نام سطر شیب در گزارش باید مشخص بماند.

**خروجی مرجع R و Python.** تعامل A×B پس از تعدیل F=1.052051، P=0.317917.

**خودآزمایی.** برای آزمون A×B چه چیزی باید بین مدل کامل و کاهش‌یافته فرق کند؟
