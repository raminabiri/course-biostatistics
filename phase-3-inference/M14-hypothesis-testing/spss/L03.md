# SPSS | درس عملی 3 — فاصله و آزمون

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

با Compute Variable ابتدا h را با `IDF.T(.975,n-1)*sd_value/SQRT(n)` حساب کنید. سپس lo برابر mean_value−target−h و hi برابر mean_value−target+h است.

**خروجی برای مقایسه.** فاصلهٔ اختلاف [−۰٫۱۳، ۸٫۱۳].

**خودآزمایی.** می‌توان از این نتیجه نتیجه گرفت که دو وضعیت هم‌ارزند؟
