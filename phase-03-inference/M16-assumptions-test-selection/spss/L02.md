# SPSS | درس عملی 2 — واریانس و مرکز گروه

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

برای جدول بلند، یک فایل تازه با دو ستون group و value بسازید. نسخهٔ طولی آماده در `data/M16_long.csv` است. در Analyze → Compare Means → One-Way ANOVA، value را Dependent و group را Factor بگذارید. در Options، Homogeneity of variance test را فعال کنید. اگر جدول نسخهٔ شما Based on Median را نشان می‌دهد، همان ردیف را بخوانید. برای بازتولید دقیق، Compute Variable فاصلهٔ مطلق را با میانهٔ ۵۳ برای A و ۵۰ برای B بسازید و ANOVA را روی فاصله‌ها اجرا کنید.

### آزمون را از فاصلهٔ هر فرد تا میانه بازسازی کنید

[دادهٔ پهن](../data/M16_groups.csv) برای هر گروه ۱۲ مقدار دارد. میانه‌ها در A و B برابر ۵۳ و ۵۰ هستند. نخستین انحراف مطلق A برابر |۴۸−۵۳|=۵ و نخستین انحراف B برابر |۴۳−۵۰|=۷ است. میانگین انحراف‌ها به‌ترتیب ۳٫۱۶۷ و ۴٫۹۱۷ است. ANOVA تک‌عاملی روی همین انحراف‌ها F≈۱٫۲۸۵ و P≈۰٫۲۶۹ می‌دهد.

در [فایل بلند](../data/M16_long.csv)، Transform → Compute Variable را باز کنید. برای group=A فاصله از ۵۳ و برای group=B فاصله از ۵۰ را بگیرید. می‌توانید از Syntax با `IF (group = "A") dev = ABS(value-53).` و متناظر آن برای B کمک بگیرید. پس از EXECUTE، dev را در One-Way ANOVA به‌عنوان پیامد و group را عامل بگذارید.

**خروجی برای مقایسه.** Brown–Forsythe حدود F=۱٫۲۸۵ و P=۰٫۲۶۹.

**خودآزمایی.** اگر P بزرگ شد، آیا می‌توان برابری واریانس را قطعی دانست؟
