## آماده‌سازی

برای شروع از File → New Project استفاده کنید. نوع جدول را مطابق دستور همین تمرین انتخاب کنید. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

[دادهٔ تمرین values.csv](../data/values.csv)

جدول Column با before و after بسازید. ردیف‌های یک فرد را روبه‌روی هم نگه دارید. Analyze → t tests و Paired را انتخاب کنید.

**خروجی مرجع R و Python.** اختلاف −3.875 و t=−11.059344.
