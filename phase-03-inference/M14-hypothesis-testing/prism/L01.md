# Prism | درس عملی 1 — فرضیه، جهت و آماره

## آماده‌سازی

برای شروع از File → New Project استفاده کنید. در جدول XY، X محل نقطه و Y ورودی تبدیل است. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

در XY، Y=54 بگذارید. در User-defined Y transform فرمول `Y=(Y-50)/(10/sqrt(25))` را وارد کنید و Results را بخوانید.

**خروجی برای مقایسه.** t=۲، df=۲۴.

**خودآزمایی.** اگر فقط سؤال «فرق دارد؟» بود، چه چیزی عوض می‌شد؟
