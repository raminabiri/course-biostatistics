# پاسخ M01-L4-E01

## پرسش

**سطح:** ساده | **مخاطب:** دانشجوی پزشکی، پیراپزشکی و علوم زیستی

کدام روش ثبت مقدار گمشده قابل‌قبول است و کدام نه؟ (الف) خانهٔ خالی (ب) 0 (ج) -99 که در کدبوک تعریف شده (د) «نامعلوم» در یک ستون عددی (هـ) `NA` (و) 999 برای سن، بدون توضیح

## پاسخ گام‌به‌گام

| | روش | قابل‌قبول؟ | دلیل |
|---|---|---|---|
| الف | خانهٔ خالی | ✔ | همهٔ نرم‌افزارها آن را گمشده می‌خوانند |
| ب | 0 | ✘ | با مقدار واقعی صفر اشتباه می‌شود |
| ج | -99 مستند | ✔ | به شرط تعریف در نرم‌افزار |
| د | «نامعلوم» | ✘ | ستون عددی را متنی می‌کند |
| هـ | `NA` | ✔ | استاندارد R و pandas؛ در SPSS و Excel باید تبدیل شود |
| و | 999 بدون توضیح | ✘ | خواننده بدون فرهنگ داده، میان کد گمشده و خطای ورود تمایز روشنی ندارد؛ هر کد باید در کدبوک باشد |
