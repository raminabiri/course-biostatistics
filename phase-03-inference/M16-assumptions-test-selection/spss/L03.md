# SPSS | درس عملی 3 — غربال و بررسی نقطهٔ دور

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

در فایل یک‌ردیفی نمونهٔ M14، ستون تازه q را با `IDF.T(1-.05/(2*12),10)` بسازید. از Explore میانگین و SD A را بردارید و در `ABS(68-m)/s` جای‌گذاری کنید. آستانه را با عبارت `11/SQRT(12)*SQRT(q**2/(10+q**2))` حساب کنید.

**خروجی برای مقایسه.** G≈۲٫۷۴۶، آستانه≈۲٫۴۱۲.

**خودآزمایی.** اگر فایلی سه مقدار دور داشته باشد، می‌توان Grubbs را پی‌درپی اجرا و هر بار حذف کرد؟
