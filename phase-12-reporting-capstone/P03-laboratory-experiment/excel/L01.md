# Excel — دوز–پاسخ و مقایسهٔ گروه‌های آزمایشگاهی

CSV را وارد کنید. برای ToolPak، سه ستون از سیگنال در دوزهای صفر، یک و دو بسازید و Data → Data Analysis → ANOVA: Single Factor را روی آن‌ها اجرا کنید. گروه‌بندی Columns باشد. با SLOPE روی CSV اصلی، شیب ۴ را به دست آورید.

خروجی مرجع با R و Python وارسی شده است. اجرای مستقیم در این نرم‌افزار در دسترس نبود.
