# SPSS — کوهورت و نرخ بیماری قلبی–عروقی

CSV را وارد کنید. از Data → Aggregate متغیر exposure را به‌عنوان Break و Sum برای event و time تعریف کنید. از Transform → Compute Variable نرخ هر سطر را از `100*events/person_years` بسازید. خروجی را با ۷٫۵ و ۱۶٫۶۷ وارسی کنید.

خروجی مرجع با R و Python وارسی شده است. اجرای مستقیم در این نرم‌افزار در دسترس نبود.
