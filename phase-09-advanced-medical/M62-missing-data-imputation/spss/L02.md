# SPSS | ترکیب برآوردها

یک مجموعهٔ دادهٔ تازه باز کنید. از File, New, Syntax پنجرهٔ فرمان را باز کنید و متن زیر را کامل اجرا کنید. سه ردیف به ترتیب شمارهٔ نسخه، برآورد و واریانس درون نسخه هستند. دستور AGGREGATE خلاصهٔ سه ردیف را به یک ردیف تبدیل می‌کند. مربع انحراف معیار همان واریانس میان نسخه‌هاست.

```spss
DATA LIST FREE / i estimate within.
BEGIN DATA
1 16 4
2 17 4
3 18 4
END DATA.
AGGREGATE OUTFILE=* /BREAK=
 /q=MEAN(estimate) /w=MEAN(within) /s=SD(estimate) /m=N(estimate).
COMPUTE total=w+(1+1/m)*s**2.
COMPUTE se=SQRT(total).
LIST VARIABLES=q w s m total se.
```

در Output، ستون q باید ۱۷ و se حدود ۲٫۳۱ باشد. اگر به ابزار Multiple Imputation دسترسی دارید، برای دادهٔ اصلی مسیر Analyze, Multiple Imputation را بررسی کنید. متغیر گروه باید طبقه‌ای، نمره باید Scale و شناسه باید از پیش‌بین‌ها خارج باشد. گزینهٔ Impute Missing Data Values نسخه‌ها را تولید می‌کند. امکان دریافت نتیجهٔ ترکیبی به نوع تحلیل و امکانات نصب‌شده وابسته است.
