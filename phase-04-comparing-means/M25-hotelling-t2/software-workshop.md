# کارگاه گام‌به‌گام M25

این کارگاه ادامهٔ [شروع M01](../../phase-00-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio پوشهٔ ماژول را از Session → Set Working Directory → Choose Directory انتخاب کنید، سپس فایل [M25_workshop.R](r/M25_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M25_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M25_workshop.py](python/M25_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M25_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

[دادهٔ ساختگی](data/practice.csv). در Excel از Data → From Text/CSV و در SPSS از Import Data → CSV Data کمک بگیرید. سرستون‌ها را از ردیف اول بخوانید و جداکننده را ویرگول بگذارید.

## تمرین 25.1

**خروجی مرجع R و Python.** تک‌نمونه‌ای T²=4.846807، F=2.261843، P=0.140865.

### Excel

A=0 را فیلتر و y,z را به ستون‌های A و B یک برگهٔ تازه منتقل کنید. میانگین‌های منهای ۴۷ و ۲۷ را در D2:D3 بگذارید. ماتریس کوواریانس ۲×۲ را در F2:G3 با VAR.S در قطر و COVARIANCE.S در دو خانهٔ خارج قطر بسازید. `=16*MMULT(TRANSPOSE(D2:D3),MMULT(MINVERSE(F2:G3),D2:D3))` مقدار T² است.

### SPSS

Data → Select Cases با a=0، سپس Descriptives برای میانگین‌ها و Correlate → Bivariate با Options برای کوواریانس را درخواست کنید. S را وارد فرمول درس یا اسکریپت R کنید. این P در خروجی Descriptives ارائه نمی‌شود.

### Prism

دو پیامد را روی XY رسم کنید تا همبستگی را ببینید. آزمون هتلینگ در Prism مسیر آماده ندارد. CSV همین کارگاه را با اسکریپت R یا Python تحلیل کنید.

### R

اسکریپت R را اجرا کنید. خط L1 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

### Python

اسکریپت Python را اجرا کنید. خط L1 را با عدد کنترل مقایسه کنید. این فایل به SciPy و NumPy متکی است.
