# SPSS | درس عملی 1 — تعامل دو عامل

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

در GLM → Univariate، value را Dependent و a و b را Fixed Factors بگذارید. با Select Cases، c=0 و Model=Full factorial را اجرا کنید.

### ورود داده و انتخاب نوبت

CSV را با File → Import Data → CSV Data باز کنید. سرستون‌ها را نام متغیر بگیرید و در Variable View ببینید که a، b، c و value عددی‌اند. داده را در یک جلسهٔ تازه باز کنید. از Data → Select Cases، گزینهٔ If condition is satisfied را بزنید و شرط `c = 0` را وارد کنید. Filter out unselected cases سطرهای دیگر را برای این تحلیل کنار می‌گذارد. در Data View، کنار سطرهای فیلترشده خط دیده می‌شود.

### تنظیم مدل و خروجی

از Analyze → General Linear Model → Univariate، ستون value را در Dependent Variable و a و b را در Fixed Factor(s) قرار دهید. a و b کد سطح‌اند، پس آن‌ها را در Covariate نگذارید. در Model، Full factorial را بزنید تا مدل هر دو اثر اصلی و تعامل را داشته باشد. در Options، Descriptive statistics را علامت بزنید تا تعداد و میانگین هر خانه قابل کنترل باشد.

در Tests of Between-Subjects Effects سطر `a * b` را بخوانید. اگر df سطر Error برابر ۱۶ و F تعامل برابر ۸ باشد، ساختار داده و مدل با کارگاه همخوان است. در پایان برای بازگرداندن همهٔ سطرها، Data → Select Cases → All cases را بزنید.
