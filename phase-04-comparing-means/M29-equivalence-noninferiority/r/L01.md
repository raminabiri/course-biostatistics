# R | درس عملی 1 — حاشیهٔ هم‌ارزی

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

اسکریپت R را اجرا کنید. خط L1 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

[فایل کد](../r/M29_workshop.R) را باز کنید. all تنها وقتی TRUE می‌دهد که هر دو کران از هر دو حد عبور نکنند و داخل باشند.

**خروجی مرجع R و Python.** دو کران نمونه درون حدود ±۲ هستند.

**خودآزمایی.** بازهٔ [−۱،۲٫۴] برای هم‌ارزی و عدم‌کم‌اثری چه می‌گوید؟
