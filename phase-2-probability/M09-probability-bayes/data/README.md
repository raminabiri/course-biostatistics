# داده‌های تمرین M09

[فایل ۱۱٬۰۰۰ رکورد فردی](M09_individuals.csv) دو جمعیت ساختگی دارد. هر سطر یک نفر است و شمار نفرات از تعداد سطرها به دست می‌آید. ترتیب سطرها در هر جمعیت به‌هم زده شده تا جواب از کنار هم بودن ردیف‌های مشابه پیدا نشود. هیچ دادهٔ گمشده‌ای در این فایل وجود ندارد.

| ستون | معنی |
|---|---|
| `id` | شناسهٔ یکتای فرد |
| `population` | `baseline`: هزار نفر برای درس‌های ۱ و ۲. `low`: ده‌هزار نفر برای مقایسهٔ درس ۳. |
| `reference` | وضعیت بر اساس معیار مرجع، positive یعنی بیمار و negative یعنی بدون بیماری |
| `test` | نتیجهٔ آزمون مورد بررسی، positive یا negative |
| `joint_code` | کد دو نتیجه کنار هم. ۱: مثبت واقعی، ۲: منفی کاذب، ۳: مثبت کاذب، ۴: منفی واقعی. |

[جدول چهارخانهٔ درس](M09_screening.csv) خلاصهٔ جمعیت baseline است. ستون count در آن شمار نفرات هر خانه است. برای تمرین ساخت جدول از فایل فردی آغاز کنید و در پایان از این جدول برای کنترل کمک بگیرید.

برای Prism، همان کدهای فردی در دو فایل تک‌ستونی آماده‌اند: [baseline](M09_prism_baseline.csv) و [low](M09_prism_low.csv). هر کد هنوز یک فرد است. این دو فایل به Prism اجازه می‌دهند بدون ورود ستون متنی، فراوانی چهار حالت را بسازد.

این بانک برای یادگیری **با شمارهای از پیش تعیین‌شده** ساخته شده است. تفاوت شیوع و ثابت‌بودن حساسیت و ویژگی، بخشی از طراحی تمرین است. می‌توانید فایل‌ها را با [اسکریپت سازنده](../tools/build_practice_data.py) بازسازی کنید. از پوشهٔ M09 فرمان `python tools/build_practice_data.py` را بزنید.
