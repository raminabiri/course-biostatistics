# Prism | درس عملی 3 — مقایسهٔ زمان‌ها

## آماده‌سازی

برای شروع از File → New Project استفاده کنید. نوع جدول را مطابق دستور همین تمرین انتخاب کنید. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

[دادهٔ تمرین wide.csv](../data/wide.csv)

[دادهٔ تمرین practice.csv](../data/practice.csv)

در Multiple Comparisons زمان‌ها را جفتی مقایسه کنید. تنظیم matched را نگه دارید و روش تعدیل را بنویسید.

### گام‌های اجرا و کنترل

برای آزمون تکی جدول Column تازه با t2c0 و t0c0 و ترتیب یکسان افراد بسازید. Analyze → t tests → Paired t test و گزینهٔ دوطرفه را بزنید. ترتیب دو ستون جهت تفاوت را مشخص می‌کند؛ در صورت نمایش معکوس، جهت را در گزارش روشن کنید. برای سه جفت، از Multiple Comparisons همان تحلیل تکراری استفاده کنید. Pهای آن جدول می‌توانند با مقدار خام آزمون زوجی فرق داشته باشند، چون برآورد خطا و تعدیل تابع تنظیم تحلیل است.

**خروجی مرجع R و Python.** تغییر میانگین 5.208333 و P خام زوجی=0.000022914.

**خودآزمایی.** چرا برای مقایسهٔ T2 و T0 از آزمون مستقل استفاده نمی‌کنیم؟
