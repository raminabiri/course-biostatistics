# کدبوک M35

[مجموعه‌دادهٔ ساختگی](M35_practice.csv) ۱۵۰ ردیف دارد. هر ردیف یک فرد با شناسهٔ یکتای id است. group گروه A، B یا C و response نتیجهٔ yes، partial یا no است. سه گروه هر کدام ۵۰ فرد جدا دارند. برای جدول ۲×۲ فقط A و B را نگه دارید و partial و no را برای پرسش از پیش تعریف‌شدهٔ «پاسخ کامل» با هم جمع کنید. برای تمرین ۳×۳، هر سه رده را جدا نگه دارید. ترتیب سطرها در فایل برای آسانی کنترل شمار است.
