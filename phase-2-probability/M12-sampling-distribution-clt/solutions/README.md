# پاسخ‌های M12

۱. **M12-1.** یک میانگین از ۳۰ زمان انتظار مستقل.  
۲. **M12-2.** ۱۵۰٬۰۰۰ مقدار.  
۳. **M12-3.** وابستگی سه اندازه‌گیری هر فرد را نگه دارید. برای طرحی که افراد را مستقل برمی‌گزیند، فرد را همراه سه اندازه‌گیری‌اش شبیه‌سازی یا بازنمونه‌گیری کنید.  
۴. **M12-4.** ۲ دقیقه.  
۵. **M12-5.** ۱۰۰ نفر.  
۶. **M12-6.** ۱۲ تقسیم بر جذر ۳۶، برابر ۲ دقیقه.  
۷. **M12-7.** قانون اعداد بزرگ.  
۸. **M12-8.** هیستوگرام شبیه‌سازی معمولاً پایدارتر می‌شود. توزیع نمونه‌گیری نظری با همان n ثابت می‌ماند.  
۹. **M12-9.** قضیه دربارهٔ میانگین استانداردشده است. مدل اندازه‌گیری فردی همان نمایی می‌ماند.
