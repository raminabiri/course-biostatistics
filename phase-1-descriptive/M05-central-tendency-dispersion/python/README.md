## بخش آموزشی

| شاخص | pandas | نکته |
|---|---|---|
| میانگین / میانه | `x.mean()` / `x.median()` | گمشده‌ها خودکار کنار گذاشته می‌شوند |
| نما | `x.mode()` | ممکن است چند مقدار برگرداند |
| SD / واریانس | `x.std()` / `x.var()` | پیش‌فرض **ddof=1** (n − 1) ✔ |
| SEM | `x.sem()` | |
| چارک‌ها | `x.quantile([.25,.75])` یا `np.percentile(x, [25,75])` | پیش‌فرض «linear» = R type 7؛ برای روش SPSS/Prism: `np.percentile(..., method="weibull")` |
| همه با هم | `x.describe()` | چارک‌ها با روش linear |
| به تفکیک گروه | `d.groupby("sex")[cols].agg(["count","mean","std"])` | |

> **دام numpy:** `np.std(x)` و `np.var(x)` به‌طور پیش‌فرض بر **n** تقسیم می‌کنند (ddof=0)، برخلاف pandas و همهٔ نرم‌افزارهای آماری. با دادهٔ این ماژول: `np.std(ldl)` = 31.52 ولی SD درست 31.85 است. همیشه `ddof=1` بنویسید یا از pandas استفاده کنید.

## خطاهای رایج

| مشکل | علت | راه‌حل |
|---|---|---|
| SD با بقیه نمی‌خواند | `np.std` با ddof=0 | `ddof=1` یا `.std()` pandas |
| `mode()` یک Series داد | ممکن است چند نما باشد | `.mode()[0]` یا `.tolist()` |
| چارک‌ها با SPSS فرق دارد | روش متفاوت | `method="weibull"` (M06) |
