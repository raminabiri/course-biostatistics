# کارگاه گام‌به‌گام M31

این کارگاه ادامهٔ [شروع M01](../../phase-0-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio پوشهٔ ماژول را از Session → Set Working Directory → Choose Directory انتخاب کنید، سپس فایل [M31_workshop.R](r/M31_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M31_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M31_workshop.py](python/M31_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M31_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

[دادهٔ ساختگی](data/practice.csv). در Excel از Data → From Text/CSV و در SPSS از Import Data → CSV Data کمک بگیرید. سرستون‌ها را از ردیف اول بخوانید و جداکننده را ویرگول بگذارید.

## تمرین 31.1

**خروجی مرجع R و Python.** U_A=۳۲ و P≈۰٫۳۸۲۸۶۷.

### Excel

اعداد A و B را در یک ستون value و گروه را در ستون دیگر نگه دارید. رتبه را با RANK.AVG روی همهٔ داده‌ها بسازید. با SUMIF رتبه‌های A را جمع و ۷×۸/۲ را کم کنید.

### SPSS

در Nonparametric Tests → Legacy Dialogs → 2 Independent Samples، value را متغیر و group را عامل بگذارید. دو گروه را تعریف و Mann–Whitney U را تیک بزنید. SPSS ممکن است U کوچک‌تر را نشان دهد.

### Prism

در Column دو ستون A و B بسازید. Analyze → t tests، Unpaired و Mann–Whitney را انتخاب کنید. گزارش جهت را از دادهٔ اصلی و ترتیب ستون‌ها بسازید.
