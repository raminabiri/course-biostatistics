## فایل را از پوشهٔ ماژول بخوانید

در VS Code از **File → Open Folder** پوشهٔ M09 را باز کنید. در ترمینال `python --version` را بزنید. اگر در M01 با python3 کار کردید همان را بنویسید. برای این ماژول نصب بستهٔ اضافی لازم نیست.

فایلی با نام `m09_steps.py` در ریشهٔ M09 بسازید و این خطوط را وارد کنید:

```python
import csv
from collections import Counter

with open("data/M09_individuals.csv", encoding="utf-8", newline="") as source:
    rows = list(csv.DictReader(source))
base = [row for row in rows if row["population"] == "baseline"]
counts = Counter((row["reference"], row["test"]) for row in base)
print(len(rows), len(base))
print(counts)
```

`with` پس از خواندن فایل آن را می‌بندد. DictReader نام ستون‌ها را از سرستون می‌گیرد. هر `row` یک فرد است. در خط base، شرط if فقط جمعیت baseline را نگه می‌دارد. Counter می‌شمارد هر جفت چند بار آمده است. با `python m09_steps.py` از ترمینالِ پوشهٔ M09 اجرا کنید. ۱۱٬۰۰۰ و ۱۰۰۰ و چهار شمار اصلی را باید ببینید.

`print(1-counts["negative","negative"]/sum(counts.values()))` را اضافه کنید. values شمار خانه‌هاست و sum مجموع آن‌هاست. جواب ۰٫۱۹ است.
