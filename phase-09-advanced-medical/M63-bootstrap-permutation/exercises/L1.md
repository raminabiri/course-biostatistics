# تمرین ۶۳٫۱

۱. برای شناسه‌های ۲، ۲، ۳، زمان‌ها و میانگین بازنمونه را بنویسید. کدام شناسه حذف شده است؟

۲. از ۲۷ بازنمونه چند مورد میانگین دقیقاً ۲ دارند؟ احتمال این حالت چقدر است؟

۳. فشار خون پیش و پس درمان برای هر فرد در یک ردیف قرار دارد. برای بازهٔ اطمینان میانگین تغییر، واحد بازنمونه‌گیری را مشخص کنید و دلیلش را بنویسید.
