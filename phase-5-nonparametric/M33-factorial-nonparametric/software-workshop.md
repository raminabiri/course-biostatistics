# کارگاه گام‌به‌گام M33

این کارگاه ادامهٔ [شروع M01](../../phase-0-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio پوشهٔ ماژول را از Session → Set Working Directory → Choose Directory انتخاب کنید، سپس فایل [M33_workshop.R](r/M33_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M33_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M33_workshop.py](python/M33_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M33_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

[دادهٔ ساختگی](data/practice.csv). در Excel از Data → From Text/CSV و در SPSS از Import Data → CSV Data کمک بگیرید. سرستون‌ها را از ردیف اول بخوانید و جداکننده را ویرگول بگذارید.

## تمرین 33.1

**خروجی مرجع R و Python.** برای تعامل ART، F≈۱۰٫۸۶۷۰۵۸ و P≈۰٫۰۰۲۶۶۴.

### Excel

Excel پایه ART آماده ندارد. با AVERAGEIFS میانگین خانه و با AVERAGEIF حاشیه‌ها را بسازید. برای تعامل value−mean(A)−mean(B)+mean(کل) و سپس RANK.AVG را به کار ببرید. آزمون نمونه در اسکریپت است.

### SPSS

با Aggregate میانگین خانه و حاشیه‌ها را به ردیف‌ها اضافه کنید. در Compute Variable هم‌ترازی تعامل را بسازید. Transform → Rank Cases روی این ستون و GLM Univariate با دو عامل. فقط سطر تعامل این مدل را بخوانید.

### Prism

Prism برای رسم چهار خانه به کار می‌رود. برای آزمون ART، فایل CSV را با کارگاه R باز کنید.

### R

اسکریپت R را اجرا کنید. خط L1 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

### Python

اسکریپت Python را اجرا کنید. خط L1 را با عدد کنترل مقایسه کنید. این فایل به SciPy و NumPy متکی است.

## تمرین 33.2

**خروجی مرجع R و Python.** برای تعامل SRH، H≈۰٫۶۲۶۴۲۰ و P≈۰٫۴۲۸۶۷۱.

### Excel

رتبهٔ کلی value را بسازید. در چیدمان ۲×۲ متوازن از ToolPak و ANOVA Two-Factor With Replication، SS هر اثر را بردارید. به جای MS خطا، SS کل رتبه/(N−1) را در مخرج H بگذارید.

در Rank Cases رتبهٔ value را بسازید. در GLM Univariate مدل عاملی کامل با رتبه به عنوان پیامد بزنید. SS هر اثر را جدا کنید و H را با SS کل تصحیح‌شده /(N−1) بسازید.

### Prism

برای نمایش از نمودار گروهی استفاده کنید. اگر جدول تحلیل SRH وجود ندارد، هر سه H را در اسکریپت کارگاه حساب کنید.
