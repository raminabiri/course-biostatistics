# M01 در SPSS

۱. [فایل فرمان](M01_module.sps) را با File → Open → Syntax باز کنید. در بلوک DATA، هر ردیف یک نوبت است. نقطهٔ مستقل در ستون temperature در سطر شناسهٔ ۲ و روز ۳ نشانهٔ گمشدگی عددی است.

۲. Run → All را بزنید. COMPUTE برای دمای ثبت‌شده مقدار ۱ و برای دمای گمشده صفر می‌سازد. AGGREGATE بر اساس روز یک ردیف خلاصه می‌سازد. rows شمار تمام ردیف‌ها، valid_n جمع پرچم ۱ و average میانگین دماهای موجود است.

۳. در جدول LIST برای روز صفر ۳ ردیف، ۳ مقدار معتبر و ۳۷٫۳۶۶۷ دارید. برای روز سه ۳ ردیف، ۲ مقدار معتبر و ۳۷٫۲۰۰۰ دارید. برای دیدن دادهٔ ردیفی، دستورهای پیش از AGGREGATE را در نشست تازه جدا اجرا کنید. وقتی خروجی را ذخیره می‌کنید نام و نسخهٔ فایل فرمان را ثبت کنید.
