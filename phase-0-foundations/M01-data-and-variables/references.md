# روش خواندن منابع

نام خواندنی‌ها، بخش پیشنهادی و سطح آن‌ها در پایان هر درس آمده است. خواندن منبع اختیاری است؛ متن درس باید برای دنبال‌کردن آموزش کافی باشد. منابع پیشرفته تنها کنار بخش پیشرفته معرفی می‌شوند.

فیلم‌ها نیز در پایان همان درس‌اند. برای کم‌شدن پیوندها، نام فیلم‌های بیرون یوتیوب به صورت متن نوشته شده؛ فیلم یوتیوب پیوند مستقیم دارد. پیش‌نیاز و بخش پیشنهادی فیلم کنار آن نوشته شده است.
