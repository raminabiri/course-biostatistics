# SPSS | درس عملی 1 — فرد و زمان

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین wide.csv](../data/wide.csv)

[دادهٔ تمرین practice.csv](../data/practice.csv)

در GLM → Repeated Measures، عامل time با سه سطح بسازید. در فایل پهن ستون‌های t0c0، t1c0 و t2c0 را به ترتیب بچینید. جدول Within-Subjects Effects را بخوانید.

### گام‌های اجرا و کنترل

فایل wide.csv را وارد کنید و مطمئن شوید هر id فقط یک سطر دارد. از Analyze → General Linear Model → Repeated Measures، نام عامل درون‌فردی را time و شمار سطح‌ها را ۳ بگذارید. Add و سپس Define را بزنید. t0c0، t1c0 و t2c0 را به‌ترتیب در سه خانهٔ Within-Subjects Variables قرار دهید. در Tests of Within-Subjects Effects، سطر time و ردیف Sphericity Assumed را بخوانید. df خطا را از Error(time) در همان زیرردیف بردارید. مسیر شرط صفر فقط همین سه ستون را لازم دارد.

**خروجی مرجع R و Python.** F=25.109578 با dfهای ۲ و ۲۲، P=0.000002096.
