# پاسخ M01-L2-E04

## پرسش

«تعداد بستری در یک سال» و «وزن به کیلوگرم» هر دو عددی‌اند. کدام از شمارش می‌آید و کدام از سنجش؟ یک مقدار پذیرفتنی برای هر کدام بنویسید.

## پاسخ گام‌به‌گام

تعداد بستری از شمارش می‌آید؛ برای نمونه ۲ بار. وزن از سنجش می‌آید؛ برای نمونه ۶۵٫۴ کیلوگرم. در شمار بستری، یک‌ونیم بار معنای شمارش رویداد ندارد، ولی وزن اعشاری پذیرفتنی است.
