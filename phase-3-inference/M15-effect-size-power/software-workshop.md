# کارگاه گام‌به‌گام M15

این کارگاه ادامهٔ [شروع M01](../../phase-0-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio فایل [M15_workshop.R](r/M15_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M15_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M15_workshop.py](python/M15_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M15_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

## تمرین 15.3

**خروجی برای مقایسه.** ۶۴ نفر در هر گروه برای توان دست‌کم ۰٫۸.

### Excel

A1=0.5، A2=0.05 و A3=0.8 را وارد کنید. در A4 تقریب نرمال `=ROUNDUP(2*((NORM.S.INV(1-A2/2)+NORM.S.INV(A3))/A1)^2,0)` را بزنید. تقریب حدود ۶۳ است. عدد ۶۴ از مدل دقیق t کارگاه است.

### SPSS

در نسخه‌هایی که Power Analysis دارند از Analyze → Power Analysis → Means → Independent-Samples T Test کمک بگیرید. آزمون دوطرفه، نسبت حجم‌ها ۱، α=0.05، توان ۰٫۸ و تفاوت استاندارد ۰٫۵ را وارد کنید. اگر پنجره میانگین و SD می‌خواهد، میانگین ۵۴ و ۵۰ و SD=8 را وارد کنید.

### Prism

در Prism دارای Power Analysis، گزینهٔ دو میانگین مستقل و تعیین sample size را بزنید. α=0.05، توان ۰٫۸، جهت دوطرفه و گروه هم‌اندازه بگذارید. اختلاف ۴ و SD=8 است. در نسخه‌های بدون این تحلیل، ۶۴ عدد کنترل مدل t است و می‌توانید تقریب نرمال را نیز در Transform با `Y=2*((ZINV(.975,"left")+ZINV(.8,"left"))/Y)^2` روی Y=0.5 اجرا کنید؛ برای تعداد نفرات آن را رو به بالا گرد کنید.

### R

در L3، power.t.test افراز دوطرفه و strict=TRUE را به کار می‌برد. نتیجه را رو به بالا گرد کنید.

### Python

اسکریپت اندازه‌ها را افزایش می‌دهد تا توان دنباله‌های توزیع t نامرکزی به ۰٫۸ برسد.
