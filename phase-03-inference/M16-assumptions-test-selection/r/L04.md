# R | درس عملی 4 — نقشهٔ انتخاب آزمون

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

سطر L4، t.test را با var.equal=FALSE اجرا می‌کند. ترتیب داده‌ها جهت اختلاف را تعیین می‌کند.

[فایل کد](../r/M16_workshop.R) را باز کنید. var.equal=FALSE در t.test یعنی Welch.

**خروجی برای مقایسه.** Welch دوطرفه برای دو گروه مستقل دادهٔ تمرین، P≈۰٫۲۱۹.

**خودآزمایی.** اگر به جای عدد، پاسخ هر فرد بله یا خیر بود، آیا Welch همان انتخاب می‌ماند؟
