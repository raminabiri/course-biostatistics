# R | درس عملی 3 — تعدیل تغییر فردی

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

اسکریپت R را اجرا کنید. خط L3 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

[فایل کد](../r/M24_workshop.R) را باز کنید. سطر L3 دو مدل برای change دارد. افزودن a پس از baseline سهم اضافی گروه را برای همین کنتراست می‌سنجد.

### گام‌های اجرا و کنترل

فایل درس را مستقیم با `z <- read.csv("data/change.csv")` بخوانید. `m1 <- lm(change ~ a + baseline, z)` مدل کامل است. `coef(m1)["a"]` ضریب گروه را جدا می‌کند. با `anova(lm(change~baseline,z),m1)` مدل با و بدون a را مقایسه کنید.

**خروجی مرجع R و Python.** کنتراست تغییر تعدیل‌شده F=2.373170، P=0.157824.

**خودآزمایی.** اگر مقدار بعد فردی ثبت نشده باشد، آیا تغییرش را صفر وارد می‌کنید؟
