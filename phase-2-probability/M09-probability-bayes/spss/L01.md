# SPSS | درس 1 — از دادهٔ خام تا جدول چهارخانه

## از فایل فردی شروع کنید

[CSV فردی](../data/M09_individuals.csv) را با **File → Import Data → CSV Data** یا راهنمای ورود فایل متنی باز کنید. سطر اول عنوان ستون است و ویرگول جداکننده. در Data View هر سطر یک نفر است. در Variable View، id و joint_code عددی و population، reference و test رشته‌ای‌اند.

## هزار نفر را بدون حذف بقیه انتخاب کنید

از **Data → Select Cases**، گزینهٔ If condition is satisfied را بزنید. شرط `population = "baseline"` بگذارید و Filter out unselected cases را انتخاب کنید. گزینهٔ حذف دائمی را انتخاب نکنید. از **Data → Weight Cases** مطمئن شوید وزن‌دهی خاموش است، چون هر سطر یک فرد است.

در **Analyze → Descriptive Statistics → Crosstabs**، reference را به Row و test را به Column ببرید. در **Cells**، Observed را انتخاب کنید. پس از OK، جدول را با برچسب‌ها بخوانید. SPSS ممکن است negative را قبل از positive بیاورد. برای baseline، مثبت واقعی ۹۰، منفی کاذب ۱۰، مثبت کاذب ۹۰، منفی واقعی ۸۱۰ و جمع ۱۰۰۰ است. اجتماع یعنی سه خانهٔ اول یا ۱۰۰۰−۸۱۰.

اگر جمع ۱۱٬۰۰۰ است فیلتر فعال نشده. اگر ترتیب را نمی‌دانید، به برچسب نگاه کنید. از File → Save As برای دادهٔ sav و از پنجرهٔ Output برای spv کمک بگیرید.
