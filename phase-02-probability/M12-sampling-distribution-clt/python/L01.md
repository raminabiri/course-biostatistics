## آماده‌سازی و اجرا

در VS Code پوشهٔ ماژول را باز کنید و کد را در فایل py تازه بگذارید. دکمهٔ Run Python File را بزنید. خروجی در Terminal دیده می‌شود.

`import numpy as np` و `rng = np.random.default_rng(12)` را اجرا کنید. `sample = rng.exponential(10,(500,5))` یک آرایهٔ ۵۰۰ سطری با پنج انتظار در هر سطر است. `x = sample.mean(axis=1)` میانگین هر سطر را می‌سازد. print(sample.shape,x.shape) را ببینید.
