# SPSS | درس عملی 4 — نقشهٔ انتخاب آزمون

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

CSV بلند را باز کنید. در Analyze → Compare Means → Independent-Samples T Test، value را Test Variable و group را Grouping Variable بگذارید و A و B را تعریف کنید. ردیف Equal variances not assumed را برای Welch بخوانید.

**خروجی برای مقایسه.** Welch دوطرفه برای دو گروه مستقل دادهٔ تمرین، P≈۰٫۲۱۹.

**خودآزمایی.** اگر به جای عدد، پاسخ هر فرد بله یا خیر بود، آیا Welch همان انتخاب می‌ماند؟
