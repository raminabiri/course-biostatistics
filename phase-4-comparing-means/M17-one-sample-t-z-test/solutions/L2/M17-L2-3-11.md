# حل M17-L2-3-11

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 7/√20 ≈ 1.5652` دقیقه. در این سؤال σ معلوم فرض شده است.
۲. اختلاف را بر SE تقسیم کنید. `z = -2.7/1.5652 ≈ -1.7250`. برای پرسش چپ مساحت `P(Z ≤ -1.7250)` را بخوانید. مقدار P حدود **0.0423** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 1.9600 است. حاصل ضرب در SE، نیمه‌عرض 3.0678 را می‌دهد. فاصلهٔ **اختلاف** `[-5.768, 0.368]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
