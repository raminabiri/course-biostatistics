# python | آزمون z یک نسبت

## ورود داده

[CSV مشترک](../data/M34_practice.csv) را دریافت کنید. در VS Code پوشهٔ ماژول را باز کنید. در مفسر دوره، در صورت نیاز SciPy را با `python -m pip install scipy` نصب کنید. فایل M34_workshop.py را با Run Python File اجرا کنید. برای اجرای خط‌های زیر، دادهٔ `rows` و ابزار `stats` را از ابتدای همان فایل بگیرید.

## اجرا و دلیل هر گام

با `from math import sqrt` جذر را وارد کنید. `z=(k/n-.5)/sqrt(.5*.5/n)` را بسازید. `stats.norm.sf(z)` احتمال دنبالهٔ راست و `2*stats.norm.sf(abs(z))` دوطرفه است.

## کنترل و تمرین

z=۲، P راست ≈۰٫۰۲۲۷۵ و دوطرفه ≈۰٫۰۴۵۵. اگر عدد فرق کرد، نخست شمار سطرهای معتبر، ترتیب رده‌ها و جهت دنباله را کنترل کنید. نتیجه را در یک جمله برای سؤال درس بنویسید.
