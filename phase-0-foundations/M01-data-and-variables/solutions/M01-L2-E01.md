# پاسخ M01-L2-E01

## پرسش

سن یک فرد ۵۱ و کد بخش بستری او ۳ است. آیا هر دو عدد اندازهٔ یک ویژگی‌اند؟ معنای هر یک را توضیح دهید.

## پاسخ گام‌به‌گام

۵۱ اندازهٔ سن ثبت‌شده است و اختلاف آن با سن دیگران معنا دارد. کد ۳ نام کوتاه‌شدهٔ یک بخش است؛ بخش ۳ سه برابر بخش ۱ نیست. سن کمّی و نام بخش کیفی اسمی است.
