# SPSS | درس عملی 3 — کنتراست از پیش تعیین‌شده

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

در One-Way ANOVA، Post Hoc را باز و روش واریانس مشترک یا نامساوی را انتخاب کنید. برای روند از Contrasts با وزن −۱،۰،۱ استفاده کنید.

**خروجی مرجع R و Python.** روند C−A=8.8 و P تعدیل‌شدهٔ Tukey برای C−A حدود 0.001694.

**خودآزمایی.** اگر همهٔ میانگین‌ها ۴ واحد زیاد شوند چرا کنتراست روند ثابت می‌ماند؟
