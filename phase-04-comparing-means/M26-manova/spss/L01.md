# SPSS | درس عملی 1 — آزمون بردار پاسخ

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

GLM → Multivariate. y و z را در Dependent Variables و a را در Fixed Factors بگذارید. جدول Multivariate Tests برای a را بخوانید.

**خروجی مرجع R و Python.** Pillai=0.719386، Wilks=0.280614، F=37.172314.

**خودآزمایی.** آیا نتیجهٔ کلی مشخص می‌کند کدام پاسخ تغییر کرده است؟
