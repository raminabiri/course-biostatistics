## بخش آموزشی

| کار | Excel | نکته |
|---|---|---|
| چارک (تعریف ۶، مثل SPSS/Prism) | `QUARTILE.EXC(r, 1)`، `PERCENTILE.EXC(r, 0.9)` | |
| چارک (تعریف ۷، مثل R/Python) | `QUARTILE(r, 1)` = `QUARTILE.INC` | |
| چولگی، کشیدگی | `SKEW(r)`، `KURT(r)` | **G1، G2** (کشیدگی اضافی) ✔ |
| نمرهٔ z | `=(C2-AVERAGE(C$2:C$61))/STDEV(C$2:C$61)` یا `STANDARDIZE(x, mean, sd)` | |
| میانگین پیراسته | `TRIMMEAN(r, 0.1)` | **۰٫۱ = مجموعاً ۱۰٪** (۵٪ از هر طرف) |
| لگاریتم | `LOG10`، `LN`، `LOG(x, 2)` | |
| میانگین هندسی | `GEOMEAN(r)` | |
| شمارش بالای حصار | `=COUNTIF(r, ">"&حصار)` | `&` عدد را به معیار می‌چسباند |
| نمودار جعبه‌ای | `Insert > Charts > Box and Whisker` (Excel 2016+) | چارک‌ها با گزینهٔ Inclusive/Exclusive median قابل‌تنظیم |

### ستون کمکی «بدون یک مقدار»

برای تحلیل حساسیت، یک ستون بسازید که مقدار مورد نظر را خالی کند: `=IF(C2=168,"",C2)`. توابع `AVERAGE`، `STDEV` و `SKEW` متن خالی را نادیده می‌گیرند.

### حل تمرین‌ها

همهٔ فرمول‌ها در برگهٔ `solutions` فایل حل.

<details>
<summary><b>حل ع۱ و ع۲</b></summary>

```
=MIN(D2:D61)  =QUARTILE.EXC(D2:D61,1)  =MEDIAN(D2:D61)  =QUARTILE.EXC(D2:D61,3)  =MAX(D2:D61)
→ 0.5  1.025  1.6  2.7  6.5
=QUARTILE(D2:D61,1)  → 1.075  (تعریف ۷)
=SKEW(D2:D61)  → 1.43        =KURT(E2:E61)  → 10.98
```

</details>

<details>
<summary><b>حل ع۳</b></summary>

```
حصار:  =QUARTILE.EXC(D2:D61,3)+1.5*(QUARTILE.EXC(D2:D61,3)-QUARTILE.EXC(D2:D61,1))   → 5.21
تعداد: =COUNTIF(D2:D61,">"&5.2125)                                                       → 2
los:   حصار 13؛ =COUNTIF(E2:E61,">13")                                                   → 6
```

</details>

<details>
<summary><b>حل ع۴</b></summary>

```
=(168-AVERAGE(C2:C61))/STDEV(C2:C61)            → 5.20
=(124-AVERAGE(C2:C61))/STDEV(C2:C61)            → -2.72
ستون H با z همهٔ سطرها؛ =COUNTIF(H2:H61,">3")+COUNTIF(H2:H61,"<-3")  → 1
ستون I: =IF(C2=168,"",C2) ← =(124-AVERAGE(I2:I61))/STDEV(I2:I61)     → -3.57
```

</details>

<details>
<summary><b>حل ع۵ و ع۶</b></summary>

```
=TRIMMEAN(E2:E61,0.1)        → 5.52   (los)
=TRIMMEAN(D2:D61,0.1)        → 1.88   (lactate)
ستون G: =LOG10(D2) ← =SKEW(G2:G61) → 0.16 ؛ =AVERAGE(G2:G61) → 0.2231
=GEOMEAN(D2:D61)             → 1.67
=10^STDEV(G2:G61)            → 1.82
```

</details>

<summary><b>حل ع۷</b></summary>

```
=COUNT(I2:I61) → 59   =AVERAGE(I2:I61) → 138.64   =STDEV(I2:I61) → 4.10   =SKEW(I2:I61) → -0.53
```

</details>

## خطاهای رایج

| مشکل | علت | راه‌حل |
|---|---|---|
| `TRIMMEAN` با R فرق دارد | نسبت کل در Excel، نسبت هر طرف در R | R `trim = 0.05` ↔ Excel `0.1` |
| `#NUM!` در `QUARTILE.EXC` | n خیلی کوچک برای آن صدک | n بیشتر یا `QUARTILE.INC` |
| نمودار جعبه‌ای با حساب دستی نمی‌خواند | گزینهٔ Quartile calculation در Format Data Series | Exclusive median را انتخاب کنید |
