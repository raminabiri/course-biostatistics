# حل M17-L3-3-07

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 7/√16 ≈ 1.7500` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 16-1 = 15` است.
۲. اختلاف را بر SE تقسیم کنید. `t = 1.8/1.7500 ≈ 1.0286`. برای پرسش راست مساحت `P(T ≥ 1.0286)` را بخوانید. مقدار P حدود **0.1600** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.1314 است. حاصل ضرب در SE، نیمه‌عرض 3.7300 را می‌دهد. فاصلهٔ **اختلاف** `[-1.930, 5.530]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
