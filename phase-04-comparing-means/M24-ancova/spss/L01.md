# SPSS | درس عملی 1 — پیش‌بینی در خط پایهٔ یکسان

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

[دادهٔ تمرین change.csv](../data/change.csv)

GLM → Univariate، value را Dependent، a را Fixed Factor و baseline را Covariate بگذارید. Estimated Marginal Means را در خط پایهٔ ۲۴ بخوانید یا دستور EMMEANS=TABLES(a) WITH(baseline=24) را به GLM اضافه کنید.

### گام‌های اجرا و کنترل

در فایل practice.csv از Data → Select Cases شرط `b=0` را فعال کنید. با File → New → Syntax پنجرهٔ فرمان باز کنید. کد زیر پیش‌بینی هر سطح a در baseline=24 را می‌دهد.

```spss
UNIANOVA value BY a WITH baseline
 /EMMEANS=TABLES(a) WITH(baseline=24)
 /DESIGN=baseline a.
```

BY عامل مقوله‌ای و WITH سنجهٔ کمّی را مشخص می‌کند. در جدول Estimated Marginal Means، سطح ۰ و ۱ را جدا بخوانید. برای درس بعد All cases را برگردانید.

**خروجی مرجع R و Python.** پیش‌بینی در baseline=24 برای A0 و A1 برابر 48.942857 و 51.285714.

**خودآزمایی.** اگر دو گروه به‌ترتیب خط پایهٔ ۲۰ و ۲۸ داشته باشند، اختلاف پیش‌بینی خام در همین مدل چند است؟
