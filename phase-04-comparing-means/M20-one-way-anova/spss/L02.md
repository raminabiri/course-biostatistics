# SPSS | درس عملی 2 — ناهمسانی پراکندگی

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

در One-Way ANOVA، Options و بخش Robust Tests of Equality of Means را باز کنید. Welch و Brown–Forsythe را درخواست کنید.

**خروجی مرجع R و Python.** Welch: F=9.266389، P=0.009547. Brown–Forsythe: F=10.664260، P=0.004720.

**خودآزمایی.** اگر جدول فقط آمارهٔ Levene گزارش کند، آیا می‌دانید میانگین‌ها فرق دارند؟
