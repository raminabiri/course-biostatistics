# spss | تعامل و هم‌خطی

[CSV آموزشی](../data/M47_practice.csv) را باز کنید. پیش از تغییر ستون‌ها، [کدبوک](../data/README.md) را بخوانید. در R و Python فایل M47_workshop را از پوشهٔ ماژول اجرا کنید.

## اجرا و کنترل

Compute برای cross=h*is_b و سپس Linear Regression با هر چهار predictor. Statistics → Collinearity diagnostics را روشن کنید. Coefficients، VIF و P ردیف cross را نشان می‌دهد. برچسب is_b برای گروه مرجع صفر است.

تعامل≈−۰٫۷۲۰، P≈۰٫۰۴۱۴ و VIF h≈۴٫۵۳۵. مدل، تعداد و جهت مقایسه را کنار خروجی بنویسید.
