# آموزش آمار پزشکی و زیستی

برای دانشجوی پزشکی، پیراپزشکی و علوم زیستی تا متخصص و پژوهشگر. آموزش فارسی است و کار با Excel، SPSS، GraphPad Prism، R و Python را در مسیرهای جداگانه دنبال می‌کنیم.

## از کجا آغاز کنم؟

**[از صفر شروع کنید ←](phase-0-foundations/M01-data-and-variables/START.md)**

هیچ آشنایی با آمار یا کدنویسی لازم نیست. نخست جدول سه‌نفری را در یک نرم‌افزار می‌سازید؛ سپس به درس نخست می‌روید. خواندن هر پنج مسیر لازم نیست.

**مسیر شما: ورود داده ← درس ← تمرین ← پاسخ همان پرسش ← درس بعد**

## اکنون چه بخوانم؟

نسخهٔ بازبینی‌شدهٔ [ماژول M01](phase-0-foundations/M01-data-and-variables/README.md) نقطهٔ آغاز است: چهار درس سه‌سطحی، ۱۲۰ تمرین و پاسخ‌های جدا. برای تازه‌کار، بخش مقدماتی و پنج تمرین نخست هر درس کافی است؛ بخش‌های دیگر برای بازگشت بعدی‌اند.
