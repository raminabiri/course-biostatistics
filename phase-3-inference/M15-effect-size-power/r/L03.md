# R | درس عملی 3 — توان و اهمیت

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

در L3، power.t.test افراز دوطرفه و strict=TRUE را به کار می‌برد. نتیجه را رو به بالا گرد کنید.

[فایل کد](../r/M15_workshop.R) را باز کنید. power.t.test حجم لازم برای مدل را می‌دهد و ceiling رو به بالا گرد می‌کند.
