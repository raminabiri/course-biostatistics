# پاسخ M01-L3-E06

## پرسش

**سطح:** متوسط | **مخاطب:** دانشجو و پژوهشگر

برای متغیر `cipro_res` یک ردیف کامل کدبوک بنویسید.

## پاسخ گام‌به‌گام

| بخش | مقدار |
|---|---|
| نام متغیر | `cipro_res` |
| شرح | مقاومت ایزولهٔ جداشده به سیپروفلوکساسین بر اساس آنتی‌بیوگرام |
| واحد | — |
| کدها | 0 = حساس (Susceptible)، 1 = مقاوم (Resistant) |
| نوع / مقیاس | کیفی دوحالتی / اسمی |
| کد گمشده | ندارد (در این داده همهٔ مقادیر ثبت شده) |
| یادداشت | بهتر است مرجع تفسیر (برای نمونه نسخهٔ CLSI یا EUCAST) و نحوهٔ برخورد با «Intermediate» هم نوشته شود. |
