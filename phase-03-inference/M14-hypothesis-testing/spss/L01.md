# SPSS | درس عملی 1 — فرضیه، جهت و آماره

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

در Syntax یک سطر با `DATA LIST FREE / mean_value target sd_value n.
BEGIN DATA
54 50 10 25
END DATA.
COMPUTE tval=(mean_value-target)/(sd_value/SQRT(n)).
EXECUTE.` بسازید. tval در Data View برابر ۲ است.

**خروجی برای مقایسه.** t=۲، df=۲۴.

**خودآزمایی.** اگر فقط سؤال «فرق دارد؟» بود، چه چیزی عوض می‌شد؟
