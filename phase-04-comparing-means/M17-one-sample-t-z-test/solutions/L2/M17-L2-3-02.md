# حل M17-L2-3-02

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 6/√11 ≈ 1.8091` دقیقه. در این سؤال σ معلوم فرض شده است.
۲. اختلاف را بر SE تقسیم کنید. `z = -2.7/1.8091 ≈ -1.4925`. برای پرسش چپ مساحت `P(Z ≤ -1.4925)` را بخوانید. مقدار P حدود **0.0678** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 1.9600 است. حاصل ضرب در SE، نیمه‌عرض 3.5457 را می‌دهد. فاصلهٔ **اختلاف** `[-6.246, 0.846]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
