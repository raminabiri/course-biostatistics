# python | درس ۵۰٫۲

[داده](../data/M50_sets.csv) را باز کنید. هر مجموعه سه سطر دارد.

فایل M50_L2.py را اجرا کنید. `sets` ردیف‌ها را با شناسهٔ مجموعه جمع می‌کند. برای هر مقدار پیشنهادی β، وزن فرد بدون مواجهه ۱ و وزن فرد مواجهه‌دار exp(β) است. تابع score از مواجههٔ مورد واقعی، میانگین وزن‌دار مواجههٔ اعضای همان مجموعه را کم می‌کند و حاصل‌ها را جمع می‌زند. الگوریتم بازهٔ جست‌وجو را نصف می‌کند تا مجموع نزدیک صفر شود. اگر علامت دو سر بازه مناسب نباشد، پیام بررسی جداسازی یا نبود اختلاف مواجهه می‌دهد. برای یک مورد در هر مجموعه و یک متغیر مواجههٔ دودویی، لازم نیست شمار شاهدها در همهٔ مجموعه‌ها برابر باشد.
