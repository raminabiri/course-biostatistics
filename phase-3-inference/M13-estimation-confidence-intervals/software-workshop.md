# کارگاه گام‌به‌گام M13

این کارگاه ادامهٔ [شروع M01](../../phase-0-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio فایل [M13_workshop.R](r/M13_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M13_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M13_workshop.py](python/M13_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M13_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

## تمرین 13.1

**خروجی برای مقایسه.** فاصله حدود [۴۵٫۸۷، ۵۴٫۱۳] دقیقه.

### Excel

A1=50، A2=10 و A3=25 را بنویسید. A4 را با `=T.INV.2T(0.05,A3-1)*A2/SQRT(A3)` پر کنید. A1 منهای A4 و A1 به‌علاوهٔ A4 کران‌ها هستند.

### SPSS

در Syntax بنویسید `DATA LIST FREE / m s n.
BEGIN DATA
50 10 25
END DATA.
COMPUTE h=IDF.T(.975,n-1)*s/SQRT(n).
COMPUTE lo=m-h.
COMPUTE hi=m+h.
EXECUTE.` هر خط را جدا وارد کنید و lo و hi را در Data View بخوانید.

### Prism

در Prism 11، جدول XY باز کنید. در X و Y مقدار ۵۰ بگذارید. از Analyze → Transform، تبدیل کاربر Y را با `Y=Y-TINV(0.05,24)*2` انجام دهید. تبدیل جدا با +، بالا را می‌دهد. Results را بخوانید.

### R

فایل تمرین را اجرا کنید. سطر L1 با qt ضریب توزیع t و با sqrt خطای استاندارد را می‌سازد.

### Python

فایل تمرین را اجرا کنید. در scipy.stats.t، تابع ppf صدک تجمعی را برمی‌گرداند. سطر L1 دو کران را چاپ می‌کند.

## تمرین 13.2

**خروجی برای مقایسه.** برای ۲ پاسخ مثبت از ۲۰، فاصلهٔ دقیق حدود [۰٫۰۱۲، ۰٫۳۱۷].

### Excel

در A1 مقدار ۲ و در A2 مقدار ۲۰ را وارد کنید. کران‌ها را با `=IF(A1=0,0,BETA.INV(0.025,A1,A2-A1+1))` و `=IF(A1=A2,1,BETA.INV(0.975,A1+1,A2-A1))` حساب کنید.

### SPSS

در یک مجموعهٔ فعال یک‌ردیفی، Transform → Compute Variable را باز کنید. lo را با `IDF.BETA(.025,2,19)` و hi را با `IDF.BETA(.975,3,18)` بسازید.

### Prism

برای اجرای ویلسون در Prism، جدول XY با Y=0.10 بسازید. تبدیل کاربر را برای مرکز `(Y+1.96^2/40)/(1+1.96^2/20)` انجام دهید. برای نیمه‌عرض، روی همان دادهٔ اولیه تبدیل `1.96*sqrt(Y*(1-Y)/20+1.96^2/1600)/(1+1.96^2/20)` را اجرا کنید. کران‌ها با کم و زیادکردن نیمه‌عرض حدود ۰٫۰۲۸ و ۰٫۳۰۱ می‌شوند.

### R

سطر L2 با binom.test فاصلهٔ دقیق را چاپ می‌کند. عدد ۲ شمار موفق‌ها و ۲۰ شمار کل است.

### Python

سطر L2، binomtest را با ۲ و ۲۰ اجرا و روش exact و wilson را چاپ می‌کند.

## تمرین 13.3

**خروجی برای مقایسه.** فاصلهٔ Welch حدود [−۱٫۴۱، ۹٫۴۱] دقیقه.

### Excel

A1=4، A2=4 و A3=3.2 را بگذارید. در A4 `=(A2+A3)^2/(A2^2/24+A3^2/19)` و در A5 `=T.INV.2T(0.05,A4)*SQRT(A2+A3)` را بزنید. مقدار A1 ± A5 را گزارش کنید. Excel در این تابع df را صحیح می‌کند، بنابراین تفاوت گرد کردن را در نظر بگیرید.

### SPSS

روی یک ردیف فعال، به‌ترتیب df را با `7.2**2/(4**2/24+3.2**2/19)` و h را با `IDF.T(.975,df)*SQRT(7.2)` بسازید. با دو Compute دیگر ۴ منهای h و ۴ به‌علاوهٔ h را ذخیره کنید.

### Prism

در Prism 11، جدول XY با Y=4 باز کنید. از Transform و User-defined Y transform برای `Y=Y-TINV(0.05,43)*sqrt(7.2)` کمک بگیرید. برای کران بالا + بگذارید. ۴۳ درجهٔ آزادی گرد شده است.

### R

اسکریپت سطر L3، سهم واریانس دو میانگین و df را پیش از فاصله حساب می‌کند.

### Python

اسکریپت سطر L3 معادلهٔ Welch را با scipy.stats.t اجرا می‌کند.
