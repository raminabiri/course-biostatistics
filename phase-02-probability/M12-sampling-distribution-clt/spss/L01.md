# SPSS | درس 1 — از یک مشاهده تا یک میانگین

از یک فرایند ساختگی دو گروه سه‌نفری گرفته‌ایم: ۴،۸،۱۲ و ۳،۹،۱۸ دقیقه.

## آماده‌سازی و اجرا

اگر تمرین با دادهٔ تازه شروع می‌شود، ابتدا فایل جدید باز کنید. نام و نوع ستون در Variable View و مقدارها در Data View قرار می‌گیرند.

از File → New → Syntax، قطعهٔ INPUT PROGRAM در [کارگاه](../software-workshop.md) را اجرا کنید. هر سطر یک نمونه است. avg5 میانگین پنج انتظار، sample_id شناسهٔ همان تکرار است.
