# spss | نیکویی برازش

## ورود داده

[CSV مشترک](../data/M34_practice.csv) را دریافت کنید. فایل را با File → Import Data → CSV Data باز کنید. سطر نخست نام متغیرهاست. در Variable View، on_time را Numeric و route را String کنترل کنید. برای فرمان‌ها File → New → Syntax و Run → All را بزنید.

## اجرا و دلیل هر گام

در Frequencies، route را بشمارید. برای آزمون با نسبت‌های نابرابر، یک فایل تازه با دو ستون عددی observed و expected و سه سطر (۶۵،۵۰)، (۲۵،۳۰)، (۱۰،۲۰) بسازید. با `COMPUTE component=(observed-expected)**2/expected.` سهم‌ها را حساب کنید. Frequencies → Statistics → Sum برابر ۱۰٫۳۳۳ را می‌دهد. در Compute جدا `1-CDF.CHISQ(10.3333333333,2)` را بزنید و در Data View نتیجه را بخوانید.

## کنترل و تمرین

χ²≈۱۰٫۳۳۳، df=۲ و P≈۰٫۰۰۵۷۰۴. اگر عدد فرق کرد، نخست شمار سطرهای معتبر، ترتیب رده‌ها و جهت دنباله را کنترل کنید. نتیجه را در یک جمله برای سؤال درس بنویسید.
