## پیش‌بینی و شمارش را جداگانه بسنجید

همان فایل را ادامه دهید:

```python
low = [row for row in rows if row["population"] == "low"]
test_positive = [row for row in low if row["test"] == "positive"]
known_disease = sum(row["reference"] == "positive" for row in low)
known_disease_in_positive = sum(row["reference"] == "positive" for row in test_positive)
p = known_disease / len(low)
true_share = p * .9
false_share = (1 - p) * .1
print(len(low), len(test_positive))
print(known_disease_in_positive / len(test_positive))
print(true_share / (true_share + false_share))
```

در جمع منطقی، True مثل ۱ و False مثل صفر حساب می‌شود. در خروجی ۱۰٬۰۰۰ و ۱۰۸۰ و سپس دو مقدار تقریباً برابر ۰٫۰۸۳۳ می‌بینید. اولی از شمار مستقیم و دومی از مدل بیز آمده است.
