# حل M17-L2-3-13

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 5/√22 ≈ 1.0660` دقیقه. در این سؤال σ معلوم فرض شده است.
۲. اختلاف را بر SE تقسیم کنید. `z = -0.9/1.0660 ≈ -0.8443`. برای پرسش راست مساحت `P(Z ≥ -0.8443)` را بخوانید. مقدار P حدود **0.8007** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 1.9600 است. حاصل ضرب در SE، نیمه‌عرض 2.0893 را می‌دهد. فاصلهٔ **اختلاف** `[-2.989, 1.189]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
