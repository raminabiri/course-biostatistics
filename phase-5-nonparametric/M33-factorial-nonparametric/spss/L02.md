# SPSS | درس عملی 2 — Scheirer–Ray–Hare

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

در Rank Cases رتبهٔ value را بسازید. در GLM Univariate مدل عاملی کامل با رتبه به عنوان پیامد بزنید. SS هر اثر را جدا کنید و H را با SS کل تصحیح‌شده /(N−1) بسازید.

### رتبهٔ یک مشاهده را تا آماره دنبال کنید

برای SRH، ۳۲ پاسخ را یک‌جا مرتب کنید. در فایل حاضر تساوی نداریم و مقدار ۲۷٫۲۴ رتبهٔ ۲ می‌گیرد. مجموع رتبهٔ چهار خانه به ترتیب A0B0، A0B1، A1B0 و A1B1 برابر ۵۸،۱۰۵،۱۳۸ و ۲۲۷ است و جمع چهار عدد ۵۲۸=۳۲×۳۳÷۲ می‌شود. اختلاف این مجموع‌ها به‌تنهایی F نیست. در ANOVA روی رتبه‌ها، SS تعامل را از سطر تعامل بردارید و برای H بر واریانس کل رتبه‌ها تقسیم کنید. H≈۰٫۶۲۶۴ است.

با Rank Cases همهٔ valueها را بدون Split File رتبه‌بندی کنید. در Univariate، رتبه را پاسخ و a و b را عامل بگذارید. SS تعامل را جدا بردارید و برای H بر واریانس کل رتبه‌ها تقسیم کنید.

**خروجی مرجع R و Python.** برای تعامل SRH، H≈۰٫۶۲۶۴۲۰ و P≈۰٫۴۲۸۶۷۱.
