# حل M17-L3-3-04

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 8/√13 ≈ 2.2188` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 13-1 = 12` است.
۲. اختلاف را بر SE تقسیم کنید. `t = -0.9/2.2188 ≈ -0.4056`. برای پرسش راست مساحت `P(T ≥ -0.4056)` را بخوانید. مقدار P حدود **0.6539** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.1788 است. حاصل ضرب در SE، نیمه‌عرض 4.8344 را می‌دهد. فاصلهٔ **اختلاف** `[-5.734, 3.934]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
