# R | درس عملی 1 — فاصلهٔ میانگین

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

فایل تمرین را اجرا کنید. سطر L1 با qt ضریب توزیع t و با sqrt خطای استاندارد را می‌سازد.

[فایل کد](../r/M13_workshop.R) را باز کنید. qt صدک t با df را می‌دهد؛ sqrt جذر حجم نمونه است.

**خروجی برای مقایسه.** فاصله حدود [۴۵٫۸۷، ۵۴٫۱۳] دقیقه.

**خودآزمایی.** اگر n چهار برابر شود اما SD همان ۱۰ باشد، SE چند می‌شود؟
