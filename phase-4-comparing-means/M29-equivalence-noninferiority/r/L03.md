# R | درس عملی 3 — هم‌ارزی نسبت‌ها

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

اسکریپت R را اجرا کنید. خط L3 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

[فایل کد](../r/M29_workshop.R) را باز کنید. pnorm و qnorm توزیع نرمال را برای تقریب اختلاف دو نسبت به‌کار می‌برند.

**خروجی مرجع R و Python.** Pهای 0.001235 و 0.034667 و فاصلهٔ ۹۰٪ [−0.051507, 0.111507].

**خودآزمایی.** آیا فاصلهٔ [−۰٫۰۵،۰٫۱۱] با حاشیهٔ ±۰٫۱۰ هم‌ارزی را نشان می‌دهد؟
