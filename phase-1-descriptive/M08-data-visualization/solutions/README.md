# پاسخ‌های M08

| شناسه | پاسخ |
|---|---|
| M08-1 | ۱۶۰ mmHg، گروه A. |
| M08-2 | ۴ نفر با فشارهای ۱۲۰، ۱۲۲، ۱۲۵ و ۱۲۶. |
| M08-3 | در هر دو گروه روش و تنظیم هموارسازی قابل مقایسه به کار ببرید و نقطه‌های اندازه‌گیری‌شده را همراه ویولن نمایش دهید. |
| M08-4 | ۱۶۰ mmHg، گروه A. |
| M08-5 | ۱۲٫۷۰۵ تقسیم بر جذر ۸، حدود ۴٫۴۹ mmHg. |
| M08-6 | داده‌ها برای تمرین ساخته شده‌اند و تخصیص تصادفی یا طراحی علّی تعریف نشده است. اختلاف فشار یک خلاصهٔ توصیفی است. |
| M08-7 | روز صفر ۱۳۶ و روز ۱۴ برابر ۱۳۰ mmHg است. روز ۷ گمشده است. |
| M08-8 | به ترتیب ۸، ۸ و ۷ نفر. برای تغییر زوجی نیز ۷ نفر هر دو اندازه‌گیری را دارند. |
| M08-9 | اختلاف میانگین‌های موجود ۱۲۵٫۲۹ منهای ۱۲۹٫۱۲۵، حدود منفی ۳٫۸۴ mmHg است. میانگین تغییر زوجی منفی ۲٫۵۷ است. فرد ۱۵ در میانگین آغازین هست و فشار روز ۱۴ او ثبت نشده است. |

[بازگشت به تمرین‌ها](../exercises/README.md)

- **M08-10.** به ترتیب بازه‌ها ۱، ۸، ۵، ۱، ۰ و ۱.
- **M08-11.** جابه‌جایی عمودی یکسان در هر دو نمودار باید همان تغییر mmHg را نشان دهد تا افراد دو گروه دیداری مقایسه‌پذیر باشند.
- **M08-12.** میانگین‌ها ۱۳۱٫۳۷۵ و ۱۲۲٫۶۲۵ هستند. اختلاف منفی ۸٫۷۵ است و چون هر هشت نفر هر دو فشار را دارند، با میانگین تغییر زوجی برابر است.
