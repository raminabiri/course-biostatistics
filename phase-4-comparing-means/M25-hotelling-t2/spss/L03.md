# SPSS | درس عملی 3 — بردار تغییر زوجی

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

در Compute Variable دو اختلاف بسازید. از جدول خلاصهٔ همین تفاوت‌ها برای محاسبهٔ T² تک‌نمونه‌ای کمک بگیرید.

**خروجی مرجع R و Python.** زوجی T²=37.195995، F=17.998062، P≈0.000007312.

**خودآزمایی.** اگر پاسخ دوم بعد برای یک بیمار مفقود باشد؟
