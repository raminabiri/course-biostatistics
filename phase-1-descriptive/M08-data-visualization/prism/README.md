# رسم در GraphPad Prism

اندازه‌گیری روز صفر هر گروه را در ستون جدا بگذارید و از نمایش نقطه‌ای، جعبه‌ای یا ویولن کمک بگیرید. برای پراکنش، در جدول XY سن را X و فشار را Y بگذارید. برای مسیر فردی، از روزهای ۰، ۷ و ۱۴ به عنوان X و یک سری Y برای هر فرد کمک بگیرید. روز گمشده را خالی نگه دارید و نمایش شکاف را در خروجی بررسی کنید.
