# Python | درس 2 — شمارِ رویداد و شمارِ شکست

یک مرکز آموزشی در هر ساعت به‌طور میانگین دو تماس می‌گیرد. در پرسشی جدا، یک تلاش آموزشی با احتمال موفقیت ۰٫۵ تکرار می‌شود.

## آماده‌سازی و اجرا

در VS Code پوشهٔ ماژول را باز کنید و کد را در فایل py تازه بگذارید. دکمهٔ Run Python File را بزنید. خروجی در Terminal دیده می‌شود.

`from math import exp` و `print(exp(-2), 2*.5**3)` را اجرا کنید. اولی پواسون با شمار صفر و دومی شمار یک شکست در مثال است.

## کنترل و گزارش

پواسونِ صفر در یک ساعت ۰٫۱۳۵۳ و احتمال یک شکست ۰٫۲۵ است.
