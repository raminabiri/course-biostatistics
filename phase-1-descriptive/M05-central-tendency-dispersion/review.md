## خلاصهٔ ماژول در یک نگاه

| مفهوم | نکتهٔ کلیدی |
|---|---|
| میانگین / میانه / نما | میانگین حساس به مقادیر دور؛ میانه مقاوم؛ نما برای متغیر اسمی |
| چولهٔ راست | میانگین > میانه؛ رایج در متغیرهای آزمایشگاهی و هزینه |
| SD / IQR / CV | SD برای دادهٔ متقارن؛ IQR برای چوله؛ CV برای مقایسهٔ نسبی (فقط مقیاس نسبی) |
| SD در برابر SEM | SD = افراد؛ SEM = SD/√n = دقت میانگین |
| گزارش | میانگین (SD) یا میانه (Q1–Q3)؛ درصد با تعداد؛ n هر گروه |

| کار | SPSS | Prism | R | Python | Excel |
|---|---|---|---|---|---|
| همهٔ شاخص‌ها | Frequencies ← Statistics | Descriptive statistics | `summary`، `sd` | `.describe()`، `.std()` | Data Analysis ← Descriptive Statistics |
| به تفکیک گروه | Means | یک ستون برای هر گروه | `aggregate` | `groupby().agg()` | PivotTable |
| چارک روش ۶ | پیش‌فرض | پیش‌فرض | `type = 6` | `method="weibull"` | `QUARTILE.EXC` |
| چارک روش ۷ | — | — | پیش‌فرض | پیش‌فرض | `QUARTILE` / `.INC` |

## سطح ۱ — پایه

**پ۱.** برای 5، 7، 8، 8، 12: میانگین، میانه، نما و SD را حساب کنید.

<details>
<summary><b>حل</b></summary>

میانگین = 40/5 = **8**؛ میانه = **8**؛ نما = **8**. انحراف‌ها: −3، −1، 0، 0، 4 ← مجذورها 9، 1، 0، 0، 16 ← جمع 26 ← واریانس = 26/4 = 6.5 ← SD = **2.55**.

</details>

**پ۲.** خلاصهٔ مناسب هر متغیر: (الف) فشار دیاستولی بزرگسالان (ب) تعداد روزهای غیبت از کار به‌خاطر بیماری در سال (بیشتر افراد صفر) (ج) گروه خونی (د) سطح فریتین سرم (چوله)

<details>
<summary><b>حل</b></summary>

(الف) **میانگین (SD)** (ب) **درصد با ≥ ۱ روز** + میانه در آن‌ها (ج) **تعداد (٪)** (د) **میانه (Q1–Q3)** یا میانگین هندسی

</details>

## سطح ۲ — متوسط

**پ۳.** (الف) SD قند ناشتای ۶۴ بیمار ۲۴ mg/dL است. SEM؟ (ب) مقاله‌ای «HbA1c ۷٫۸ ± ۰٫۱۵ (میانگین ± SEM)، n = ۱۰۰» نوشته؛ SD چقدر است؟

<details>
<summary><b>حل</b></summary>

- (الف) 24/√64 = 24/8 = **3 mg/dL**
- (ب) 0.15 × √100 = **1.5٪**

</details>

**پ۴.** دو دستگاه یک نمونهٔ کنترل را اندازه گرفته‌اند: دستگاه A برای کراتینین (میانگین ۱٫۲، SD ۰٫۰۶ mg/dL) و دستگاه B برای قند (میانگین ۱۰۰، SD ۳ mg/dL). کدام تکرارپذیرتر است؟

<details>
<summary><b>حل</b></summary>

CV_A = 0.06/1.2 = **۵٪**؛ CV_B = 3/100 = **۳٪** ← **B** تکرارپذیرتر است (SD بزرگ‌ترش به‌خاطر اندازهٔ بزرگ‌تر کمیت است).

</details>

**پ۵.** یک جدول گزارش کرده: «مدت بستری: ۸٫۲ ± ۹٫۵ روز». (الف) دو نکتهٔ مبهم یا نادرست را بنویسید. (ب) چه چیزی را جایگزین می‌کنید؟

<details>
<summary><b>حل</b></summary>

- **(الف)** (۱) معلوم نیست ± SD است یا SEM. (۲) اگر SD باشد، میانگین − ۲SD = −10.8 روز (غیرممکن) و SD > میانگین ← توزیع چوله است و میانگین (SD) مناسب نیست.
- **(ب)** «مدت بستری، میانه (Q1–Q3): … روز».

</details>

**پ۶.** این اعداد را به یک جدول دو گروهی استاندارد تبدیل کنید. گروه دارو (n = ۴۰): سن میانگین ۶۱٫۳۵۷، SD ۹٫۸۸؛ زن ۱۸ نفر؛ CRP میانه ۴٫۲ (چارک‌ها ۲٫۱ و ۹٫۷). گروه دارونما (n = ۳۸): سن ۶۰٫۹۱۲، SD ۱۰٫۴؛ زن ۱۹ نفر؛ CRP میانه ۳٫۹ (۱٫۸ و ۸٫۸).

<details>
<summary><b>حل</b></summary>

| | دارو (n = 40) | دارونما (n = 38) |
|---|---|---|
| سن، سال، میانگین (SD) | 61.4 (9.9) | 60.9 (10.4) |
| زن، تعداد (٪) | 18 (45.0) | 19 (50.0) |
| CRP، mg/L، میانه (IQR) | 4.2 (2.1–9.7) | 3.9 (1.8–8.8) |

</details>

## سطح ۳ — پیشرفته

**پ۷.** یک شکل مقاله، بیان یک ژن را در دو گروه (هر گروه n = ۳ موش) با ستون و میلهٔ خطای «SEM» نشان داده است. سه ایراد و یک نمایش بهتر بنویسید.

<details>
<summary><b>حل</b></summary>

1. با n = ۳، SEM خودش بسیار نادقیق است؛ میله‌های کوتاه SEM اطمینان کاذب می‌دهند (فاصلهٔ اطمینان ۹۵٪ حدود ۴ برابر SEM است).
2. ستون فقط میانگین را نشان می‌دهد و **داده‌های واقعی** (سه نقطه) پنهان است؛ یک موش پرت دیده نمی‌شود.
3. SEM توصیف پراکندگی **موش‌ها** نیست؛ اگر هدف نشان دادن تنوع زیستی است، SD لازم است.
**بهتر:** نمودار نقطه‌ای با همهٔ نقطه‌ها + خط میانگین (و در صورت نیاز فاصلهٔ اطمینان)؛ در زیرنویس n و نوع میله را بنویسید (Cumming و همکاران، منبع ۵؛ M08).

</details>

**پ۸.** دو بیمارستان میانگین مدت بستری یکسان ۷ روز دارند. بیمارستان A: میانه ۶ (Q1–Q3: ۵–۸)؛ بیمارستان B: میانه ۳ (Q1–Q3: ۲–۶). (الف) توزیع کدام چوله‌تر است؟ (ب) چه چیزی دربارهٔ بیماران B می‌توان حدس زد؟ (ج) چرا فقط مقایسهٔ میانگین گمراه‌کننده است؟

<details>
<summary><b>حل</b></summary>

- **(الف)** **B**: میانه (۳) بسیار کمتر از میانگین (۷) است و ۷۵٪ بیماران حداکثر ۶ روز بستری‌اند؛ پس چند بیمار با بستری بسیار طولانی میانگین را بالا کشیده‌اند.
- **(ب)** بیشتر بیماران B کوتاه‌مدت بستری می‌شوند، ولی گروه کوچکی بستری بسیار طولانی دارند (شاید بیماران پیچیده یا عوارض).
- **(ج)** میانگین یکسان دو الگوی کاملاً متفاوت را پنهان کرده است؛ برای مدیریت تخت و کیفیت مراقبت، میانه و چارک‌ها (یا هیستوگرام، M08) اطلاعات بسیار بیشتری می‌دهند.

</details>
