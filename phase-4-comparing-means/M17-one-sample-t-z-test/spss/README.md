# M17 با SPSS | داده، آزمون و خواندن خروجی

دو راه دارید. راه منویی برای فهم ترتیب کار مناسب است. [فایل Syntax](M17_workshop.sps) همان تحلیل را تکرارپذیر انجام می‌دهد. هر دو از هشت زمان انتظار شروع می‌کنند. قبل از تمرین، فایل‌های کاری دیگر را ذخیره کنید و یک جلسهٔ تازه باز کنید.

## ۱. راه منویی

۱. [فایل CSV](../data/values.csv) را دانلود کنید. در **File → Import Data → CSV Data** آن را باز کنید. اگر در نسخهٔ شما این گزینه نیست، از **File → Open → Data** فایل CSV را انتخاب کنید و راهنمای ورود فایل متنی را دنبال کنید. سطر اول نام متغیر و جداکننده ویرگول است. در Variable View بررسی کنید value عددی است. در Data View، هر ردیف یک نفر است.
۲. **Analyze → Compare Means → One-Sample T Test** را باز کنید. در بعضی نسخه‌ها Compare Means and Proportions نام دارد. value را به Test Variables ببرید. در Test Value بنویسید 50 و در Options سطح فاصله را 95 بگذارید.
۳. پس از OK پنجرهٔ Output باز می‌شود. جدول One-Sample Statistics باید N=8، Mean=54 و Std. Error Mean≈1.658 داشته باشد. جدول One-Sample Test، t≈2.412، df=7 و P دوطرفه≈0.0466 می‌دهد. Mean Difference=4 یعنی ۵۴−۵۰. Lower و Upper این جدول **بازهٔ اختلاف**‌اند که از ۰٫۰۷۹ تا ۷٫۹۲۱ است.
۴. از پنجرهٔ داده با File → Save As فایل sav و از پنجرهٔ Output نتایج را با فرمت spv ذخیره کنید. اگر N=7 است، پیش از تحلیل دوباره، دادهٔ گمشده یا سطر واردنشده را پیدا کنید.

## ۲. فایل Syntax را چطور اجرا کنیم؟

در **File → Open → Syntax** فایل را باز کنید. از **Run → All** استفاده کنید. نتیجهٔ آزمون و جدول یک‌ردیفی محاسبات در Output ظاهر می‌شوند. در **Window** یا فهرست مجموعه‌های داده می‌توانید میان دادهٔ خام M17Raw و خلاصهٔ M17Summary جابه‌جا شوید. برای تمرین بعدی، کل فایل را در جلسهٔ تازه اجرا کنید تا نام مجموعه‌ها با اجرای قبلی تداخل پیدا نکند.

| خط یا بلوک تازه | چه می‌کند و کجا اثرش را می‌بینید؟ |
|---|---|
| `DATA LIST FREE /value` و `BEGIN DATA` | نام ستون را تعریف می‌کند و هشت سطر زیر آن را می‌خواند. پس از اجرا در Data View هشت عدد می‌بینید. |
| `T-TEST /TESTVAL=50 /VARIABLES=value` | یک ستون را با مرجع ۵۰ می‌سنجد. `CI(.95)` سطح بازهٔ دوطرفه است. |
| `DATASET COPY` و `DATASET ACTIVATE` | یک نسخهٔ جدا برای محاسبهٔ خلاصه می‌سازد و آن را فعال می‌کند. |
| `AGGREGATE` با `/BREAK=` | کل داده را بدون گروه‌بندی به یک ردیف تبدیل می‌کند. n_valid، mean_value و sd_value از همان هشت نفر محاسبه می‌شوند. |
| `COMPUTE` | یک ستون محاسبه‌شده می‌سازد. نخست delta=4 و se_t≈1.658، سپس stat_t≈2.412 ساخته می‌شوند. |
| `CDF.T(stat_t,df_t)` | مساحت سمت چپ t را می‌دهد. مکمل آن P راست است. برای دوطرفه، از قدر مطلق t و دو برابر یک دنباله کمک می‌گیریم. |
| `CDF.NORMAL(z_known,0,1)` | مساحت سمت چپ z در نرمال استاندارد است. برای σ=۸، z≈1.414 و P راست≈0.07865. |
| `IDF.T(.975,df_t)` | صدکِ ۰٫۹۷۵ t را می‌دهد. برای بازهٔ ۹۵٪ دوطرفه، ۲٫۵٪ در هر انتها می‌ماند. |
| `FORMATS` و `LIST` | نمایش عددها را خوانا و جدول خروجی را چاپ می‌کنند. قالب نمایش، دقت محاسبه را تعیین نمی‌کند. |

**خودتان کنترل کنید.** P دوطرفه در جدول یک‌نمونه‌ای و pt_two در خلاصه باید یکسان باشند. اگر به‌جای ۰٫۰۴۶۶ عدد ۰٫۰۲۳۳ می‌بینید، برچسب دنباله را بخوانید. [شرح خروجی و گزارش](../software-workshop.md#lesson-3)
