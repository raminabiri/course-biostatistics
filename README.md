# آموزش آمار پزشکی و زیستی

از نخستین جدول تا پژوهش پیشرفته؛ برای دانشجوی پزشکی، پیراپزشکی و علوم زیستی، متخصص و پژوهشگر.

**[شروع آموزش ←](phase-0-foundations/M01-data-and-variables/START.md)**

دانستن آمار یا کدنویسی پیش‌نیاز نیست. یک نرم‌افزار را برمی‌گزینید، یک جدول سه‌نفری می‌سازید و سپس درس‌ها را به‌ترتیب می‌خوانید. در پایان هر درس راه رفتن به درس پیش و بعد آمده است.

آموزش فارسی است؛ نام منوها و فرمان‌ها انگلیسی‌اند. همهٔ داده‌ها ساختگی‌اند. ماژول نخست چهار درس سه‌سطحی و ۱۲۰ تمرین با پاسخ جدا دارد.
