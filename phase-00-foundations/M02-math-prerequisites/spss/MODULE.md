# M02 در SPSS

[فایل فرمان سه تمرین](M02_module.sps) را با File → Open → Syntax باز کنید و Run → All را بزنید. DATA LIST نام ستون‌ها و شکل ورودی را می‌دهد. در COMPUTE، نخست دو خطر را می‌سازیم و سپس تفاضل را در ۱۰۰ ضرب می‌کنیم. `**` علامت توان است و LN لگاریتم طبیعی می‌دهد. نسبت دو لگاریتم طبیعی، پایه را از e به ۲ تبدیل می‌کند.

در LIST، diff_pp=۴، rel_pct≈۳۳٫۳۳، inc100=۵، x_mean=۶، sqsum=۱۳۴ و sumsq=۳۲۴ را پیدا کنید. برای logratio عدد منفی ۳ را وارسی کنید. اگر متغیرها را در Variable View و عبارت‌ها را از Transform → Compute Variable می‌سازید، برای دیدن مثال مرحله‌ای [راهنمای درصد](L01.md) را بخوانید.
