# حل M17-L3-3-03

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 7/√12 ≈ 2.0207` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 12-1 = 11` است.
۲. اختلاف را بر SE تقسیم کنید. `t = -1.8/2.0207 ≈ -0.8908`. برای پرسش دوطرفه مساحت `2 × P(T ≥ 0.8908)` را بخوانید. مقدار P حدود **0.3921** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.2010 است. حاصل ضرب در SE، نیمه‌عرض 4.4476 را می‌دهد. فاصلهٔ **اختلاف** `[-6.248, 2.648]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
