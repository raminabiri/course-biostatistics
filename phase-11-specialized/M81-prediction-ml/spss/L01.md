# SPSS | اعتبارسنجی مدل پیش‌بینی، کالیبراسیون و نشت داده

در Syntax بنویسید `COMPUTE brier=(p-y)**2.` سپس `DESCRIPTIVES VARIABLES=brier.` را اجرا کنید. برای ROC از Analyze → Classify → ROC Analysis استفاده کنید و حالت مثبت را y=1 و test variable را p قرار دهید. تعداد چهار نفر فقط برای تطبیق عدد مرجع است.

**خروجی مرجع:** بریر ۰٫۳۲۵، AUC برابر ۰٫۷۵ و سهم رویداد در دو دسته هر دو ۰٫۵.

محاسبهٔ مرجع با R و Python وارسی شده است. اجرای مستقیم این مسیر در نرم‌افزار در دسترس نبود.
