## آماده‌سازی و اجرا

در VS Code پوشهٔ ماژول را باز کنید و کد را در فایل py تازه بگذارید. دکمهٔ Run Python File را بزنید. خروجی در Terminal دیده می‌شود.

[اسکریپت مقایسه](M12_practice.py) را اجرا کنید. در هر اندازهٔ نمونه، mean نزدیک ۱۰ و simulated SE نزدیک theoretical SE است. عددهای نمونهٔ Python و R ممکن است از دو مولد متفاوت بیایند.

## یک خروجی ثابت برای کنترل پنج مسیر

در پوشهٔ ماژول با `import pandas as pd` شروع کنید و `d = pd.read_csv("data/M12_sample_means.csv")` را بزنید. `print(d.agg(["count","mean","std"]))` شمار معتبر، میانگین و SD نمونه‌ای هر ستون را نشان می‌دهد. این خواندن فایل ثابت از مولد اعداد تصادفی کمک نمی‌گیرد. در اسکریپت، `ddof=1` مخرج نمونه‌ای را برای std تعیین می‌کند.

[فایل ۵۰۰ تکرار](../data/M12_sample_means.csv) را باز کنید. در ستون‌های n1، n5 و n30 میانگین‌ها به‌ترتیب تقریباً ۹٫۰۱۸، ۹٫۹۶۴ و ۹٫۹۹۵ و SDها ۸٫۵۲۳، ۴٫۴۵۹ و ۱٫۸۰۱ هستند. SD هر ستون پراکندگی ۵۰۰ میانگین را برآورد می‌کند. مقدار نظری از ۱۰÷√n می‌آید. هیستوگرام ستون n1 دنبالهٔ راست بلندتری دارد و با n=۳۰ بدنه باریک‌تر می‌شود. اختلاف SD مشاهده‌شده و نظری در ۵۰۰ تکرار طبیعی است.
