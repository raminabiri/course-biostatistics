# آمار پزشکی و زیستی، از دل یک پرسش آشنا

آیا سه بار خواندن یک نمونه، سه نمونه به ما می‌دهد؟ چرا یک خانهٔ خالی، میانگین را عوض می‌کند؟ و از کجا بدانیم عددی که نرم‌افزار نشان داده، همان چیزی است که می‌خواستیم بدانیم؟

در این دوره، از چنین پرسش‌هایی آغاز می‌کنیم. نخست یک یادداشت سادهٔ درمانگاه را به جدول تبدیل می‌کنیم؛ سپس آرام‌آرام می‌شناسیم هر عدد دربارهٔ چیست و چگونه آن را بخوانیم. برای شروع، دانستن آمار یا کدنویسی پیش‌نیاز نیست.

**[آغاز با داستان سه نفر در درمانگاه ←](phase-0-foundations/M01-data-and-variables/START.md)**

آموزش فارسی است و راه کار با Excel، SPSS، GraphPad Prism، R و Python کنار هر درس آمده است. مسیر از دانشجوی پزشکی، پیراپزشکی و علوم زیستی تا متخصص و پژوهشگر ادامه پیدا می‌کند. هر درس بخش مقدماتی، متوسط و پیشرفته دارد؛ همهٔ داده‌ها ساختگی‌اند.
