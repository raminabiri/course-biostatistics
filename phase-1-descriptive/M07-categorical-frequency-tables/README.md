# ماژول M07 — داده‌های کیفی: جدول فراوانی و جدول توافقی

**فاز ۱ (آمار توصیفی)** | پیش‌نیاز: M01، M02 | زمان تقریبی: ۳ ساعت درس نظری + ۱ تا ۲ ساعت برای هر نرم‌افزار

## چرا این ماژول؟

بیشتر متغیرهای پزشکی **کیفی**اند: جنس، سیگار، واکسن، بیماری دارد/ندارد، شدت. خلاصهٔ آن‌ها ساده به نظر می‌رسد («فقط درصد بگیر»)، ولی سؤال اصلی همیشه این است: **درصدِ چه چیزی از چه چیزی؟** درصد سطری یا ستونی؟ از کل افراد یا از پاسخ‌دهندگان؟ این ماژول این سؤال‌ها را دقیق جواب می‌دهد.

## هدف‌های یادگیری

در پایان این ماژول می‌توانید:

1. جدول فراوانی با تعداد، درصد، درصد معتبر و درصد تجمعی بسازید و تفسیر کنید.
2. جدول توافقی بسازید و درصد **سطری** یا **ستونی** مناسب سؤال را انتخاب کنید.
3. نسبت‌ها را در دو گروه با تفاضل (واحد درصد) و نسبت (برابر) مقایسه کنید.
4. داده‌های کیفی را درست گزارش کنید: مخرج‌های کوچک، پرسش‌های چندپاسخی و ادغام طبقه‌ها.
5. همهٔ این‌ها را در SPSS، Prism، R، Python یا Excel انجام دهید.
