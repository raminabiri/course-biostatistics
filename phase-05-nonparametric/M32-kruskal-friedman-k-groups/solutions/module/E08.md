# M32-E08 | پرهیز از نتیجه‌گیری بیش از داده

در سطح ۰٫۰۵ شواهد نمونه برای رد برابری توزیع‌های سه دوز کافی نبود. میانهٔ دقیقه‌ها ۱۴، ۱۹ و ۲۲ است و برای قضاوت دربارهٔ بزرگی اختلاف باید نقاط خام و عدم‌قطعیت را ببینیم. آزمون معادل‌بودن از حاشیهٔ از پیش مشخص و روش استنباط مناسب استفاده می‌کند.
