# SPSS | درس عملی 3 — شیب‌های چندمتغیره

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

در Custom Model جملهٔ a*baseline را با حفظ اثرهای اصلی اضافه کنید. ردیف تعامل هم‌متغیر را جدا از a*b بخوانید.

**خروجی مرجع R و Python.** تعامل A×baseline، Pillai=0.091975 و P=0.299379.
