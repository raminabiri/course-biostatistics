# پاسخ M01-L1-E16

## پرسش

**سطح:** پیشرفته | **مخاطب:** متخصص و پژوهشگر؛ دانشجوی علاقه‌مند

برای «چند درصد بیمارستان‌ها بخش سوختگی دارند» واحد تحلیل را تعیین کنید.

## پاسخ گام‌به‌گام

بیمارستان واحد تحلیل است. فایل در سطح بیمار برای این پرسش کافی نیست، مگر ابتدا فهرست یکتای بیمارستان و ویژگی بخش ساخته شود.
