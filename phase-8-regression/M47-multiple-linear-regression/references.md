# منابع M47

- Excel، گزینهٔ Regression و ورودی Y و X را در بخش Analysis ToolPak ببینید. [Microsoft، Analysis ToolPak](https://support.microsoft.com/en-us/excel/use-the-analysis-toolpak-to-perform-complex-data-analysis)
- SPSS، فصل REGRESSION را برای Collinearity و SAVE مرور کنید. [IBM، Command Syntax Reference](https://www.ibm.com/docs/en/SSLVMB_31.0.0/pdf/IBM_SPSS_Statistics_Command_Syntax_Reference.pdf)
- Prism، شیوهٔ واردکردن پاسخ و چند توضیح‌دهنده را بخوانید. [GraphPad، Multiple Variables](https://www.graphpad.com/guides/prism/latest/user-guide/multiple-variable-tables.htm)
- Prism، فیلم مقدماتی برای مرور رگرسیون خطی. تعامل و تشخیص مدل در مسیر مکتوب توضیح داده شده‌اند. [GraphPad، مجموعهٔ فیلم‌های تحلیل](https://www.graphpad.com/series/learn-to-perform-common-statistical-analyses)
- R، معنی اهرم و فاصلهٔ Cook را در بخش Details ببینید. [R، Influence Measures](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/influence.measures.html)
- Python، مرجع خروجی برازش چندمتغیره. [NumPy، lstsq](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)
