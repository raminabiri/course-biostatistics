# SPSS | درس عملی 1 — مقایسهٔ مستقل و جهت اختلاف

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین values.csv](../data/values.csv)

[دادهٔ تمرین long.csv](../data/long.csv)

فایل long را وارد کنید. Analyze → Compare Means → Independent-Samples T Test. value را متغیر پیامد و group را گروه‌بندی بگذارید. Define Groups را با A و B پر کنید. ردیف Equal variances not assumed را بخوانید.

**خروجی مرجع R و Python.** Welch: t=1.768441 و df=13.709707.

**خودآزمایی.** اگر ترتیب را B−A بگیریم بازه و t چه تغییری می‌کنند؟
