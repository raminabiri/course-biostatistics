# M09 در Python | چهار خانه و دو مسیر مثبت

در VS Code پوشهٔ M09 را باز کنید تا پوشه‌های data و python کنار هم دیده شوند. [فایل تمرین](M09_practice.py) را با **Run Python File** اجرا کنید یا در Terminal، `python python/M09_practice.py` را بزنید. بستهٔ اضافی لازم نیست.

- `Path(__file__).resolve().parents[1]` از فایل کد به پوشهٔ ماژول می‌رسد. اگر خطای فایل پیدا نشد دارید، جای CSV را بررسی کنید.
- `csv.DictReader` از عنوان‌های CSV استفاده می‌کند. کد برای هر سطر، جفت `(reference, test)` را به عنوان کلید و `int(count)` را به عنوان شمار نگه می‌دارد. در نتیجه `counts["positive","positive"]` به ۹۰ می‌رسد. برای دیدن همهٔ خانه‌ها، موقتاً `print(counts)` را پس از خواندن فایل بگذارید.
- `tp`، `fn`، `fp` و `tn` به ترتیب مثبت واقعی، منفی کاذب، مثبت کاذب و منفی واقعی‌اند. جمع هر چهار عدد ۱۰۰۰ است. L1 جمع سه خانهٔ اجتماع را بر کل تقسیم می‌کند.
- در L2، `tp/(tp+fn)` از میان بیماران و `tp/(tp+fp)` از میان مثبت‌ها می‌شمارد. کنترل کنید خروجی‌ها ۰٫۹ و ۰٫۵ باشند.
- حلقهٔ `for prevalence in (0.01,0.10)` یک‌بار با هر شیوع کار می‌کند. در صورتِ PPV فقط سهم مثبت واقعی است. مخرج هر دو سهم مثبت را جمع می‌کند. قالب `:.4%` نسبت اعشاری را فقط هنگام چاپ به درصد تبدیل می‌کند.

خروجی با نام‌های L1 تا L3 در Terminal دیده می‌شود. برای ذخیرهٔ متن، `python python/M09_practice.py > M09_Python.txt` را اجرا کنید. [کارگاه](../software-workshop.md)
