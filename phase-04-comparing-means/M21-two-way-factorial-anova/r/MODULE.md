# M21 در R

[دادهٔ آموزشی](../data/practice.csv) ۴۰ مشاهدهٔ مستقل دارد. a، b و c سه عامل با کدهای صفر و یک‌اند. value پاسخ عددی است. از ۲۰ ردیف c=0 برای مدل دوطرفه استفاده می‌کنیم.

## اجرا و فهم فرمول

از RStudio، [اسکریپت](M21_workshop.R) را باز و پوشهٔ ماژول را از Session → Set Working Directory انتخاب کنید. Source را بزنید. در ترمینال از همان پوشه `Rscript --vanilla r/M21_workshop.R` را اجرا کنید.

```r
d <- read.csv("data/practice.csv")
sub <- subset(d, c == 0)
fit <- lm(value ~ factor(a) * factor(b), data = sub)
anova(fit)
```

`subset` فقط ردیف‌های شرط را نگه می‌دارد. `==` شرط برابری است. `factor` صفر و یک را برچسب گروه می‌کند. در فرمول R، `a*b` به معنای a و b و a:b است. `lm` مدل را برازش می‌کند و `anova` جدول F می‌دهد. در L2 کارگاه `tapply` مشاهده‌ها را با کد A گروه‌بندی می‌کند و برای هر گروه `mean` را اجرا می‌کند. `diff` مقدار دوم را از نظر ترتیب منهای مقدار نخست می‌کند، ۴۹ منهای ۴۲.

با سه عامل، `factor(a)*factor(b)*factor(c)` اثرهای اصلی و تمام تعامل‌ها را وارد مدل می‌کند. ردیف سه‌طرفه را در L3 پیدا کنید. اگر بعداً داده نامتوازن بود، نوع مجموع مربعات را در گزارش ذکر کنید. جدول معمول `anova(lm(...))` از مجموع مربعات ترتیبی استفاده می‌کند.

## کنترل نتیجه

با C0، تعامل A×B برابر ۴ واحد و F(۱،۱۶)=۸ با P≈۰٫۰۱۲۱۱ است. اثر سادهٔ A در B1 برابر ۷ واحد است. در دادهٔ کامل، تعامل A×B×C برابر ۲ واحد و F(۱،۳۲)=۰٫۴ با P≈۰٫۵۳۱۵۸ است.
