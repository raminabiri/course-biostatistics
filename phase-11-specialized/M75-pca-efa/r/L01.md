# R | تحلیل مؤلفه‌های اصلی برای خلاصه‌سازی داده

ترمینال را در پوشهٔ ماژول باز کنید و دستور زیر را اجرا کنید. فایل داده باید در پوشهٔ data بماند.

```bash
Rscript --vanilla r/M75_L1.R
```

`prcomp` مؤلفه‌ها را برازش می‌کند. `scale.=TRUE` ستون‌ها را استاندارد می‌کند. `sdev` انحراف معیار نمره‌های مؤلفه و `x` نمرهٔ هر فرد است.

**خروجی مرجع:** مقدارهای ویژهٔ حدود ۱٫۷۰۷ و ۰٫۲۹۳، و سهم مؤلفهٔ اول ۸۵٫۳۶٪.
