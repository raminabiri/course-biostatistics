## پرسش

**سطح:** ساده | **مخاطب:** دانشجوی پزشکی، پیراپزشکی و علوم زیستی

پتاسیم سرم (mmol/L) هشت بیمار: `4.2, (خالی), 5.1, -99, 3.9, 4.8, -99, 5.0`. کد ‎-99 یعنی «اندازه‌گیری نشد».
(الف) n معتبر چند است؟ (ب) میانگین درست؟ (ج) اگر نرم‌افزار خانهٔ خالی را کنار بگذارد ولی ‎-99 را عدد حساب کند، چه میانگینی می‌دهد؟

## پاسخ گام‌به‌گام

- **(الف)** مقادیر معتبر: 4.2، 5.1، 3.9، 4.8، 5.0 ← **n = 5** (از ۸).
- **(ب)** مجموع = 23.0 ← میانگین = 23.0 / 5 = **4.60 mmol/L**.
- **(ج)** ۷ مقدار حساب می‌شود: مجموع = 23.0 + (−99) + (−99) = −175 ← میانگین = −175 / 7 = **−25.0** (پتاسیم منفی!).
