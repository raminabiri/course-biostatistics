# M17 با Python | راهنمای خواندن کد و خروجی

در VS Code از **File → Open Folder** پوشهٔ M17 را باز کنید و همان مفسر M01 را انتخاب کنید. در **Terminal → New Terminal** با `python -c "import scipy"` بررسی کنید SciPy نصب است. اگر دستور با ModuleNotFoundError ایستاد، `python -m pip install scipy` را در همان ترمینال اجرا کنید. اگر در M01 از python3 استفاده کرده‌اید، اینجا هم همان نام را بنویسید. [فایل Python](M17_workshop.py) را باز کنید و **Run Python File** را بزنید یا `python python/M17_workshop.py` را در ترمینال اجرا کنید.

## خواندن داده

۱. `Path(__file__)` نشانی همین فایل Python است. `resolve().parents[1]` از فایل، یک سطح به پوشهٔ python و سطح بعد به ماژول M17 می‌رسد. سپس با نشانهٔ `/` بخش‌های `data` و `values.csv` به نشانی افزوده می‌شوند.
۲. `with data_path.open(...)` فایل را در زمان خواندن باز نگه می‌دارد و پس از پایان بلوک آن را می‌بندد. `csv.DictReader(source)` هر ردیف را بر اساس عنوان ستون‌ها می‌خواند. `row["value"]` متن زمان همان ردیف است.
۳. `[float(row["value"]) for row in ...]` یعنی برای هر ردیف، زمان را به عدد اعشاری تبدیل کن و در فهرست `x` بگذار. بخش `if` پیش از آزمون تعداد و معتبر بودن عددها را کنترل می‌کند. برای دیدن داده‌ها می‌توانید پس از این بخش، در یک نسخهٔ تمرینی `print(x)` اضافه کنید.

## تحلیل و چاپ

| فرمان یا نشانه | به زبان ساده |
|---|---|
| `from scipy import stats` | بخش آماری SciPy را آمادهٔ استفاده می‌کند. در کد، نقطه بعد از stats یعنی تابع در همین بخش قرار دارد. |
| `mean(x)`، `stdev(x)` و `len(x)` | میانگین، SD نمونه‌ای و تعداد زمان‌ها را می‌دهند. `sqrt(n)` جذر n را می‌گیرد. |
| `stats.ttest_1samp(x, popmean=target)` | داده‌های یک نمونه و میانگین فرض صفر را می‌گیرد. حالت پیش‌فرض دوطرفه است. شیء fit آماره، df و P را نگه می‌دارد. |
| `stats.norm.sf(z)` | sf مساحت سمت راست است. `cdf` مساحت چپ را می‌دهد. در آزمون t همین دو روش روی `stats.t` به df هم نیاز دارند. |
| `fit.confidence_interval()` | کران‌های فاصلهٔ میانگین را می‌دهد. `mean_ci.low` کران پایین است و با کم کردن target از هر کران، بازهٔ اختلاف را می‌گیریم. |
| `f"...{fit.pvalue:.6f}"` | مقدار P را در متن جای‌گذاری می‌کند و شش رقم اعشار نشان می‌دهد. شیوهٔ چاپ، عدد ذخیره‌شده را گرد نمی‌کند. |

**کنترل خروجی.** L1 باید N=8، میانگین ۵۴ و t≈۲٫۴۱۲ داشته باشد. در L2، z≈۱٫۴۱۴ و P راست≈۰٫۰۷۸۶۵ است. در L3، `mean_ci` با `difference_ci` متفاوت است و فاصلهٔ دوم از هر کران اول ۵۰ کمتر است. اگر FileNotFoundError آمد، پوشهٔ data و نام فایل را بررسی کنید. اگر خواستید خروجی را نگه دارید، در ترمینال `python python/M17_workshop.py > M17_Python_output.txt` را بزنید.
