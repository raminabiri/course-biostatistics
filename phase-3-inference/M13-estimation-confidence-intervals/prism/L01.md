# Prism | درس عملی 1 — فاصلهٔ میانگین

## آماده‌سازی

برای شروع از File → New Project استفاده کنید. در جدول XY، X محل نقطه و Y ورودی تبدیل است. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

در Prism 11، جدول XY باز کنید. در X و Y مقدار ۵۰ بگذارید. از Analyze → Transform، تبدیل کاربر Y را با `Y=Y-TINV(0.05,24)*2` انجام دهید. تبدیل جدا با +، بالا را می‌دهد. Results را بخوانید.

**خروجی برای مقایسه.** فاصله حدود [۴۵٫۸۷، ۵۴٫۱۳] دقیقه.

**خودآزمایی.** اگر n چهار برابر شود اما SD همان ۱۰ باشد، SE چند می‌شود؟
