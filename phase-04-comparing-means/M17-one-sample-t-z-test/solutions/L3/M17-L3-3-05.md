# حل M17-L3-3-05

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 5/√14 ≈ 1.3363` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 14-1 = 13` است.
۲. اختلاف را بر SE تقسیم کنید. `t = 0/1.3363 ≈ 0.0000`. برای پرسش چپ مساحت `P(T ≤ 0.0000)` را بخوانید. مقدار P حدود **0.5000** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.1604 است. حاصل ضرب در SE، نیمه‌عرض 2.8869 را می‌دهد. فاصلهٔ **اختلاف** `[-2.887, 2.887]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
