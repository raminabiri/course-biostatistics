# R | درس عملی 3 — کنتراست از پیش تعیین‌شده

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

اسکریپت R را اجرا کنید. خط L3 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

[فایل کد](../r/M20_workshop.R) را باز کنید. در جدول Tukey هر سطر یک تفاضل و ستون `p adj` مقدار تعدیل‌شدهٔ همان سطر است.

**خروجی مرجع R و Python.** روند C−A=8.8 و P تعدیل‌شدهٔ Tukey برای C−A حدود 0.001694.

**خودآزمایی.** اگر همهٔ میانگین‌ها ۴ واحد زیاد شوند چرا کنتراست روند ثابت می‌ماند؟
