# Prism | درس عملی 3 — تفاضل و جهت

## آماده‌سازی

برای شروع از File → New Project استفاده کنید. در جدول XY، X محل نقطه و Y ورودی تبدیل است. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

در Prism 11، جدول XY با Y=4 باز کنید. از Transform و User-defined Y transform برای `Y=Y-TINV(0.05,43)*sqrt(7.2)` کمک بگیرید. برای کران بالا + بگذارید. ۴۳ درجهٔ آزادی گرد شده است.

**خروجی برای مقایسه.** فاصلهٔ Welch حدود [−۱٫۴۱، ۹٫۴۱] دقیقه.

**خودآزمایی.** اگر B−A را بخواهیم، با بازه چه می‌کنیم؟
