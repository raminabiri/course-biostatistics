# M03 در SPSS

[فایل Syntax](M03_module.sps) را باز کنید. دو فرمان GET DATA از مسیر نسبی data بهره می‌گیرند. رو به‌روی FILE، مسیر کامل دو CSV را وارد کنید اگر SPSS در پوشهٔ ماژول نیست. Run → All را بزنید. SORT CASES کل ردیف را بر اساس u و سپس id مرتب می‌کند.

TEMPORARY باعث می‌شود شرط SELECT IF فقط برای فرمان بعدی اعمال شود. پس جدول فهرست ده ردیف و خلاصهٔ نمونه از یک چارچوب یکسان می‌آیند. میانگین htn، سهم کد ۱ است. جدول پایانی ID و program را نشان می‌دهد. program=۱ برای ۳ و ۲ است.
