# SPSS | فاکتور بیز، آزمون t و رگرسیون بیزی

در File → New → Syntax فرمان زیر را اجرا کنید. CDF لازم نیست، چون احتمال دقیقاً هفت پاسخ را می‌خواهیم.
```spss
DATA LIST FREE / k n.
BEGIN DATA
7 10
END DATA.
COMPUTE null=PDF.BINOM(k,n,.5).
COMPUTE alt=1/(n+1).
COMPUTE bf=alt/null.
LIST VARIABLES=null alt bf.
```

**خروجی مرجع:** BF10 حدود ۰٫۷۷۶ و احتمال پسین مدل جایگزین حدود ۰٫۴۳۷.

محاسبهٔ مرجع با R و Python وارسی شده است. اجرای مستقیم این مسیر در نرم‌افزار در دسترس نبود.
