# R | کالیبراسیون، حد تشخیص و تکرارپذیری

ترمینال را در پوشهٔ ماژول باز کنید و دستور زیر را اجرا کنید. فایل داده باید در پوشهٔ data بماند.

```bash
Rscript --vanilla r/M73_L1.R
```

`coef` دو ضریب را به‌ترتیب عرض از مبدأ و شیب می‌گیرد. `unname` نام درونی ضریب را حذف می‌کند تا نام ستون خروجی همان برچسب آموزشی باشد.

**خروجی مرجع:** شیب ۳، غلظت نمونه ۳٫۵، حد تشخیص ۰٫۳۳ و حد اندازه‌گیری ۱.
