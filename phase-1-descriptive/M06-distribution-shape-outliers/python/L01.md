# درس عملی 1 — چارک و قرارداد محاسبه

هفت انتظار مرتب ۱۰، ۱۱، ۱۲، ۱۳، ۱۴، ۱۵ و ۴۰ دقیقه داریم.

## ورود داده و اجرا

در VS Code فایل py تازه بسازید. همان مفسر تمرین M01 را انتخاب و کد را در فایل اجرا کنید.

`from statistics import median, quantiles`؛ `x = [10,11,12,13,14,15,40]`. `print(median(x[:3]),median(x[4:]),quantiles(x,method="inclusive"))` را اجرا کنید. اندیس ۳ جای میانه است.

## خواندن خروجی و خودآزمایی

میانه ۱۳ است. در تمرین میانهٔ نیمه‌ها، خود ۱۳ را کنار می‌گذاریم. میانهٔ ۱۰،۱۱،۱۲ برابر ۱۱ و میانهٔ ۱۴،۱۵،۴۰ برابر ۱۵ است. با درون‌یابی type 7، Q1=11.5 و Q3=14.5.

پیش از مقایسهٔ دو نرم‌افزار، قرارداد را همسان کنید. اختلاف چارک به‌تنهایی نشانهٔ خطای ورود داده نیست.
