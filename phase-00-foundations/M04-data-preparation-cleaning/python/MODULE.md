# M04 در Python

از پوشهٔ ماژول اجرا کنید `python3 python/M04_module.py`. فایل از کتابخانهٔ استاندارد بهره می‌گیرد. `setdefault` برای شناسه‌ای که هنوز در دیکشنری نیست فهرست تازه می‌سازد و اندازه‌گیری را با append به آن اضافه می‌کند. برای شناسهٔ بدون آزمایش، میانگین محاسبه نمی‌شود و مقدار None است. فشار −۹۹ و متن خالی هم در خروجی نشانهٔ گمشدگی دارند. خط دوم ۱۶۸ و ۲۶٫۰۴ و خط سوم None برای LDL دارد.
