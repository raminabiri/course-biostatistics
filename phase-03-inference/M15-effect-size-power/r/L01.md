# R | درس عملی 1 — اثر خام و استاندارد

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

در اسکریپت L1، SD ترکیبی و ضریب J را بخوانید.

[فایل کد](../r/M15_workshop.R) را باز کنید. ضریب J در فرمول g روی d ضرب می‌شود.

**خروجی برای مقایسه.** d=۰٫۵ و g≈۰٫۴۹۰.

**خودآزمایی.** اگر همان اختلاف در مقیاسی با SD برابر ۴ به دست آید، d چگونه عوض می‌شود؟
