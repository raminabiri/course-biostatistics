## مسیر R

۱. در RStudio، پوشهٔ همین ماژول را به عنوان Working Directory انتخاب کنید. از `Session → Set Working Directory → Choose Directory` کمک بگیرید. در Console، با `getwd()` مطمئن شوید نام آخر پوشه با M10 شروع می‌شود و با `list.files()` وجود پوشهٔ r را ببینید.
۲. از `File → Open File` فایل [تمرین R](r/M10_practice.R) را باز کنید. فایل را در جای فعلی نگه دارید تا مسیر داده و شکل‌ها برقرار باشد.
۳. در Console فرمان `source("r/M10_practice.R")` را وارد کنید و Enter بزنید. برای دیدن یک فرمان در لحظه، نشانگر را روی خط مربوطه بگذارید و Run را بزنید. خط خواندن داده یا تعریف متغیر را اول اجرا کنید.
۴. L1 شامل ۰٫۲۰۴۸ و ۰٫۲۶۲۷۲، L2 شامل حدود ۰٫۱۳۵۳ و ۰٫۲۵ و L3 برابر ۰٫۳ است. برای نگهداری متن خروجی، آن را از Console به یک فایل متنی منتقل کنید.

## مسیر Python

۱. در VS Code با `File → Open Folder` پوشهٔ همین ماژول را باز کنید. همان مفسر Python که در M01 انتخاب کردید به کار می‌رود. فایل [تمرین Python](python/M10_practice.py) را باز کنید.
۲. کد با امکانات خود Python اجرا می‌شود و بستهٔ تازه‌ای لازم ندارد.
۳. دکمهٔ `Run Python File` بالای فایل را بزنید یا در ترمینالِ پوشهٔ ماژول، `python python/M10_practice.py` را اجرا کنید. پاسخ‌ها در Terminal ظاهر می‌شوند و شکل‌های Python، در درس‌های دارای شکل، در پوشهٔ ماژول ذخیره می‌شوند.
۴. اگر `ModuleNotFoundError` دیدید، اول مفسر انتخاب‌شده و مفسر ترمینال را یکی کنید. اگر فایل داده پیدا نشد، مطمئن شوید پوشهٔ data را همراه فایل برنامه دارید. خطوط چاپ‌شده را با خروجی مورد انتظار درس مقایسه کنید.

## پیش از کار در Excel، SPSS یا Prism

- **Excel.** برای CSV، یک کارپوشهٔ خالی باز کنید. از `Data → From Text/CSV` فایل را انتخاب کنید، در پیش‌نمایش Delimiter را Comma بگذارید و Load را بزنید. هر ستون باید جدا دیده شود. اگر فرمول با ویرگول پذیرفته نشد، جداکنندهٔ آرگومان را مطابق تنظیم Excel خود عوض کنید. در پایان با `File → Save As` یک نسخهٔ xlsx ذخیره کنید.
- **SPSS.** از `File → Import Data → CSV Data` فایل را انتخاب کنید. سطر اول نام متغیرهاست و جداکننده ویرگول است. پس از وارد کردن، ستون‌های عددی را در Variable View بررسی کنید. از `File → Save As` برای ذخیرهٔ دادهٔ sav و از پنجرهٔ Output برای ذخیرهٔ نتایج spv کمک بگیرید.
- **Prism.** از `File → New Project` شروع کنید. نوع جدول را طبق تمرین انتخاب کنید. هنگام انتقال جدول از CSV، عنوان ستون‌ها را جدا از خانه‌های عددی بگذارید. نتیجهٔ تحلیل در Results و نمودار در Graphs دیده می‌شود. از `File → Save As` برای ذخیرهٔ پروژه کمک بگیرید.

اگر درس دادهٔ آماده ندارد، جدول جدید بسازید و عددهای خود درس را وارد کنید. در SPSS برای تمرین‌های محاسباتیِ بدون فایل، می‌توانید `File → New → Syntax` را باز کنید، دستورهای داده‌شده را منتقل کنید و `Run → All` را بزنید.

## Excel

۱. **درس ۱۰.۱.** در یک برگهٔ خالی، در A1 بنویسید `=BINOM.DIST(2,5,0.2,FALSE)`. در A2 بنویسید `=1-BINOM.DIST(1,5,0.2,TRUE)`. FALSE احتمال دقیقاً دو و TRUE تا یک را می‌دهد. A1 باید ۰٫۲۰۴۸ شود.
۲. **درس ۱۰.۲.** در A3، `=POISSON.DIST(0,2,FALSE)` و در A4، `=NEGBINOM.DIST(1,2,0.5,FALSE)` را بگذارید. اولی شمار صفر در بازه و دومی شمار یک شکست پیش از دومین موفقیت است.
۳. **درس ۱۰.۳.** در A5، `=HYPGEOM.DIST(2,4,3,10,FALSE)` را وارد کنید. ورودی‌ها به‌ترتیب موفق‌های نمونه، اندازهٔ نمونه، موفق‌های جامعه و اندازهٔ جامعه‌اند. نتیجه ۰٫۳ است.

## SPSS

در یک Syntax تازه، این قطعه را وارد کنید. پس از Run All، در Data View یک سطر با نتایج هر سه درس می‌بینید. ستون‌های bin_exact و bin_tail برای درس اول، pois_zero و nb_one برای درس دوم و hypo_two برای درس سوم‌اند.

```spss
DATA LIST FREE / seed_value.
BEGIN DATA
1
END DATA.
COMPUTE bin_exact=PDF.BINOM(2,5,.2).
COMPUTE bin_tail=1-CDF.BINOM(1,5,.2).
COMPUTE pois_zero=PDF.POISSON(0,2).
COMPUTE nb_one=2*.5**3.
COMPUTE hypo_two=(3*21)/210.
FORMATS bin_exact bin_tail pois_zero nb_one hypo_two (F9.5).
EXECUTE.
```

## Prism

در هر گام یک جدول XY بسازید. برای تبدیل ستون Y، از `Analyze → Transform` و سپس User-defined Y transform کمک بگیرید. جواب در Results ظاهر می‌شود.

۱. **درس ۱۰.۱.** Y را ۱۰ بگذارید و `Y=Y*0.2^2*0.8^3` را اعمال کنید. ۱۰ شمار راه‌های انتخاب دو جایگاه از پنج جایگاه است.
۲. **درس ۱۰.۲.** دو ستون Y بسازید یا دو جدول جدا باز کنید. برای صفر تماس، Y=2 را با `Y=exp(-Y)` تبدیل کنید. برای یک شکست، Y=0.5 را با `Y=2*Y^3` تبدیل کنید.
۳. **درس ۱۰.۳.** Y=63 را با `Y=Y/210` تبدیل کنید. ۶۳ انتخاب‌های دارای دقیقاً دو علامت‌دار و ۲۱۰ همهٔ چهارتایی‌هاست. پنج خروجی را با متن درس مقایسه کنید.
