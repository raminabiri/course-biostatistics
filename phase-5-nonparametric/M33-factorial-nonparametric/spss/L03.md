# SPSS | درس عملی 3 — تعدیل رتبه‌ای

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

ابتدا b=0 را فیلتر کنید. با Rank Cases دو رتبه بسازید. از Linear Regression، رتبهٔ value را روی رتبهٔ baseline برازش دهید و در Save ماندهٔ Unstandardized را درخواست کنید. روی آن مانده، One-Way ANOVA را با گروه a اجرا کنید.
