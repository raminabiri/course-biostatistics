# حل M17-L3-3-02

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 6/√11 ≈ 1.8091` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 11-1 = 10` است.
۲. اختلاف را بر SE تقسیم کنید. `t = -2.7/1.8091 ≈ -1.4925`. برای پرسش چپ مساحت `P(T ≤ -1.4925)` را بخوانید. مقدار P حدود **0.0832** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.2281 است. حاصل ضرب در SE، نیمه‌عرض 4.0309 را می‌دهد. فاصلهٔ **اختلاف** `[-6.731, 1.331]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
