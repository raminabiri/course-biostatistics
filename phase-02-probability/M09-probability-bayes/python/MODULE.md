# M09 در Python

از پوشهٔ ماژول اجرا کنید `python3 python/M09_module.py`. Counter هر زوج جمعیت و کد را می‌شمارد. سپس برای هر جمعیت شمار چهار کد به ترتیب ساخته می‌شود. در Python اندیس low[0] خانهٔ اول است. آن را بر مجموع همان خانه و low[2] تقسیم می‌کنیم. مشاهده کنید که نتیجهٔ ۰٫۰۸۳۳۳۳ به معنی ۸٫۳۳٪ است.
