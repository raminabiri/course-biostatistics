# R | تحلیل تشخیصی خطی، همبستگی کانونی و تحلیل تناظر

ترمینال را در پوشهٔ ماژول باز کنید و دستور زیر را اجرا کنید. فایل داده باید در پوشهٔ data بماند.

```bash
Rscript --vanilla r/M78_L1.R
```

`tapply` میانگین را بر حسب گروه محاسبه می‌کند. `correct=FALSE` اصلاح پیوستگی را برای محاسبهٔ پیرسون کنار می‌گذارد. برای CCA چندستونی `cancor(X,Y)` و برای LDA عمومی تابع `MASS::lda` را ببینید.

**خروجی مرجع:** مرز ۴، همبستگی کانونی آموزشی ۱ و اینرسی ۰٫۲۵.
