# SPSS | کالیبراسیون، حد تشخیص و تکرارپذیری

CSV را از File → Import Data وارد کنید و در Syntax اجرا کنید:
```spss
REGRESSION /DEPENDENT signal /METHOD=ENTER x.
```
عرض از مبدأ را از Constant و شیب را از سطر x در ستون Unstandardized B بگیرید. برای محاسبهٔ حدود در یک مجموعه‌دادهٔ تمرینی جدا، فرمان `COMPUTE concentration=(12.5-2)/3.` و فرمول‌های درس را به کار ببرید. عددهای ۲ و ۳ از همین خط‌اند.

**خروجی مرجع:** شیب ۳، غلظت نمونه ۳٫۵، حد تشخیص ۰٫۳۳ و حد اندازه‌گیری ۱.

محاسبهٔ مرجع با R و Python وارسی شده است. اجرای مستقیم این مسیر در نرم‌افزار در دسترس نبود.
