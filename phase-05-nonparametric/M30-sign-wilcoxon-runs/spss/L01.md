# SPSS | درس عملی 1 — علامت اختلاف

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

در Compute Variable، diff=after-before و positive=(diff>0) را بسازید. صفر را از آزمون کنار بگذارید. از Nonparametric Tests → Legacy Dialogs → 2 Related Samples و Sign کمک بگیرید.
