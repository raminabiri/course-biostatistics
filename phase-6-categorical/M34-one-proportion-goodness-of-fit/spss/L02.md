# spss | آزمون z یک نسبت

## ورود داده

[CSV مشترک](../data/M34_practice.csv) را دریافت کنید. فایل را با File → Import Data → CSV Data باز کنید. سطر نخست نام متغیرهاست. در Variable View، on_time را Numeric و route را String کنترل کنید. برای فرمان‌ها File → New → Syntax و Run → All را بزنید.

## اجرا و دلیل هر گام

با شمارهای درس پیش، دستور `COMPUTE z = (.60-.50)/SQRT(.5*.5/100).` و سپس `COMPUTE p_right = 1-CDF.NORMAL(z,0,1).` و `COMPUTE p_two = 2*(1-CDF.NORMAL(ABS(z),0,1)).` را اجرا کنید. با EXECUTE عددها در Data View دیده می‌شوند. ۰ و ۱ در CDF.NORMAL میانگین و SD نرمال استانداردند.

## کنترل و تمرین

z=۲، P راست ≈۰٫۰۲۲۷۵ و دوطرفه ≈۰٫۰۴۵۵. اگر عدد فرق کرد، نخست شمار سطرهای معتبر، ترتیب رده‌ها و جهت دنباله را کنترل کنید. نتیجه را در یک جمله برای سؤال درس بنویسید.
