# تمرین M07 با R

[پرسش‌های عملی](../practice.md) را باز کنید و از پوشهٔ همین راهنما فرمان `Rscript --vanilla M07_solutions.R` را اجرا کنید. اسکریپت با R پایه کار می‌کند.

`table()` شمارها و `prop.table(t, 1)` سهم هر خانه از سطر را به دست می‌دهد. با آرگومان `2` مخرج جمع ستون است. در جدول واکسن، پاسخ‌های خالی را جدا بشمارید و مخرج معتبر را از جمع جدول دوطرفه بخوانید. خروجی را با [پاسخ‌ها](../review.md) بسنجید.
