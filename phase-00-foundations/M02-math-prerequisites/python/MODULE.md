# M02 در Python

از پوشهٔ ماژول اجرا کنید `python3 python/M02_module.py`. برای این فایل هیچ بستهٔ اضافه‌ای لازم نیست.

`sum(v**2 for v in x)` مربع هر عضو را در جمع وارد می‌کند. در `sum(x)**2` مربع پس از جمع گرفته می‌شود. اندیس در Python از صفر شروع می‌شود، پس `table[1]` سطر دوم است. `range(4)` مقدارهای ۰ تا ۳ می‌دهد. `log2` برای نسبت نهایی پایهٔ دو را به کار می‌برد. دیکشنری answers نام هر مقدار را کنار آن چاپ می‌کند تا ترتیب خروجی گم نشود.
