# Python | درس 2 — خطای استاندارد میانگین

یک مدل انتظار با میانگین و SD برابر ۱۰ دقیقه داریم. اگر n=25 باشد، میانگین یک نمونه از نمونهٔ بعدی چقدر نوسان دارد؟

## آماده‌سازی و اجرا

در VS Code پوشهٔ ماژول را باز کنید و کد را در فایل py تازه بگذارید. دکمهٔ Run Python File را بزنید. خروجی در Terminal دیده می‌شود.

`print(10/25**.5, x.std(ddof=1), 10/5**.5)` را بزنید. ddof=1 برای پراکندگی نمونه‌ای است. عدد دوم از n=5 و عدد اول از n=25 می‌آید.

## کنترل و گزارش

SE با n=25 برابر ۲ و با n=5 حدود ۴٫۴۷ است.

**خودآزمایی.** اگر فقط تعداد تکرارها را زیاد کنیم و n هر نمونه تغییر نکند، کدام پراکندگی عوض می‌شود؟

<summary>حل تشریحی</summary>

SE نظری ثابت است. شکل تجربی و برآورد SE معمولاً پایدارتر می‌شوند. تعداد تکرار مدل نمایش را دقیق‌تر می‌کند و n اندازهٔ نمونه توزیع میانگین را تغییر می‌دهد.
