# نخستین فرمان و جدول در Python

**سطح:** نخستین آشنایی · **مخاطب:** خوانندهٔ بدون پیشینهٔ کدنویسی

## ۱. Python چیست و کجا بنویسیم؟

Python زبانی برای دادن فرمان به کامپیوتر است. برای نوشتن و اجرای فرمان، خود Python باید نصب باشد. یک برنامهٔ ویرایش نوشته نیز لازم داریم؛ در این راهنما VS Code را برمی‌گزینیم. نام Python با نام VS Code یکی نیست: اولی فرمان‌ها را اجرا می‌کند، دومی جای نوشتن و دیدن خروجی است.

اگر نصب نیستند، [Python](https://www.python.org/downloads/) و [VS Code](https://code.visualstudio.com/) را از صفحهٔ رسمی بگیرید. در نصب Python روی ویندوز، اگر گزینهٔ افزودن Python به PATH دیده می‌شود آن را روشن کنید. در لینوکس بستهٔ Python توزیع خود را بررسی کنید؛ نصب آن با ویندوز یکسان نیست. سپس در VS Code بخش Extensions را باز کرده و افزونهٔ **Python از Microsoft** را نصب کنید.

## ۲. نخستین فایل فرمان

۱. روی کامپیوتر پوشه‌ای با نام `biostat-start` بسازید.
۲. در VS Code، `File > Open Folder` را بزنید و همان پوشه را برگزینید.
۳. از `File > New Text File` یک فایل تازه بسازید و با نام `first_table.py` در آن پوشه ذخیره کنید. پسوند py یعنی نوشتهٔ فرمان Python.
۴. Ctrl+Shift+P را بزنید؛ این پنجره برای پیدا کردن فرمان‌های VS Code است. عبارت `Python: Select Interpreter` را بنویسید و Python نصب‌شده را برگزینید. Interpreter همان برنامه‌ای است که کد را اجرا می‌کند.
۵. داخل فایل فقط این خط را بنویسید:

```python
print(2 + 3)  # نمایش نتیجه در خروجی
```

روی دکمهٔ مثلثی `Run Python File` بزنید؛ اگر چند گزینه دارد، اجرای فایل در Terminal را برگزینید. در پایین صفحه خروجی ۵ را می‌بینید. `print` یعنی نتیجه را روی صفحه نشان بده. کدهای این راهنما را در فایل py بنویسید؛ فرمان‌های بخش نصب بسته، جای دیگری دارند که پایین‌تر گفته می‌شود.

## ۳. یک نام به یک مقدار بدهیم

خط پیشین را نگه دارید و این دو خط را زیر آن بنویسید:

```python
age = 24  # نگه‌داشتن سن با یک نام
print(age)  # نمایش نتیجه در خروجی
```

فایل را ذخیره و دوباره اجرا کنید. این بار ۵ و ۲۴ چاپ می‌شوند. `=` یعنی مقدار سمت راست با نام سمت چپ نگه داشته شود. age نامی است که خودمان برگزیده‌ایم. age و Age یک نام نیستند.

سه سن را در یک فهرست می‌گذاریم:

```python
ages = [24, 51, 38]  # نگه‌داشتن سه سن کنار هم
print(ages)  # نمایش نتیجه در خروجی
```

کروشه‌های `[` و `]` مرز فهرست‌اند. ویرگول، مقدارها را از هم جدا می‌کند. خروجی `[24, 51, 38]` است. هنوز بستهٔ افزوده‌ای لازم نداریم.

## ۴. نخستین جدول، بدون نصب بسته

برای آغاز، جدول را با ابزار همراه Python می‌سازیم. کد زیر را به فایل بیفزایید؛ فاصلهٔ ابتدای خط‌های زیر `with` را نگه دارید:

```python
import csv  # آماده‌کردن ابزار لازم
from pathlib import Path  # آماده‌کردن ابزار لازم

rows = [  # سه سطر، هر سطر یک نفر
    [1, 24, 36.8],
    [2, 51, 37.2],
    [3, 38, 38.1],
]

folder = Path(__file__).resolve().parent  # پوشهٔ فایل کد
file = folder / "my_first_table.csv"  # نام و مسیر فایل خروجی
with file.open("w", newline="", encoding="utf-8") as stream:  # بازکردن فایل برای این بخش
    writer = csv.writer(stream)  # آماده‌کردن ابزار نوشتن CSV
    writer.writerow(["patient_id", "age", "temperature"])  # نوشتن یک سطر در فایل
    writer.writerows(rows)  # نوشتن سطرهای داده در فایل

print(file)  # نمایش نتیجه در خروجی
```

توضیح کوتاه کنار هر فرمان آمده است. خط‌های زیر `with` چهار فاصله جلوتر نوشته می‌شوند؛ این فاصله‌ها مرز بخش نوشتن فایل‌اند.

فایل را اجرا کنید. کنار first_table.py باید `my_first_table.csv` ساخته شود. روی آن در فهرست فایل‌های VS Code بزنید. سطر نخست عنوان است و سه سطر بعد داده‌اند. این فایل را در Excel نیز می‌توان باز کرد.

## ۵. فایل را دوباره بخوانیم

زیر کد بالا بنویسید:

```python
with file.open(newline="", encoding="utf-8") as stream:  # بازکردن فایل برای این بخش
    table = list(csv.DictReader(stream))  # خواندن سطرها با نام ستون

print(table)  # نمایش نتیجه در خروجی
print(table[1]["age"])  # نمایش نتیجه در خروجی
```

`DictReader` هر سطر را با نام ستون‌ها می‌خواند. شماره‌گذاری فهرست Python از صفر آغاز می‌شود؛ `table[1]` سطر نفر دوم است. خروجی خط آخر باید `51` باشد. ابزار csv این مقدار را به صورت متن خوانده است؛ در این گام فقط آن را می‌خوانیم. برای محاسبهٔ عددی، تبدیل نوع لازم است که در درس‌های بعد یاد می‌گیریم.

## ۶. آشنایی آرام با pandas؛ گام بعدی و اختیاری

pandas بسته‌ای افزوده برای کار با جدول است. DataFrame نام جدول در آن است. اکنون می‌دانید فایل و سطر و ستون چیست؛ می‌توانیم همین فایل را به یک DataFrame بخوانیم.

در VS Code از Ctrl+Shift+P، فرمان `Python: Create Terminal` را اجرا کنید. **Terminal** جای فرمان‌های سیستم است، نه نوشتهٔ داخل فایل py. اگر نشان `>>>` می‌بینید در محیط گفت‌وگوی Python هستید؛ با `exit()` از آن بیرون بیایید. در Terminal بنویسید:

```bash
python -m pip install pandas
```

اگر Python انتخاب‌شده روی لینوکس با نام python3 اجرا می‌شود، به جای python بنویسید python3. اگر پیام محیط مدیریت‌شده یا نداشتن دسترسی نصب آمد، فایل‌های سیستم را دست‌کاری نکنید؛ در VS Code فرمان `Python: Create Environment` و سپس Venv را برگزینید، Python را تعیین کنید، پنجرهٔ Terminal تازه باز کنید و نصب را در همان محیط انجام دهید. Venv پوشه‌ای برای بسته‌های همین کار است. در گام‌های ۱ تا ۵ اصلا به pandas نیاز نداشتیم؛ گیرکردن در نصب نباید جلوی درس نخست را بگیرد.

اکنون این سه خط را **داخل فایل py** بیفزایید و فایل را با همان Python اجرا کنید:

```python
import pandas as pd  # آماده‌کردن ابزار لازم
patients = pd.read_csv(file)  # خواندن فایل و ساخت جدول
print(patients)  # نمایش نتیجه در خروجی
```

`as pd` نام کوتاه برای pandas است؛ `read_csv` فایل را می‌خواند. در سمت چپ جدول چاپ‌شده شماره‌های ۰،۱،۲ را می‌بینید؛ آن‌ها شناسهٔ بیمار نیستند. ستون patient_id همچنان ۱،۲،۳ است. نیازی نیست اکنون همهٔ ابزارهای pandas را یاد بگیرید.

## ۷. اگر خطا دیدید

| پیام | راه پیش‌رفتن |
|---|---|
| `SyntaxError` | پرانتز، کروشه، گیومه و دونقطهٔ پایان خط with را بررسی کنید |
| `IndentationError` | خط‌های درون with باید چهار فاصله جلوتر باشند؛ فاصله‌ها بخشی از ساختار Python هستند |
| `NameError` | نامی مانند rows درست نوشته نشده یا کد بالای آن حذف شده است |
| `ModuleNotFoundError: pandas` | بسته در Python برگزیده نصب نیست؛ Interpreter و Terminal نصب را همخوان کنید |
| `__file__ is not defined` | این کد برای اجرای فایل py نوشته شده؛ آن را در فایل ذخیره و با Run Python File اجرا کنید |

در این گام موفقیت یعنی ساخت یک فایل سه‌نفری و دیدن سن نفر دوم، نه یادگرفتن همهٔ فرمان‌ها.
