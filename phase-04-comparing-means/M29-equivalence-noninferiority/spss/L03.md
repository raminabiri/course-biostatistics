# SPSS | درس عملی 3 — هم‌ارزی نسبت‌ها

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

ورودی‌های عددی تمرین در همین صفحه آمده‌اند.

در Compute Variable ابتدا d=.45−.42 و se=`SQRT(.45*.55/200+.42*.58/200)` را بسازید. سپس `1-CDF.NORMAL((d+.12)/se,0,1)` و `CDF.NORMAL((d-.12)/se,0,1)` را در دو ستون بخوانید.

**خروجی مرجع R و Python.** Pهای 0.001235 و 0.034667 و فاصلهٔ ۹۰٪ [−0.051507, 0.111507].

**خودآزمایی.** آیا فاصلهٔ [−۰٫۰۵،۰٫۱۱] با حاشیهٔ ±۰٫۱۰ هم‌ارزی را نشان می‌دهد؟
