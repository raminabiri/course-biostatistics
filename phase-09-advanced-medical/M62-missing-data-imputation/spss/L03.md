# SPSS | ساخت سناریو

از File, New, Syntax یک پنجره باز کنید و فرمان‌های زیر را اجرا کنید. هر ردیف یک فرض دربارهٔ چهار مشاهدهٔ گمشدهٔ B است. LIST خروجی را به شکل جدول چاپ می‌کند.

```spss
DATA LIST FREE / delta.
BEGIN DATA
0
-3
-6
-4.5
END DATA.
COMPUTE overall=17+4*delta/12.
LIST VARIABLES=delta overall.
```

ستون overall باید ۱۷، ۱۶، ۱۵ و ۱۵٫۵ را نشان دهد. برای رسم، در Graphs قسمت Chart Builder یک نمودار Scatter ساده با delta در محور X و overall در محور Y بسازید. این چهار ردیف سناریو هستند و نباید برای آن‌ها آزمون همبستگی گزارش کنید.
