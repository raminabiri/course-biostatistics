# R | خوشه‌بندی و نقشهٔ حرارتی

ترمینال را در پوشهٔ ماژول باز کنید و دستور زیر را اجرا کنید. فایل داده باید در پوشهٔ data بماند.

```bash
Rscript --vanilla r/M77_L1.R
```

`dist` فاصلهٔ جفت‌ها را می‌دهد و `hclust` آن‌ها را ادغام می‌کند. در `kmeans` دو ردیف داده مرکزهای آغازند. برای نمایش می‌توانید `heatmap(x, Rowv=as.dendrogram(tree), Colv=NA, scale="none")` را اجرا کنید.

**خروجی مرجع:** مرکزها (۰،۱) و (۸،۹)، جمع مربع‌ها ۴ و ارتفاع آخر حدود ۱۲٫۸۰۶.
