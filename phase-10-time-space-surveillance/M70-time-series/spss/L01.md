# SPSS | سری زمانی منقطع و تغییر سطح و شیب

CSV را با File → Import Data → CSV باز کنید. سطر اول نام متغیرها و همهٔ ستون‌ها عددی هستند. در File → New → Syntax بنویسید:
```spss
REGRESSION /DEPENDENT wait /METHOD=ENTER month post since.
```
در جدول Coefficients ستون B ضرایب خام است. month برابر ۱، post منفی ۵ و since منفی ۲ است. در دادهٔ بدون نویز از معنی‌داری استفاده نکنید.

**خروجی مرجع:** شیب پیشین ۱، جهش منفی ۵، تغییر شیب منفی ۲ و اختلاف ماه ۱۰ برابر منفی ۱۱ دقیقه.

محاسبهٔ مرجع با R و Python وارسی شده است. اجرای مستقیم این مسیر در نرم‌افزار در دسترس نبود.
