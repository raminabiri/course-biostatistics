# حل M17-L1-3-09

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 5/√18 ≈ 1.1785` دقیقه. پراکندگی نمونه‌ای است و اگر آزمون لازم شود، `df = 18-1 = 17` است.
۲. اختلاف را بر SE تقسیم کنید. `t = 3.6/1.1785 ≈ 3.0547`. برای پرسش دوطرفه مساحت `2 × P(T ≥ 3.0547)` را بخوانید. مقدار P حدود **0.0072** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 2.1098 است. حاصل ضرب در SE، نیمه‌عرض 2.4864 را می‌دهد. فاصلهٔ **اختلاف** `[1.114, 6.086]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
