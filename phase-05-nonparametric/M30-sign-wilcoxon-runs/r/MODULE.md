# M30 در R

[دادهٔ پایه](../data/practice.csv) هشت زوج و دوازده وضعیت دارد. design هر طرح را جدا می‌کند. [دادهٔ افزوده](../data/extended.csv) ۲۴ زوج با صفر و رتبهٔ برابر و ۴۸ وضعیت دارد. تحلیل ترتیب را بر اساس id اجرا کنید.

## اجرا و دو آزمون زوجی

[اسکریپت](M30_workshop.R) را در RStudio باز کنید و از Session → Set Working Directory پوشهٔ ماژول را بگیرید. Source را بزنید. از Terminal می‌توانید `Rscript --vanilla r/M30_workshop.R` را اجرا کنید. نام فایل پیش از هر سه خروجی چاپ می‌شود.

`subset` دادهٔ paired را جدا می‌کند. `nonzero <- delta[delta != 0]` صفرها را کنار می‌گذارد. `sum(nonzero > 0)` مثبت‌ها را می‌شمارد. `binom.test` شمار مثبت و شمار کل غیرصفر را می‌گیرد. `alternative="less"` یعنی احتمال مثبت کمتر از نصف. در Wilcoxon برای پایه `exact=TRUE` و برای دادهٔ افزوده `exact=FALSE` است. `correct=FALSE` اصلاح پیوستگی را در تقریب خاموش می‌کند.

## گردش‌ها و کدهای کمکی

`order(sequence$id)` ترتیب صعودی شناسه‌ها را می‌دهد. `diff(x) != 0` هر تغییر بین دو وضعیت را تشخیص می‌دهد. `choose(n,k)` شمار انتخاب k از n است. در تابع runs_test، `%/%` بخش صحیح تقسیم و `%%` باقیمانده را می‌دهد. از این دو برای تعیین حالت زوج و فرد گردش استفاده می‌شود. سپس چیدمان‌های دو دنباله جمع و P دوطرفه با قاعدهٔ درس محاسبه می‌شود.
