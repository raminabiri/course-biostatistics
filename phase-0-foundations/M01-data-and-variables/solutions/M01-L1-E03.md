# پاسخ M01-L1-E03

## پرسش

**سطح:** ساده | **مخاطب:** دانشجوی پزشکی، پیراپزشکی و علوم زیستی

در مطالعه‌ای فقط **زنان ۵۰ تا ۶۰ سالهٔ مبتلا به دیابت نوع ۲** وارد شده‌اند. برای هر نفر این‌ها ثبت شده: جنس، HbA1c، نوع دیابت، سن، شاخص تودهٔ بدنی (BMI)، سال‌های ابتلا. کدام‌ها متغیرند و کدام‌ها ثابت؟

## پاسخ گام‌به‌گام

| ویژگی | متغیر یا ثابت؟ | دلیل |
|---|---|---|
| جنس | ثابت | همه زن‌اند |
| نوع دیابت | ثابت | همه نوع ۲ |
| سن | **متغیر** | بین ۵۰ تا ۶۰ تغییر می‌کند (بازه محدود است، ولی هنوز متغیر است) |
| HbA1c | **متغیر** | |
| BMI | **متغیر** | |
| سال‌های ابتلا | **متغیر** | |

نکته: این دو ستون در نمونهٔ کنونی ثابت‌اند. نگه‌داشتن آن‌ها در فایل مادر برای کنترل معیار ورود و پیوند بعدی سودمند است؛ معیارهای ورود در بخش روش‌ها هم نوشته شوند.
