# SPSS | درس عملی 3 — بلوک‌های کامل

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

دادهٔ پهن با سه ستون شرط را بسازید. Nonparametric Tests → Legacy Dialogs → K Related Samples و Friedman یا Kendall W را بزنید. برای Nemenyi یا Conover بلوکی، اسکریپت کارگاه را اجرا کنید.

**خروجی مرجع R و Python.** Q=۶٫۲۵، W=۰٫۳۹۰۶۲۵ و P آزمون Quade≈۰٫۰۱۹۵۴۹.
