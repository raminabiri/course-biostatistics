# M11 در Python

در محیط دوره `python3 -m pip install scipy` را اجرا کنید و سپس `python3 python/M11_module.py`. cdf مساحت چپ و ppf مقدار متناظر با مساحت داده‌شده را می‌دهد. تابع exp نرخ ضرب در مدت با علامت منفی را به احتمال بقا تبدیل می‌کند.
