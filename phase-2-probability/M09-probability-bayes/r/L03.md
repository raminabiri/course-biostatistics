## آزمون بیز با دادهٔ دوم

در Console بعد از دو درس پیشین بنویسید:

```r
low <- subset(d, population == "low")
low_tab <- with(low, table(reference, test))
p <- mean(low$reference == "positive")
s <- row_share["positive", "positive"]
c_spec <- row_share["negative", "negative"]
tp <- p * s
fp <- (1 - p) * (1 - c_spec)
c(prevalence = p, true_share = tp, false_share = fp, bayes = tp / (tp + fp))
prop.table(low_tab, 2)["positive", "positive"]
```

در R شرط برابری برداری از TRUE/FALSE می‌دهد و میانگین آن سهم TRUE است. پس p باید ۰٫۰۱ شود. دو سهم ۰٫۰۰۹ و ۰٫۰۹۹ هستند. نسبت بیز و سهم واقعی در ستون مثبت جدول دوم باید هر دو حدود ۰٫۰۸۳۳ باشند.
