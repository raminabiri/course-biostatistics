# SPSS | درس عملی 1 — اثر خام و استاندارد

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

در یک دادهٔ یک‌ردیفی، با Compute Variable مقدار cohend را از `(54-50)/8` و hedgesg را از `cohend*(1-3/(4*38-1))` به دست آورید. برای ساخت ردیف از دستور DATA LIST نمونهٔ M14 کمک بگیرید.

**خروجی برای مقایسه.** d=۰٫۵ و g≈۰٫۴۹۰.

**خودآزمایی.** اگر همان اختلاف در مقیاسی با SD برابر ۴ به دست آید، d چگونه عوض می‌شود؟
