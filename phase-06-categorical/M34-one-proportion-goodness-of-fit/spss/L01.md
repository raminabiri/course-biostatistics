# spss | آزمون دقیق یک نسبت

## ورود داده

[CSV مشترک](../data/M34_practice.csv) را دریافت کنید. فایل را با File → Import Data → CSV Data باز کنید. سطر نخست نام متغیرهاست. در Variable View، on_time را Numeric و route را String کنترل کنید. برای فرمان‌ها File → New → Syntax و Run → All را بزنید.

## اجرا و دلیل هر گام

با Analyze → Descriptive Statistics → Frequencies، on_time را بشمارید. در یک جلسهٔ تمرینی، `COMPUTE p_right = 1-CDF.BINOM(59,100,.5).`، `COMPUTE p_two = 2*p_right.` و `EXECUTE.` را اجرا کنید. CDF.BINOM شمارهای تا ۵۹ را شامل می‌شود. مقدارهای ساخته‌شده در هر سطر یکسان‌اند؛ سطر اول را بخوانید.

## کنترل و تمرین

۶۰ از ۱۰۰، P راست ≈۰٫۰۲۸۴۴۴ و دوطرفه ≈۰٫۰۵۶۸۸۸. اگر عدد فرق کرد، نخست شمار سطرهای معتبر، ترتیب رده‌ها و جهت دنباله را کنترل کنید. نتیجه را در یک جمله برای سؤال درس بنویسید.
