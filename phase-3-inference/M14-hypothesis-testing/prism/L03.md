# Prism | درس عملی 3 — فاصله و آزمون

## آماده‌سازی

برای شروع از File → New Project استفاده کنید. در جدول XY، X محل نقطه و Y ورودی تبدیل است. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

در Prism 11، Y=4 و تبدیل کاربر `Y=Y-TINV(.05,24)*2` کران پایین را می‌دهد. + به جای − کران بالا را می‌دهد. صفر را با بازه بسنجید.

**خروجی برای مقایسه.** فاصلهٔ اختلاف [−۰٫۱۳، ۸٫۱۳].

**خودآزمایی.** می‌توان از این نتیجه نتیجه گرفت که دو وضعیت هم‌ارزند؟
