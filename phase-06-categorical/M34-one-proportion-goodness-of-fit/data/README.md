# کدبوک M34

فایل [تمرین](M34_practice.csv) ۱۰۰ درخواست ساختگی از یک واحد پذیرش را دارد. هر سطر یک درخواست و کلید یکتا `id` است. `on_time` پیامد دوحالتی است: ۱ یعنی ثبت در بازهٔ زمانی مقرر، ۰ یعنی خارج از بازه. `route` مسیر دریافت A، B یا C است. هر دو متغیر برای تمرین آماده شده‌اند و خانهٔ خالی ندارند. تحلیل هر متغیر در این ماژول جداست. استقلال درخواست‌ها بخشی از طراحی فرضی است. در مطالعهٔ واقعی، درخواست‌های تکراری یک فرد ممکن است به هم وابسته باشند.
