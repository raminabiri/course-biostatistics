# پاسخ M01-L4-E05

## پرسش

در یک ستون، هیچ مقدار سنجیده‌شده‌ای نداریم. آیا نوشتن میانگین صفر گزارش درستی است؟ چه جمله‌ای روشن‌تر است؟

## پاسخ گام‌به‌گام

صفر یک مقدار عددی واقعی است و از نبود داده به دست نمی‌آید. جملهٔ روشن‌تر این است: «برای این ستون هیچ مقدار معتبری ثبت نشده بود؛ میانگین برآورد نشد.»
