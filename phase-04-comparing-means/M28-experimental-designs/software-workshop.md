# کارگاه گام‌به‌گام M28

این کارگاه ادامهٔ [شروع M01](../../phase-00-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio پوشهٔ ماژول را از Session → Set Working Directory → Choose Directory انتخاب کنید، سپس فایل [M28_workshop.R](r/M28_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M28_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M28_workshop.py](python/M28_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M28_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

[دادهٔ ساختگی](data/practice.csv). در Excel از Data → From Text/CSV و در SPSS از Import Data → CSV Data کمک بگیرید. سرستون‌ها را از ردیف اول بخوانید و جداکننده را ویرگول بگذارید.

## تمرین 28.1

**خروجی مرجع R و Python.** بلوک: F تیمار=8.977099، P=0.009027. مربع لاتین: F=28.822222، P=0.000583.

### Excel

برای بلوک کاملِ یک خوانش در هر خانه، سطر را بلوک و ستون را تیمار بگذارید. ToolPak → ANOVA Two-Factor Without Replication. برای مربع لاتین، ستون‌های نشانگر سطر، ستون و تیمار را در Regression بسازید و مدل با و بدون تیمار را مقایسه کنید.

### SPSS

در GLM Univariate برای block، متغیرهای u و w را Fixed Factors بگذارید. در Custom Model فقط اثرهای اصلی را وارد کنید. برای latin، v را هم اضافه کنید.

### Prism

بلوک را ردیف و تیمار را ستون یا برعکس وارد کنید و طرح matched را با توجه به جهت تنظیم کنید. برای مربع لاتین سه جملهٔ جدا را در کارگاه R اجرا کنید.

### R

اسکریپت R را اجرا کنید. خط L1 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

### Python

اسکریپت Python را اجرا کنید. خط L1 را با عدد کنترل مقایسه کنید. این فایل به SciPy و NumPy متکی است.

## تمرین 28.2

**خروجی مرجع R و Python.** بازو: F=9.618182، P=0.036175. مؤلفهٔ آزمایشگاه=1.222222.

### Excel

برای فهم مخرج، میانگین هر آزمایشگاه را جدا بسازید. از کد R برای MS آزمایشگاه و خطای درون آزمایشگاه کمک بگیرید. ToolPak مدل تصادفی آشیانه‌ای آماده ندارد.

در دادهٔ nested، شناسهٔ آزمایشگاه را در سطح بازو یکتا کنید. در Mixed Models → Linear، a را اثر ثابت، lab را Subject و عرض از مبدأ را Random بگذارید. درجهٔ آزادی گزارش MIXED به روش انتخاب‌شده وابسته است. برای جدول متوازنِ کلاسیک، اسکریپت R را بخوانید.

### Prism

نمودار هر آزمایشگاه را جدا رسم کنید و برای تفکیک دو مؤلفهٔ واریانس، کد همین درس را اجرا کنید.

### R

اسکریپت R را اجرا کنید. خط L2 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.
