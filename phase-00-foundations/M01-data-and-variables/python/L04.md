پیش از اجرا، جدول نمونهٔ درس مفهومی را یک بار با دست بخوانید. [راهنمای شروع این نرم‌افزار](START.md) · [درس مفهومی](../lessons/L4-missing-data-and-measurement-error.md) · [درس عملی پیش](L03.md)

پنج وزن را در یک ستون pandas قرار می‌دهیم. در این نوشته، None جای مقدار در دسترس‌نبوده را نگه می‌دارد:

```python
weight = pd.Series([72, None, 65, 80, None])  # ستون وزن پنج نفر
print(weight.isna())  # جایگاه خانه‌های گمشده
```

Series را می‌توان یک ستون دانست. isna برای جایگاه دوم و پنجم True می‌دهد. اکنون شمار مقدارهای پر و خالی را جدا می‌بینیم:

```python
print(weight.count())       # شمار مقدارهای پر
print(weight.isna().sum())  # شمار مقدارهای خالی
print(weight.mean())        # میانگین مقدارهای پر
```

پاسخ‌ها ۳،۲ و نزدیک ۷۲٫۳۳ هستند. میانگین در pandas به‌طور پیش‌فرض گمشده‌ها را کنار می‌گذارد؛ R در نمونهٔ بالا برای همین کار گزینهٔ جدا می‌خواست. این تفاوت نرم‌افزاری، دلیل خوبی برای نوشتن شمار مقدار معتبر کنار نتیجه است.
