# کارگاه گام‌به‌گام M27

این کارگاه ادامهٔ [شروع M01](../../phase-0-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio پوشهٔ ماژول را از Session → Set Working Directory → Choose Directory انتخاب کنید، سپس فایل [M27_workshop.R](r/M27_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M27_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M27_workshop.py](python/M27_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M27_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

[دادهٔ ساختگی](data/practice.csv). در Excel از Data → From Text/CSV و در SPSS از Import Data → CSV Data کمک بگیرید. سرستون‌ها را از ردیف اول بخوانید و جداکننده را ویرگول بگذارید.

## تمرین 27.1

**خروجی مرجع R و Python.** در baseline=25، بردارهای پیش‌بینی (44.366071،26.072917) و (47.955357،24.052083). برای اثر تعدیل‌شده P=0.010964.

### Excel

برای b=0 جداگانه y و z را با Regression روی a و baseline برازش دهید. از ضرایب در baseline=25 دو بردار بسازید. برای آزمون مشترک کارگاه R را اجرا کنید.

### SPSS

b=0 را انتخاب کنید. در GLM → Multivariate، y و z را Dependent، a را Fixed و baseline را Covariate بگذارید. در Syntax از EMMEANS=TABLES(a) WITH(baseline=25) کمک بگیرید.

### Prism

در دو نمودار XY رابطهٔ baseline با هر پیامد را رسم کنید. MANCOVA را با اسکریپت اجرا کنید.

### R

اسکریپت R را اجرا کنید. خط L1 خروجی همین درس را نشان می‌دهد. تعریف گروه‌ها، مدل و توزیع مرجع درون فایل آمده است.

### Python

اسکریپت Python را اجرا کنید. خط L1 را با عدد کنترل مقایسه کنید. این فایل به SciPy و NumPy متکی است.
