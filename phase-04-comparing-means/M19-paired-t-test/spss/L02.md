# SPSS | درس عملی 2 — خطای معیار تغییر

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین values.csv](../data/values.csv)

از Transform → Compute Variable متغیر diff=after-before را بسازید و در Descriptives، SD را بخوانید.

**خروجی مرجع R و Python.** SD=0.991031 و SE=0.350382.

**خودآزمایی.** اگر SD تقریباً ثابت بماند، برای نصف‌کردن SE حدوداً چند زوج لازم است؟
