# M04 در SPSS

[فایل Syntax](M04_module.sps) را در نشست تازه با Run → All اجرا کنید. در AGGREGATE پیش از پیوند، هر شناسهٔ آزمایش یک ردیف می‌گیرد. سپس فایل ثبت با نام جدا ساخته می‌شود. IF فقط قد فرد ۲ را عوض می‌کند. RECODE خروجی را در ستون sbp می‌سازد و ‎−۹۹ را به system missing تبدیل می‌کند. فایل ثبت و جدول تجمیع‌شده هر دو روی pid مرتب‌اند. در MATCH FILES جدول آزمایش با TABLE افزوده می‌شود. بنابراین ردیف‌های ثبت باقی می‌مانند.

در جدول LIST، سه ردیف پیدا کنید. meanldl ردیف ۳ باید خالی آماری و bmi ردیف ۲ حدود ۲۶٫۰۴ باشد.
