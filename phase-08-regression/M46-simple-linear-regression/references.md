# منابع M46

- درس ۴۶٫۱، متوسط. تابع خطی، باقیمانده‌ها و R² را از بخش رگرسیون خطی مرور کنید. [NIST، Linear Least Squares Regression](https://www.itl.nist.gov/div898/handbook/pmd/section1/pmd141.htm)
- Excel، روش محاسبهٔ یک پیش‌بینی روی خط را ببینید. [Microsoft، FORECAST.LINEAR](https://support.microsoft.com/en-us/office/forecast-and-forecast-linear-functions-50ca49c9-7b40-4892-94e4-7ad38bbeda99)
- SPSS، گزینه‌های مدل و ذخیرهٔ باقیمانده و فاصله را در فصل REGRESSION مرور کنید. [IBM، Command Syntax Reference](https://www.ibm.com/docs/en/SSLVMB_31.0.0/pdf/IBM_SPSS_Statistics_Command_Syntax_Reference.pdf)
- Prism، بخش مقایسهٔ شیب‌ها و پس از آن مقایسهٔ عرض‌ها را بخوانید. [GraphPad، Comparing slopes and intercepts](https://www.graphpad.com/guides/prism/latest/curve-fitting/reg_comparingslopesandintercepts.htm)
- Prism، فیلم مقدماتی. از مجموعهٔ رسمی، ویدئوی رگرسیون خطی را برای ورود XY و خواندن خط ببینید. [GraphPad، آموزش تحلیل آماری](https://www.graphpad.com/series/learn-to-perform-common-statistical-analyses)
- R، شکل newdata و فرق confidence و prediction را ببینید. [مستندات predict.lm](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/predict.lm.html)
- Python، خروجی ضرایب و مفهوم حداقل مربعات را مرور کنید. [NumPy، lstsq](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)
