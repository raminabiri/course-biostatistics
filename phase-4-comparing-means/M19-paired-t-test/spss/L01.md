# SPSS | درس عملی 1 — شناسه و اختلاف زوجی

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین values.csv](../data/values.csv)

Analyze → Compare Means → Paired-Samples T Test. after را اول و before را دوم بگذارید. ترتیب را در عنوان زوج کنترل کنید.

**خروجی مرجع R و Python.** اختلاف −3.875 و t=−11.059344.

**خودآزمایی.** اگر بعد بیمار دوم در دسترس نباشد، میانگین زوج‌های کامل چند است؟
