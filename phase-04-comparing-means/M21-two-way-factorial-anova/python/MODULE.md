# M21 در Python

[دادهٔ آموزشی](../data/practice.csv) ۴۰ مشاهدهٔ مستقل دارد. a، b و c سه عامل با کدهای صفر و یک‌اند. value پاسخ عددی است. از ۲۰ ردیف c=0 برای مدل دوطرفه استفاده می‌کنیم.

## اجرا و مشاهدهٔ خروجی

در Terminal پوشهٔ ماژول را باز کنید. در مفسر M01، در صورت نیاز با `python -m pip install numpy scipy` کتابخانه‌ها را بگیرید. [اسکریپت](M21_workshop.py) را با `python python/M21_workshop.py` اجرا کنید. L1 زوج مرتب F و P، L2 تفاضل ۷ و L3 آزمون تعامل سه عامل را چاپ می‌کند.

## چرا دو مدل ساخته می‌شود؟

دستور `np.loadtxt` ستون‌ها را می‌خواند. `s = c == 0` یک دنبالهٔ درست/نادرست می‌سازد تا تنها نوبت صفر انتخاب شود. `np.column_stack([o,a,b])` سه ستون مدل ساده را کنار هم می‌گذارد. ستون o از عدد یک پر شده و مقدار پایه را برآورد می‌کند. مدل کامل برای آزمون دوطرفه ستون `a*b` را هم دارد. چون کدها صفر و یک‌اند، این ستون فقط برای a و b هر دو برابر یک، عدد یک می‌گیرد.

تابع `np.linalg.lstsq` ضرایبی را پیدا می‌کند که مجموع مربع مانده‌ها را کمینه می‌کنند. در اسکریپت، `x @ coefficient` مقدار پیش‌بینی‌شده و سپس `y - x @ coefficient` مانده است. `residual @ residual` مجموع مربع مانده‌هاست. کاهش این مجموع از مدل ساده به کامل، در مقایسه با خطای مدل کامل، F را می‌دهد. `f.sf` دنبالهٔ سمت راست F را برمی‌گرداند. برای مدل سه‌طرفه، مدل کوچک همهٔ تعامل‌های دوتایی را نگه می‌دارد و مدل کامل ستون `a*b*c` را هم می‌افزاید.

## کنترل نتیجه

با C0، تعامل A×B برابر ۴ واحد و F(۱،۱۶)=۸ با P≈۰٫۰۱۲۱۱ است. اثر سادهٔ A در B1 برابر ۷ واحد است. در دادهٔ کامل، تعامل A×B×C برابر ۲ واحد و F(۱،۳۲)=۰٫۴ با P≈۰٫۵۳۱۵۸ است.
