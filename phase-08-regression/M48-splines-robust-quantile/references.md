# منابع M48

- Excel، کاربرد Solver برای کمینه‌کردن تابع هدف را بخوانید. [Microsoft، Define and solve a problem by using Solver](https://support.microsoft.com/en-us/office/define-and-solve-a-problem-by-using-solver-5d1a388f-079d-43ac-a7eb-f63e45925040)
- SPSS، فصل REGRESSION را برای مدل خطی روی ستون‌های پایه مرور کنید. [IBM، Command Syntax Reference](https://www.ibm.com/docs/en/SSLVMB_31.0.0/pdf/IBM_SPSS_Statistics_Command_Syntax_Reference.pdf)
- Prism، فیلم رگرسیون خطی برای تفاوت دادهٔ XY و خط برازش. [GraphPad، مجموعهٔ رسمی آموزش](https://www.graphpad.com/series/learn-to-perform-common-statistical-analyses)
- R، تعریف گره و خطی‌بودن بیرون مرز را با ستون آموزشی مقایسه کنید. [R، Natural Cubic Splines](https://stat.ethz.ch/R-manual/R-devel/library/splines/html/ns.html)
- Python، بخش تساوی‌ها و کران متغیرها را برای رگرسیون چندکی بخوانید. [SciPy، linprog](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)
- مقالهٔ پیشرفته برای زیان مقاوم. [Huber، Robust Estimation of a Location Parameter](https://doi.org/10.1214/aoms/1177703732)
- مقالهٔ پیشرفته برای درس ۴۸٫۳. [Koenker و Bassett، Regression Quantiles](https://doi.org/10.2307/1913643)
