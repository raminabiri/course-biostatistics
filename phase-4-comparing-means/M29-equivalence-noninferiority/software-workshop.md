# کارگاه گام‌به‌گام M29

این کارگاه ادامهٔ [شروع M01](../../phase-0-foundations/M01-data-and-variables/START.md) است. [فیلم و مرجع هر پنج مسیر](references.md#software-media) برای مرور در دسترس است.

- **Excel.** کارپوشهٔ خالی باز کنید. هر فرمول را با علامت = وارد کنید و Enter بزنید. اگر جداکنندهٔ آرگومان در نصب شما نقطه‌ویرگول است، ویرگول بین آرگومان‌ها را عوض کنید. کارپوشه را با File → Save As ذخیره کنید.
- **SPSS.** برای قطعه‌های Syntax از File → New → Syntax استفاده کنید. کد را وارد کنید و Run → All را بزنید. برای حفظ پروژهٔ باز، تمرین را در یک مجموعهٔ تازه انجام دهید. جدول را در Output و متغیر محاسبه‌شده را در Data View بخوانید.
- **Prism.** از File → New Project شروع کنید. نوع جدول و چگونگی ورود داده در تمرین آمده است. Analyze را بزنید و نتیجه را در Results بخوانید. پروژه را از File → Save As ذخیره کنید.
- **R.** در RStudio پوشهٔ ماژول را از Session → Set Working Directory → Choose Directory انتخاب کنید، سپس فایل [M29_workshop.R](r/M29_workshop.R) را باز کنید و Source را بزنید. برای اجرای ترمینالی در پوشهٔ ماژول، `Rscript --vanilla r/M29_workshop.R`. پاسخ در Console دیده می‌شود.
- **Python.** در VS Code پوشهٔ ماژول را باز کنید و فایل [M29_workshop.py](python/M29_workshop.py) را با Run Python File اجرا کنید. اگر SciPy لازم است، در همان مفسر M01 و از Terminal → New Terminal، فرمان `python -m pip install scipy` را اجرا کنید. در سیستمی که M01 را با python3 اجرا کردید همان نام را به کار ببرید. سپس `python python/M29_workshop.py` را اجرا کنید. پاسخ در Terminal چاپ می‌شود. برای نگهداری آن، می‌توانید در پایان فرمان `> output.txt` بگذارید تا متن در همان پوشه ذخیره شود.

### Excel

## تمرین 29.3

**خروجی مرجع R و Python.** Pهای 0.001235 و 0.034667 و فاصلهٔ ۹۰٪ [−0.051507, 0.111507].

### Excel

در B1 و B2 نسبت‌های `=90/200` و `=84/200` را بگذارید. B3=B1−B2 و B4=`=SQRT(B1*(1-B1)/200+B2*(1-B2)/200)`. برای CI، B3 ± NORM.S.INV(.95)×B4 و برای Pها `=1-NORM.S.DIST((B3+.12)/B4,TRUE)` و `=NORM.S.DIST((B3-.12)/B4,TRUE)` را به کار ببرید.

### SPSS

در Compute Variable ابتدا d=.45−.42 و se=`SQRT(.45*.55/200+.42*.58/200)` را بسازید. سپس `1-CDF.NORMAL((d+.12)/se,0,1)` و `CDF.NORMAL((d-.12)/se,0,1)` را در دو ستون بخوانید.

### Prism

در XY با Y=.03، دو تبدیل کاربر را با `Y=1-NORMDIST((Y+.12)/sqrt(.45*.55/200+.42*.58/200),0,1,"left")` و `Y=NORMDIST((Y-.12)/sqrt(.45*.55/200+.42*.58/200),0,1,"left")` اجرا کنید. روش تقریب Wald است.
