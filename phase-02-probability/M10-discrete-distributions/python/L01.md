# Python | درس 1 — دوجمله‌ای از شمار نتیجه‌ها

در یک فرایند ساختگی، شانس نتیجهٔ مثبت هر تلاش ۰٫۲ است. پنج تلاش مستقل داریم. پیش از دیدن نتیجه می‌پرسیم احتمال دقیقاً دو مثبت چقدر است.

## آماده‌سازی و اجرا

در VS Code پوشهٔ ماژول را باز کنید و کد را در فایل py تازه بگذارید. دکمهٔ Run Python File را بزنید. خروجی در Terminal دیده می‌شود.

`from math import comb` و `print(comb(5,2)*.2**2*.8**3)` را اجرا کنید. comb شمار ترکیب‌ها را می‌دهد. برای دست‌کم دو از `print(1-.8**5-5*.2*.8**4)` استفاده کنید.
