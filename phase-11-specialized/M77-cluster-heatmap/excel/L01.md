# Excel | خوشه‌بندی و نقشهٔ حرارتی

CSV را وارد کنید. برای فاصلهٔ A تا B از `=SQRT((B2-B3)^2+(C2-C3)^2)` استفاده کنید. مرکز دو خوشه را با AVERAGE برای هر مختصات بسازید. ستون‌های B و C را انتخاب کنید و Home → Conditional Formatting → Color Scales را بزنید. این رنگ‌بندی مقدارهای جدول را نمایش می‌دهد. عضویت خوشه را در ستونی مستقل نگه دارید.

**خروجی مرجع:** مرکزها (۰،۱) و (۸،۹)، جمع مربع‌ها ۴ و ارتفاع آخر حدود ۱۲٫۸۰۶.

محاسبهٔ مرجع با R و Python وارسی شده است. اجرای مستقیم این مسیر در نرم‌افزار در دسترس نبود.
