# SPSS | درس عملی 1 — حاشیهٔ هم‌ارزی

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

ورودی‌های عددی تمرین در همین صفحه آمده‌اند.

در یک دادهٔ یک‌ردیفی، با Compute Variable مقدار eq را با `(-1.1 > -2) AND (1.3 < 2)` بسازید. شرط یک‌طرفه را در ستونی جدا بنویسید.

**خروجی مرجع R و Python.** دو کران نمونه درون حدود ±۲ هستند.

**خودآزمایی.** بازهٔ [−۱،۲٫۴] برای هم‌ارزی و عدم‌کم‌اثری چه می‌گوید؟
