# R | درس عملی 2 — خطای معیار تغییر

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

اسکریپت R را اجرا کنید و خط L2 را با خروجی همین تمرین تطبیق دهید. تنظیم آزمون در فراخوانی با نام کامل نوشته شده است.

[فایل کد](../r/M19_workshop.R) را باز کنید. `sd(d)` انحراف معیار نمونه را می‌سنجد و `sqrt(length(d))` مقسوم‌علیه SE است.

**خروجی مرجع R و Python.** SD=0.991031 و SE=0.350382.

**خودآزمایی.** اگر SD تقریباً ثابت بماند، برای نصف‌کردن SE حدوداً چند زوج لازم است؟
