# M29 در SPSS

دو [دادهٔ ساختگی میانگین](../data/means.csv) و [نسبت](../data/proportions.csv) در دسترس‌اند. کد ۱ روش تازه و ۰ مرجع است. اختلاف همه‌جا تازه منهای مرجع است. حدهای تمرین برای میانگین ±۲ و برای نسبت ±۰٫۱۲ هستند.

## ورود داده و محاسبهٔ فرمول‌ها

۱. [فایل فرمان](M29_module.sps) را از File → Open → Syntax باز کنید. اگر پوشهٔ کاری شما پوشهٔ ماژول نیست، دو مسیر FILE را کامل کنید. Run → All را بزنید. برای ورود از منو می‌توانید File → Import Data → CSV Data با جداکنندهٔ Comma را بگیرید.

۲. در فرمان، COMPUTE ابتدا ستون‌های جدا برای روش تازه و مرجع می‌سازد. `SYSMIS` مقدار گمشدهٔ سیستمی است. IF فقط ردیف‌های همان گروه را در ستون می‌گذارد. AGGREGATE شمار، میانگین و انحراف استاندارد را از مقدارهای ثبت‌شده می‌گیرد. در فایل دودویی، میانگین ستون صفر و یک همان نسبت است.

۳. در محاسبهٔ t، `CDF.T(t,df)` احتمال سمت چپ را می‌دهد. برای حد پایین آن را از ۱ کم کنید و برای حد بالا مستقیم بخوانید. `IDF.T(.95,df)` صدک سمت چپ را به نیم‌عرض تبدیل می‌کند. در فایل نسبت، `CDF.NORMAL(z,0,1)` همان کار را با توزیع نرمال استاندارد انجام می‌دهد.

## خواندن خروجی

LIST دو ردیف جدا نشان می‌دهد. در خروجی اول واریانس مشترک و مرز ±۲، و در خروجی دوم تقریب والد و مرز ±۰٫۱۲ به کار رفته‌اند. m_new و m_ref را برای جهت نتیجه و ci_lo و ci_hi را برای کران‌ها بخوانید. p_tost بزرگ‌ترِ دو مقدار است. برای مدت یا هزینه که کوچک‌تر بهتر است، در آزمون یک‌طرفه به کران بالا و جهت نگاه کنید.

## کنترل خروجی

بزرگ‌ترین P برای میانگین ≈۰٫۰۰۵۵۹۶ و فاصلهٔ ۹۰٪ [−۰٫۶۱۱۵۷۳،۱٫۴۱۱۵۷۳] است. برای تفاوت نسبت‌ها با والد، بزرگ‌ترین P≈۰٫۰۳۴۶۶۷ و بازهٔ ۹۰٪ [−۰٫۰۵۱۵۰۷،۰٫۱۱۱۵۰۷] است. هر دو بازه داخل حدود خودشان‌اند.
