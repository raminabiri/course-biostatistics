# M17 با R | راهنمای خواندن کد و خروجی

این تمرین به بستهٔ اضافی نیاز ندارد. در RStudio از **Session → Set Working Directory → Choose Directory** پوشهٔ M17 را انتخاب کنید. در Console فرمان `file.exists("data/values.csv")` را بزنید. TRUE یعنی مسیر درست است. بعد `source("r/M17_workshop.R")` را اجرا کنید. اگر می‌خواهید دلیل هر خط را ببینید، [فایل R](M17_workshop.R) را باز کنید و خطوط را از بالا با دکمهٔ Run اجرا کنید.

| فرمان یا نشانه | به زبان ساده |
|---|---|
| `data <- read.csv("data/values.csv")` | جدول از روی فایل خوانده می‌شود و با پیکان `<-` نام data می‌گیرد. |
| `x <- data$value` | علامت دلار ستون value را از جدول جدا می‌کند. `x` اکنون فهرست هشت زمان است. در Console با نوشتن `x` آن را ببینید. |
| `stopifnot(...)` | خط کنترل داده است. اگر تعداد زمان‌ها هشت نباشد، ستون عددی نباشد یا عدد گمشده باشد، اجرا متوقف می‌شود. |
| `length(x)`، `sd(x)` و `sqrt(n)` | به‌ترتیب شمار داده، SD نمونه‌ای و جذر n را می‌دهند. تقسیم SD بر جذر n، SE را می‌سازد. |
| `fit <- t.test(x, mu = target)` | t تک‌نمونه‌ای با مرجع target را اجرا می‌کند و خروجی را در fit نگه می‌دارد. حالت پیش‌فرض دوطرفه است. با نوشتن `fit` می‌توانید جدول معمول R را بخوانید. |
| `fit$statistic`، `fit$parameter` و `fit$p.value` | آماره t، درجهٔ آزادی و P دوطرفه را از نتیجه برمی‌دارند. `unname()` فقط نام داخلی عدد را برای چاپ ساده‌تر حذف می‌کند. |
| `pnorm(z, lower.tail = FALSE)` و `pt(t, df, lower.tail = FALSE)` | در توزیع نرمال و t به‌ترتیب مساحت سمت راست می‌دهند. اگر آرگومان را ننویسید، تابع مساحت چپ را می‌دهد. |
| `fit$conf.int - target` | هر دو کران فاصلهٔ میانگین را به اندازهٔ ۵۰ کم می‌کند تا فاصلهٔ اختلاف ساخته شود. `rbind()` دو بازه را در دو ردیف چاپ می‌کند. |

**تمرین با یک تغییر.** در نسخهٔ جداگانهٔ فایل، target را به ۵۵ عوض کنید و از ابتدای فایل دوباره اجرا کنید. اول حدس بزنید علامت t چه می‌شود. بعد نتیجه را ببینید. میانگین هنوز ۵۴ است و اختلاف ۱- می‌شود، پس P راست باید بالاتر از ۰٫۵ باشد.

**کنترل و ذخیره.** با مرجع ۵۰، خروجی باید n=8، t≈2.412 و P دوطرفه≈0.046631 داشته باشد. برای ذخیره در پوشهٔ ماژول، `out <- capture.output(source("r/M17_workshop.R"))` و سپس `writeLines(out, "M17_R_output.txt")` را اجرا کنید. [بازگشت به کارگاه](../software-workshop.md)
