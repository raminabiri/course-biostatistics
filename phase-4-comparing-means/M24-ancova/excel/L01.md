# Excel | درس عملی 1 — پیش‌بینی در خط پایهٔ یکسان

## آماده‌سازی

کارپوشهٔ تازه را باز کنید. فرمول‌ها با = شروع می‌شوند و با Enter اجرا می‌شوند. نتیجه را در خانهٔ همان فرمول بخوانید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

[دادهٔ تمرین change.csv](../data/change.csv)

B=0 را جدا کنید. ToolPak → Regression، value را Y و ستون‌های A و baseline را X قرار دهید. مقدار پیش‌بینی با A=0 و A=1 و baseline=24 را حساب کنید.

### گام‌های اجرا و کنترل

CSV را با Data → From Text/CSV وارد کنید. ستون B را روی ۰ فیلتر کنید. در برگهٔ تازه، A و baseline را کنار هم در دو ستون و value را در ستون سوم کپی کنید؛ باید ۱۲ ردیف داده بماند. Data → Data Analysis → Regression را باز کنید. Input X Range را دو ستون توضیح‌دهنده و Input Y Range را value بگذارید. اگر عنوان‌ها داخل محدوده‌اند، Labels را علامت بزنید. در Coefficients، عرض از مبدأ، ضریب a و شیب baseline را پیدا کنید. پیش‌بینی A0 برابر عرض از مبدأ + ۲۴×شیب و پیش‌بینی A1 همین مقدار + ضریب a است.

**خروجی مرجع R و Python.** پیش‌بینی در baseline=24 برای A0 و A1 برابر 48.942857 و 51.285714.

**خودآزمایی.** اگر دو گروه به‌ترتیب خط پایهٔ ۲۰ و ۲۸ داشته باشند، اختلاف پیش‌بینی خام در همین مدل چند است؟
