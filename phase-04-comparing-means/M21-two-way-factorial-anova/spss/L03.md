# SPSS | درس عملی 3 — تعامل سه‌طرفه

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

هر سه عامل را در GLM → Univariate وارد کنید و Full factorial را بزنید. a*b*c را بخوانید.

### گام‌های اجرا و کنترل

قبل از اجرا Data → Select Cases → All cases را بزنید. در Univariate، value را پیامد و a، b و c را Fixed Factors بگذارید. در Model، Full factorial را انتخاب کنید. در Options، آمار توصیفی را بخواهید و شمار کل ۴۰ و هشت شمارِ ۵ را کنترل کنید. در خروجی، `a*b*c` ردیف تعامل سه‌طرفه است و `a*b` ردیف دیگری است. ردیف Error باید ۳۲ درجهٔ آزادی و میانگین مربعات ۶٫۲۵ نشان دهد.

**خروجی مرجع R و Python.** تعامل سه‌طرفه F=0.4 و P=0.531583.

**خودآزمایی.** اگر تعامل A×B در هر دو C برابر ۵ باشد، دربارهٔ تعامل سه‌طرفه چه می‌گویید؟
