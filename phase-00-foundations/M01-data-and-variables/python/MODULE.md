# M01 در Python

از پوشهٔ ماژول در ترمینال اجرا کنید `python3 python/M01_module.py`. این فایل از ابزارهای همراه Python بهره می‌گیرد. نصب بسته لازم نیست.

`DictReader` هر سطر را با نام ستون‌ها می‌خواند. خانهٔ خالی به صورت رشتهٔ خالی وارد می‌شود. آن را به `None` تبدیل می‌کنیم تا با صفر عددی فرق داشته باشد. دیکشنری نخست بر اساس شناسه و دیکشنری درونی بر اساس روز است. با این چیدمان، دو نوبت همان فرد را پیدا می‌کنیم. برای میانگین هر روز صرفاً مقدارهای متفاوت از None را نگه می‌داریم.

برای روز صفر ۳ ردیف و ۳ دمای معتبر و برای روز سه ۳ ردیف و ۲ دمای معتبر چاپ می‌شود. دو میانگین حدود ۳۷٫۳۶۶۷ و ۳۷٫۲ هستند. خط آخر اختلاف جفت‌ها را با دقت دو رقم اعشار نشان می‌دهد.
