# SPSS | درس عملی 2 — P، تصمیم و دو نوع خطا

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

روی همان فایل، در Compute Variable برای p_right از `1-CDF.T(tval,n-1)` و برای p_two از `2*(1-CDF.T(ABS(tval),n-1))` کمک بگیرید.

### اگر علامت آماره برعکس شود

فرض جهت‌دار از پیش «میانگین بالاتر از مرجع» بوده است. اکنون با t=−۲ و df=۲۴، مقدار P راست ≈۰٫۹۷۱۵ و P دوطرفه ≈۰٫۰۵۶۹ است. برای آزمون راست‌طرفه دنبال مساحت سمت راست t منفی بگردید.

در Compute Variable راست را با `1-CDF.T(-2,24)` و دوطرفه را با `2*(1-CDF.T(ABS(-2),24))` حساب کنید. CDF مساحت سمت چپ را می‌دهد.

**خروجی برای مقایسه.** P راست حدود ۰٫۰۲۸۵ و P دوطرفه حدود ۰٫۰۵۶۹.

**خودآزمایی.** اگر در واقع میانگین ۵۰ باشد ولی آزمون آن را رد کند، خطا از چه نوع است؟
