# SPSS | درس عملی 1 — هم‌ترازی پیش از رتبه

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

با Aggregate میانگین خانه و حاشیه‌ها را به ردیف‌ها اضافه کنید. در Compute Variable هم‌ترازی تعامل را بسازید. Transform → Rank Cases روی این ستون و GLM Univariate با دو عامل. فقط سطر تعامل این مدل را بخوانید.

**خروجی مرجع R و Python.** برای تعامل ART، F≈۱۰٫۸۶۷۰۵۸ و P≈۰٫۰۰۲۶۶۴.

**خودآزمایی.** آیا همان رتبه‌های تعامل را برای آزمون اثر A استفاده می‌کنید؟
