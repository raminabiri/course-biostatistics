# M07 در SPSS

[Syntax](M07_module.sps) را اجرا کنید. WEIGHT BY freq هر سطر تجمیع‌شده را با شمارش همان دسته وارد محاسبات می‌کند. در جدول نخست نامعلوم‌ها دیده می‌شوند. در جدول دوم، SELECT IF به‌طور موقت فقط معلوم‌ها را نگه می‌دارد. در سطر A و ستون Positive مقدار Row % باید ۳۰ و Column % باید ۶۰ باشد. برای دادهٔ فردی با یک ردیف به ازای نفر، WEIGHT BY لازم نیست.
