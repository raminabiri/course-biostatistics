# SPSS | درس عملی 3 — میانه و جابه‌جایی

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

میانهٔ ادغام را از Frequencies بخوانید. در Compute Variable، پرچم value>میانه را بسازید. در Crosstabs ستون پرچم و گروه را وارد و P دقیق Fisher را برای شمار کم این تمرین بخوانید.

**خروجی مرجع R و Python.** برآورد Hodges–Lehmann برابر ۲ و P دقیق آزمون میانه برابر ۱.
