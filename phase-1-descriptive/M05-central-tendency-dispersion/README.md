# ماژول M05 — شاخص‌های مرکزی و پراکندگی

**فاز ۱ (آمار توصیفی)** | پیش‌نیاز: M01، M02 | زمان تقریبی: ۴ ساعت درس نظری + ۱ تا ۲ ساعت برای هر نرم‌افزار

## چرا این ماژول؟

اولین جدول هر مقالهٔ پزشکی («جدول ۱») از همین شاخص‌ها ساخته می‌شود: میانگین، میانه، انحراف معیار. این‌ها ساده به نظر می‌رسند، ولی رایج‌ترین خطاهای گزارش در مقالات هم همین‌جاست: گزارش میانگین برای داده‌های چوله، اشتباه گرفتن انحراف معیار (SD) با خطای استاندارد (SEM)، و خلاصه کردن متغیری که بیشتر مقادیرش صفر است با یک «میانگین».

## هدف‌های یادگیری

در پایان این ماژول می‌توانید:

1. میانگین، میانه و نما را حساب کنید و بدانید هر کدام کی مناسب است.
2. دامنه، واریانس، انحراف معیار، دامنهٔ میان‌چارکی و ضریب تغییرات را حساب و تفسیر کنید.
3. تفاوت **SD** و **SEM** را توضیح دهید و هر کدام را درست به کار ببرید.
4. برای هر متغیر خلاصهٔ مناسب را انتخاب و مطابق استانداردهای مقالات گزارش کنید، کلی و به تفکیک گروه.
5. همهٔ این‌ها را در SPSS، Prism، R، Python یا Excel انجام دهید.
