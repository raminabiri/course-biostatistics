# کدبوک M39

سه فایل جمع‌شده و ساختگی داریم. [فایل خطر](M39_risk.csv) برای هر گروه تعداد رخداد و افراد تحت پیگیری را دارد. [فایل پیگیری](M39_followup.csv) تعداد در معرض خطرِ شروع، موارد تازه، نفر–سال، موارد موجود و جمعیت سرشماری را نگه می‌دارد. [فایل استانداردسازی](M39_standard.csv) هر گروه و طبقهٔ سنی، تعداد، رخداد، جمعیت معیار و خطر مرجع را نشان می‌دهد. جمعیت معیار در هر گروه تکرار می‌شود. هر سه فایل سناریوی آموزشی هستند و نباید برای پیوند فردی به کار روند.
