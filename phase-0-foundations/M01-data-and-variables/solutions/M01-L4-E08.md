# پاسخ M01-L4-E08

## پرسش

**سطح:** متوسط | **مخاطب:** دانشجو و پژوهشگر

CRP یک نمونهٔ کنترل کیفی با مقدار واقعی ۵۰ mg/L، پنج بار در دو آزمایشگاه اندازه‌گیری شده است:
آزمایشگاه A: 49.8، 50.3، 50.1، 49.9، 50.2
آزمایشگاه B: 44.0، 57.5، 51.2، 46.3، 52.0
میانگین هر آزمایشگاه را حساب کنید و هر کدام را از نظر دقت و صحت ارزیابی کنید.

## پاسخ گام‌به‌گام

**آزمایشگاه A:** مجموع = 49.8 + 50.3 + 50.1 + 49.9 + 50.2 = 250.3 ← میانگین = **50.06**
- بازه: 49.8 تا 50.3 (پهنای 0.5) ← **دقیق**
- میانگین بسیار نزدیک به ۵۰ ← **صحیح**

**آزمایشگاه B:** مجموع = 44.0 + 57.5 + 51.2 + 46.3 + 52.0 = 251.0 ← میانگین = **50.20**
- بازه: 44.0 تا 57.5 (پهنای 13.5) ← **نادقیق** (خطای تصادفی زیاد)
- میانگین نزدیک ۵۰ ← به‌طور میانگین **صحیح** (سوگیری ندارد)

نتیجه: هر دو آزمایشگاه به‌طور میانگین صحیح‌اند، ولی یک اندازه‌گیری منفرد در دادهٔ نشان‌داده‌شدهٔ B تا ۷ واحد فاصله با مرجع دارد؛ این عدد کران خطای آینده نیست. برای تصمیم بالینی روی **یک** بیمار، آزمایشگاه A بسیار قابل‌اعتمادتر است. (معیار عددی پراکندگی، یعنی انحراف معیار و ضریب تغییرات، در M05 آموزش داده می‌شود.)
