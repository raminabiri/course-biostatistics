# درس عملی 2 — رابطهٔ سن و فشار در یک سطر

شناسهٔ ۸، سن ۷۱ و فشار ۱۶۰ دارد.

## آماده‌سازی

[فایل داده](../data/M08_followup.csv) را دانلود کنید. از File → Import Data → CSV Data شروع کنید. سطر اول را نام متغیر بگیرید. نتایج در Output و داده در Data View دیده می‌شوند.

## اجرا

در Chart Builder نمودار Scatter با age در X و day0 در Y بسازید. برای گروه از Set color استفاده کنید. در Data View مقدارهای همان ردیف شناسهٔ ۸ را با نقطهٔ (۷۱،۱۶۰) بسنجید. Explore با day0 به‌عنوان پاسخ و group به‌عنوان عامل، SE را جدا گزارش می‌کند.

## کنترل و تفسیر

در نمودار پراکنش، همین سطر یک نقطهٔ (۷۱،۱۶۰) در گروه A می‌سازد. ۷۱ را روی محور سن و ۱۶۰ را روی محور فشار پیدا کنید. اگر ستون‌ها را جدا مرتب کنید، ممکن است سن و فشار دو فرد را اشتباهی به هم وصل کنید.

اگر خلاصهٔ میانگین ± SE می‌سازید، آن را با نمودار پراکندگی افراد اشتباه نگیرید. در A میانگین ۱۳۱٫۳۷۵ و SE حدود ۴٫۴۹۲ است. زیرنویس مشخص کند میله SD، SE یا CI است.
