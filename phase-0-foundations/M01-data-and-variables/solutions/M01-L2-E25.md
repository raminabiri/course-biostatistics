# پاسخ M01-L2-E25

## پرسش

**سطح:** پیشرفته | **مخاطب:** متخصص و پژوهشگر؛ دانشجوی علاقه‌مند

CRP زیر حد سنجش با صفر ثبت شده است. چرا این یک تصمیم دربارهٔ نوع داده هم هست؟

## پاسخ گام‌به‌گام

یک بازهٔ نامعلوم زیر حد سنجش به نقطهٔ دقیق صفر تبدیل شده است. حد سنجش و پرچم زیر حد را جدا نگه دارید؛ این داده با گمشدهٔ ساده یکسان نیست.
