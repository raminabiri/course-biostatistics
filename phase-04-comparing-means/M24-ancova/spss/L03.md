# SPSS | درس عملی 3 — تعدیل تغییر فردی

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

[دادهٔ تمرین change.csv](../data/change.csv)

در این تمرین پاسخ ستون change آماده است.

### گام‌های اجرا و کنترل

فایل change.csv را وارد کنید. ستون change از قبل آماده است. در Univariate آن را Dependent و a و baseline را به‌ترتیب Fixed Factor و Covariate بگذارید. مدل a و baseline را نگه دارید. در جدول آزمون، F سطر a≈۲٫۳۷۳ و df خطا ۹ است. اگر جهت ضریب گروه را می‌خواهید، میانگین‌های تعدیل‌شده در یک baseline مشترک را بگیرید و A0 را از A1 کم کنید؛ علامت ضرایب Parameter Estimates به ردهٔ مرجع نرم‌افزار وابسته است.

**خروجی مرجع R و Python.** کنتراست تغییر تعدیل‌شده F=2.373170، P=0.157824.

**خودآزمایی.** اگر مقدار بعد فردی ثبت نشده باشد، آیا تغییرش را صفر وارد می‌کنید؟
