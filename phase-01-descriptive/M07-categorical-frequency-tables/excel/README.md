# تمرین M07 با Excel

[CSV پیمایش](../data/M07_survey.csv) را وارد و محدوده را به جدول Excel با نام `Survey` تبدیل کنید. در [تمرین‌ها](../practice.md)، درصد را با قالب Percentage نمایش دهید.

- ع۱ و ع۲. با `COUNTIF` هر طبقه را بشمارید و بر مجموع شمارها تقسیم کنید. برای درصد تجمعی تحصیلات، درصدها را به ترتیب کد جمع کنید.
- ع۳. `COUNTBLANK(Survey[flu_vacc])` را به کار ببرید. `COUNTIF(Survey[flu_vacc],"yes")` را یک بار بر شمار شناسه‌ها و بار دیگر بر مجموع شمار yes و no تقسیم کنید.
- ع۴ و ع۵. در PivotTable، متغیر گروه را در Rows و متغیر پیامد را در Columns بگذارید و شناسه را با Count خلاصه کنید. از Show Values As برای درصد سطر و ستون کمک بگیرید. در ع۵ پاسخ خالی واکسن را فیلتر کنید.
- ع۶. یک ستون با فرمول `=IF([@self_health]="","",IF([@self_health]>=4,1,0))` بسازید. در جدول توافقی محل و ستون تازه، پاسخ خالی را فیلتر کنید.
- ع۷. نسبت و تفاضل را با کسرهای اصلی حساب کنید. برای نسبت شانس، شمار سیگاری فعلی را بر شمار سایر افراد همان گروه تقسیم کنید و دو شانس را بر هم تقسیم کنید.

## خودآموز ع۵ | جدول را از CSV بسازید

۱. **Data → From Text/CSV** را باز کنید، ویرگول را جداکننده بگذارید و **Load** را بزنید. سطر اول عنوان است. روی یک خانهٔ جدول کلیک کنید و از **Insert → PivotTable → New Worksheet** کمک بگیرید.
۲. در PivotTable Fields، age_group را به Rows، flu_vacc را به Columns و id را به Values ببرید. اگر Values نوشته **Sum of id**، روی آن بزنید، **Value Field Settings → Count** را انتخاب کنید. عدد شناسه برای جمع‌زدن نیست.
۳. در فیلتر برچسب ستون، Blank را غیرفعال و yes و no را نگه دارید. ردیف کد ۳ برای گروه ۶۰ سال و بیشتر است. Count of id در yes باید ۲۴ و در no باید ۲۰ باشد.
۴. id را بار دوم به Values ببرید و **Show Values As → % of Row Total** را انتخاب کنید. در ستون yes و ردیف ۳، ۵۴٫۵٪ ببینید. برای درصد ستونی، id را بار سوم بگذارید و **% of Column Total** را بزنید. همان خانه اکنون ۴۴٫۴٪ دارد. عنوان دو ستون را جدا بنویسید.
۵. اگر جمع ستون yes برابر ۵۴ نیست، فیلترهای فعال و نحوهٔ شمارش id را بررسی کنید. برای ثبت روش و داده، کارپوشه را به صورت xlsx ذخیره کنید.
