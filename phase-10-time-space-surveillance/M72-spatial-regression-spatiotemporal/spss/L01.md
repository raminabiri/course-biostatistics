# SPSS | رگرسیون فضایی و پایش فضایی–زمانی

در File → New → Syntax اجرا کنید. متغیر #last متغیر موقت است و از یک ردیف به ردیف بعد نگه داشته می‌شود. ترتیب هفته‌ها در ورود ثابت است.
```spss
INPUT PROGRAM.
COMPUTE #last=10.
LOOP week=1 TO 4.
 DO IF week=1.
  COMPUTE requests=10.
 ELSE IF week=2.
  COMPUTE requests=12.
 ELSE IF week=3.
  COMPUTE requests=16.
 ELSE.
  COMPUTE requests=18.
 END IF.
 COMPUTE ewma=.25*requests+.75*#last.
 COMPUTE #last=ewma.
 COMPUTE signal=(ewma>13).
 END CASE.
END LOOP.
END FILE.
END INPUT PROGRAM.
LIST VARIABLES=week requests ewma signal.
```
نتیجهٔ signal فقط در هفتهٔ چهارم ۱ است.

**خروجی مرجع:** پیش‌بینی مکانی ۳، ۴ و ۵ است. سری هموار ۱۰، ۱۰٫۵، ۱۱٫۸۷۵ و ۱۳٫۴۰۶۲۵ است. عبور از مرز در هفتهٔ ۴ رخ می‌دهد.

محاسبهٔ مرجع با R و Python وارسی شده است. اجرای مستقیم این مسیر در نرم‌افزار در دسترس نبود.
