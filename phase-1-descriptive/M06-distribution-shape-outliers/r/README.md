| کار | R | نکته |

### تابع چولگی G1 (همان فرمول SPSS و Excel)

```r
G1 <- function(x) {
  n <- length(x); m <- mean(x)
  g1 <- mean((x - m)^3) / mean((x - m)^2)^1.5
  sqrt(n * (n - 1)) / (n - 2) * g1
}
```
فرمول را لازم نیست حفظ کنید؛ فقط بدانید چرا اعداد نرم‌افزارها کمی فرق دارد (درس ۶.۲).

```r
tukey <- function(x, type = 6) {
  q <- unname(quantile(x, c(.25, .75), type = type)); iqr <- q[2] - q[1]
  c(lower = q[1] - 1.5 * iqr, upper = q[2] + 1.5 * iqr)
}
f <- tukey(d$lactate); sort(d$lactate[d$lactate > f["upper"]])   # 5.5 6.5
f <- tukey(d$los);     sort(d$los[d$los > f["upper"]])           # 17 17 20 23 28 41
```
`unname()` لازم است؛ وگرنه نام «75%» به نتیجه می‌چسبد و `f["upper"]` پیدا نمی‌شود.

## خطاهای رایج

| مشکل | علت | راه‌حل |
|---|---|---|
| چارک‌ها با SPSS فرق دارد | type 7 پیش‌فرض | `type = 6` |
