# SPSS | درس عملی 1 — بردار میانگین

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

Data → Select Cases با a=0، سپس Descriptives برای میانگین‌ها و Correlate → Bivariate با Options برای کوواریانس را درخواست کنید. S را وارد فرمول درس یا اسکریپت R کنید. این P در خروجی Descriptives ارائه نمی‌شود.

**خروجی مرجع R و Python.** تک‌نمونه‌ای T²=4.846807، F=2.261843، P=0.140865.

**خودآزمایی.** اگر پاسخ دوم را از گرم به میلی‌گرم تبدیل کنیم؟
