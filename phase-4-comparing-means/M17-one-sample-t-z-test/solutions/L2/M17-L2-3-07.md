# حل M17-L2-3-07

۱. پراکندگی داده‌شده را بر جذر تعداد افراد تقسیم کنید. `SE = 7/√16 ≈ 1.7500` دقیقه. در این سؤال σ معلوم فرض شده است.
۲. اختلاف را بر SE تقسیم کنید. `z = 1.8/1.7500 ≈ 1.0286`. برای پرسش راست مساحت `P(Z ≥ 1.0286)` را بخوانید. مقدار P حدود **0.1518** است. برای محاسبه، SE را گرد نکنید.
۳. برای فاصلهٔ دوطرفهٔ ۹۵٪، صدک ۰٫۹۷۵ همان توزیع حدود 1.9600 است. حاصل ضرب در SE، نیمه‌عرض 3.4299 را می‌دهد. فاصلهٔ **اختلاف** `[-1.630, 5.230]` دقیقه است. برای تبدیل به بازهٔ میانگین، مقدار مرجع را به هر کران اضافه کنید.
