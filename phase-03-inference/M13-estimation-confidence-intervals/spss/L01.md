# SPSS | درس عملی 1 — فاصلهٔ میانگین

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

در Syntax بنویسید:

```spss
DATA LIST FREE / m s n.
BEGIN DATA
50 10 25
END DATA.
COMPUTE h=IDF.T(.975,n-1)*s/SQRT(n).
COMPUTE lo=m-h.
COMPUTE hi=m+h.
EXECUTE.
```
 هر خط را جدا وارد کنید و lo و hi را در Data View بخوانید.

**خروجی برای مقایسه.** فاصله حدود [۴۵٫۸۷، ۵۴٫۱۳] دقیقه.

**خودآزمایی.** اگر n چهار برابر شود اما SD همان ۱۰ باشد، SE چند می‌شود؟
