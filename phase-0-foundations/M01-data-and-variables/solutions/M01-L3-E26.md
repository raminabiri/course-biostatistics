# پاسخ M01-L3-E26

## پرسش

**سطح:** پیشرفته | **مخاطب:** متخصص و پژوهشگر؛ دانشجوی علاقه‌مند

برای تبدیل رفت‌وبرگشت پهن و بلند چه بررسی‌ای پیشنهاد می‌دهید؟

## پاسخ گام‌به‌گام

شمار شناسه، یکتایی کلید، نام روزها و برابری هر مقدار را بررسی کنید. پس از بازگشت، جدول مرتب‌شده باید با جدول آغازین برابر باشد؛ تنها برابری میانگین کافی نیست.
