# Python | توزیع بتا

در ترمینال از پوشهٔ ماژول اجرا کنید `python python/M64_L1.py`. فقط کتابخانهٔ استاندارد پایتون لازم است. `next` اولین ردیف داده را می‌گیرد. تابع `cdf` احتمال سمت چپ نقطهٔ x را با یک هم‌ارزی محاسبه می‌کند. وقتی هر دو پارامتر شکل بتا عدد صحیح مثبت‌اند، این احتمال برابر احتمال دست‌کم a موفقیت در `a+b−1` آزمون دوجمله‌ای با احتمال موفقیت x است. تابع `comb` شمار انتخاب‌های هر حالت را می‌دهد.

تابع `quantile` با بازهٔ صفر تا یک شروع می‌کند. اگر احتمال تجمعی در وسط بازه از هدف کمتر باشد، نیمهٔ بالایی را نگه می‌دارد. در غیر این صورت، نیمهٔ پایینی را نگه می‌دارد. پس از تکرار، وسط بازه تخمین صدک است. برای پارامترهای شکل غیرصحیح از تابع‌هایی مانند `scipy.stats.beta.ppf` استفاده کنید. خروجی این تمرین باید ۹، ۵، میانگین ۰٫۶۴۲۹ و حدود ۰٫۳۸۵۷ تا ۰٫۸۶۱۴ باشد.
