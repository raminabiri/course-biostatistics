# M01 — داده، متغیر و ساختار مجموعه‌داده

**مخاطب:** دانشجوی پزشکی، پیراپزشکی و علوم زیستی؛ متخصص و پژوهشگر  
**سطح:** مقدماتی، متوسط و پیشرفته  
**پیش‌نیاز:** ندارد  
**زمان پیشنهادی:** ۴ تا ۶ ساعت درس؛ ۸ تا ۱۶ ساعت تمرین؛ ۲ تا ۳ ساعت برای هر مسیر نرم‌افزاری

## پرسش راهنما

پیش از هر آزمون، باید بدانیم هر سطر دربارهٔ چیست، هر ستون چه معنایی دارد و چند واحد مستقل داریم. کد عددی بخش بیمارستان، عدد سنجیده‌شده نیست؛ سه نوبت از یک بیمار هم سه بیمار مستقل نیست. در این ماژول این تفاوت‌ها را روی دادهٔ ساختگی تمرین می‌کنید.

## دستاورد یادگیری

در پایان، باید بتوانید واحد اندازه‌گیری و تخصیص را از هم جدا کنید؛ نوع و مقیاس ستون را با دلیل بنویسید؛ فرهنگ داده بسازید؛ قالب پهن و بلند را تبدیل و کلید را کنترل کنید؛ گمشده را از صفر و زیر حد سنجش جدا کنید؛ و همین کارها را در مسیر نرم‌افزاری خود انجام دهید.
