## ورود داده

[CSV مشترک](../data/M34_practice.csv) را دریافت کنید. در VS Code پوشهٔ ماژول را باز کنید. در مفسر دوره، در صورت نیاز SciPy را با `python -m pip install scipy` نصب کنید. فایل M34_workshop.py را با Run Python File اجرا کنید. برای اجرای خط‌های زیر، دادهٔ `rows` و ابزار `stats` را از ابتدای همان فایل بگیرید.

## اجرا و دلیل هر گام

`counts=Counter(row["route"] for row in rows)` شمار هر نام را نگه می‌دارد. `stats.chisquare([counts[c] for c in "ABC"], f_exp=[50,30,20])` ترتیب دو بردار را یکسان می‌کند. در شیء خروجی statistic و pvalue به‌ترتیب آماره و P هستند.

## کنترل و تمرین

χ²≈۱۰٫۳۳۳، df=۲ و P≈۰٫۰۰۵۷۰۴. اگر عدد فرق کرد، نخست شمار سطرهای معتبر، ترتیب رده‌ها و جهت دنباله را کنترل کنید. نتیجه را در یک جمله برای سؤال درس بنویسید.
