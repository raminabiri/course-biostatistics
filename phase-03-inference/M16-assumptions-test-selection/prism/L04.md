# Prism | درس عملی 4 — نقشهٔ انتخاب آزمون

## آماده‌سازی

برای شروع از File → New Project استفاده کنید. در جدول XY، X محل نقطه و Y ورودی تبدیل است. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

در Column با دو گروه، از Analyze → t tests (and nonparametric tests) آزمون غیرزوجی دوطرفه را انتخاب کنید. گزینهٔ Welch برای واریانس‌های نامساوی را فعال کنید. اختلاف و P را کنار هم بخوانید.

**خروجی برای مقایسه.** Welch دوطرفه برای دو گروه مستقل دادهٔ تمرین، P≈۰٫۲۱۹.

**خودآزمایی.** اگر به جای عدد، پاسخ هر فرد بله یا خیر بود، آیا Welch همان انتخاب می‌ماند؟
