# R | درس عملی 3 — غربال و بررسی نقطهٔ دور

## آماده‌سازی

در RStudio از Session → Set Working Directory پوشهٔ ماژول را انتخاب کنید. فایل کد را باز کنید و Source را بزنید. خط‌های خروجی در Console دیده می‌شوند.

## اجرا و معنی نتیجه

در L3، فرمول G و آستانه مستقیماً از داده و qt حساب می‌شوند.

[فایل کد](../r/M16_workshop.R) را باز کنید. qt برای آستانهٔ Grubbs از df=n−2 کمک می‌گیرد.

**خروجی برای مقایسه.** G≈۲٫۷۴۶، آستانه≈۲٫۴۱۲.

**خودآزمایی.** اگر فایلی سه مقدار دور داشته باشد، می‌توان Grubbs را پی‌درپی اجرا و هر بار حذف کرد؟
