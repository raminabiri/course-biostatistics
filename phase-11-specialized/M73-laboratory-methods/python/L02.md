به Python 3.10 یا بالاتر نیاز دارید. `zip(rows,rows[1:])` هر ردیف را با ردیف بعدی جفت می‌کند. در `max` کلید lambda ستون غلظت را برای انتخاب قله مشخص می‌کند. `zip(*terminal)` دو ستون جدا برای برازش می‌سازد.

**خروجی مرجع:** AUC تا ساعت ۴ برابر ۱۴٫۵، Cmax برابر ۸، Tmax برابر ساعت ۱ و نیمه‌عمر انتهایی برابر یک ساعت.
