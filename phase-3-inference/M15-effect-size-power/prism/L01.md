# Prism | درس عملی 1 — اثر خام و استاندارد

## آماده‌سازی

برای شروع از File → New Project استفاده کنید. در جدول XY، X محل نقطه و Y ورودی تبدیل است. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

در XY، Y=4 بگذارید و با Analyze → Transform تبدیل `Y=Y/8` را اجرا کنید. برای g، روی دادهٔ اصلی `Y=Y/8*(1-3/(4*38-1))` را بزنید.

**خروجی برای مقایسه.** d=۰٫۵ و g≈۰٫۴۹۰.

**خودآزمایی.** اگر همان اختلاف در مقیاسی با SD برابر ۴ به دست آید، d چگونه عوض می‌شود؟
