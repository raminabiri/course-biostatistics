# Python از نخستین قدم — سه نفر و یک جدول کوچک

**سطح:** نخستین آشنایی · **مخاطب:** کسی که تا امروز کد ننوشته است

سن نفر دوم درمانگاه ۵۱ سال است. روی کاغذ به‌سادگی پیدایش می‌کنیم. در این صفحه می‌بینیم همین کار در Python چگونه انجام می‌شود. هر بار یک چیز کوچک به کارمان افزوده می‌شود: یک عدد، چند عدد، سپس یک جدول.

## نوشته را کجا می‌نویسیم و پاسخ را کجا می‌بینیم؟

Python زبان کار ماست. VS Code جایی برای نوشتن کد و دیدن نتیجه است. در VS Code، پوشه‌ای مانند `biostat-start` را با `File > Open Folder` باز می‌کنیم. یک فایل تازه با نام `first_table.py` در همان پوشه می‌سازیم؛ نوشتهٔ کد در این فایل می‌ماند.

<details>
<summary>اگر ابزارها هنوز آماده نیستند</summary>

خود [Python](https://www.python.org/downloads/) و سپس [VS Code](https://code.visualstudio.com/) نصب می‌شوند. در VS Code، بخش Extensions جای نصب افزونهٔ **Python از Microsoft** است. فرمان `Python: Select Interpreter` در پنجرهٔ Ctrl+Shift+P، Python نصب‌شده را برمی‌گزیند. این انتخاب مشخص می‌کند کدام Python نوشتهٔ ما را اجرا خواهد کرد. روش نصب Python در لینوکس با توزیع آن همخوان است؛ در ویندوز، گزینهٔ افزودن به PATH در نصب‌کننده‌های دارای این گزینه کمک‌کننده است.

</details>

دکمهٔ مثلثی `Run Python File` فایل را اجرا می‌کند و پاسخ در بخش پایین صفحه، **Terminal**، دیده می‌شود. ما کد را داخل فایل py می‌نویسیم؛ نتیجه را پایین صفحه می‌خوانیم. برای آغاز، همان یک فایل کافی است.

## یک عدد را ببینیم

اولین نوشتهٔ ما فقط این است:

```python
print(24)  # نمایش سن نفر نخست
```

با اجرای فایل، عدد `24` پایین صفحه دیده می‌شود. `print` کاری را انجام می‌دهد که نامش پیشنهاد می‌کند: مقدار را در خروجی نشان می‌دهد. پرانتز، چیزی را که می‌خواهیم ببینیم در بر گرفته است.

اکنون به‌جای تکرار عدد، نامی به آن می‌دهیم. این دو خط را می‌توان به جای خط نخست نوشت:

```python
age = 24    # نگه‌داشتن سن با نام age
print(age)  # دیدن مقدار این نام
```

پاسخ باز هم ۲۴ است. علامت `=` در اینجا یعنی «این مقدار را با این نام نگه دار». نام age را خودمان برگزیده‌ایم؛ واژهٔ اجباری Python نیست. از این پس هر جا age بنویسیم، Python مقدار نگه‌داشته‌شده را پیدا می‌کند.

## سه سن را کنار هم بگذاریم

افراد ما ۲۴،۵۱ و ۳۸ ساله‌اند. Python می‌تواند چند مقدار را در یک **فهرست** نگه دارد:

```python
ages = [24, 51, 38]  # فهرست سن سه نفر
print(ages)         # دیدن فهرست
```

در خروجی `[24, 51, 38]` دیده می‌شود. کروشه‌ها مرز فهرست‌اند و ویرگول‌ها سه مقدار را جدا کرده‌اند. ترتیب همان ترتیب افراد است.

**یک درنگ کوتاه:** می‌خواهیم تنها سن نفر دوم دیده شود. Python خانه‌های فهرست را از صفر می‌شمارد؛ خانهٔ نخست شمارهٔ ۰ و خانهٔ دوم شمارهٔ ۱ دارد:

```python
print(ages[1])  # سن دوم فهرست
```

پاسخ ۵۱ است. عدد ۱ در کروشه، شمارهٔ جایگاه در فهرست است؛ به شمارهٔ شناسایی فرد اشاره نمی‌کند. این تفاوت در شروع کمی ناآشناست، اما با همین نمونهٔ کوچک روشن می‌شود.

## برای جدول، ابزار pandas به کمکمان می‌آید

فهرست برای چند سن کافی بود. اکنون می‌خواهیم سن و دما کنار شمارهٔ هر نفر بنشینند. **pandas** مجموعه‌ای از ابزارهای کار با جدول است؛ **DataFrame** نام جدول در آن است. پیش از ساخت جدول، این ابزار را آماده می‌کنیم.

<details>
<summary>اگر pandas هنوز نصب نیست</summary>

در VS Code فرمان `Python: Create Terminal` یک Terminal برای Python برگزیده باز می‌کند. این فرمان نصب در همان Terminal نوشته می‌شود، نه داخل فایل py:

```bash
python -m pip install pandas
```

در محیطی که نام برنامه python3 است، همان نام جای python می‌نشیند. اگر محیط سیستم اجازهٔ نصب مستقیم بسته نمی‌دهد، فرمان `Python: Create Environment` و گزینهٔ Venv در VS Code محیطی برای همین پوشه می‌سازند. پس از گزینش آن محیط و بازکردن Terminal تازه، نصب در همان محیط انجام می‌شود. بسته باید در همان Python نصب شود که فایل ما را اجرا می‌کند.

</details>

این خط در **فایل py** نوشته می‌شود:

```python
import pandas as pd  # آماده‌کردن ابزار جدول
```

`pd` نام کوتاهی است که از این پس برای pandas می‌نویسیم. اکنون یک جدول با تنها یک ستون، شمارهٔ افراد، می‌سازیم:

```python
patients = pd.DataFrame({"patient_id": [1, 2, 3]})  # جدول شمارهٔ افراد
```

در این نوشته، `patient_id` نام ستون و `[1, 2, 3]` مقدارهای آن است. دو نقطه این نام و مقدارها را به هم پیوند داده است. patients هم نام خود جدول است. هنوز لازم نیست همهٔ شکل‌های ساخت جدول را یاد بگیریم؛ اینجا فقط یک ستون ساخته‌ایم.

سه سن از پیش در ages هستند. حالا آن‌ها را به ستون سن جدول می‌سپاریم:

```python
patients["age"] = ages  # افزودن ستون سن
print(patients)        # دیدن جدول دو ستونی
```

عبارت `patients["age"]` یعنی «ستون age از جدول patients». گیومه‌ها نشان می‌دهند age در اینجا نام نوشته‌شدهٔ یک ستون است. سن‌ها به همان ترتیب کنار شمارهٔ افراد می‌نشینند.

دمای بدن هم به همین شکل افزوده می‌شود:

```python
patients["temperature"] = [36.8, 37.2, 38.1]  # افزودن دمای بدن
print(patients)                            # دیدن جدول کامل
```

اکنون انتظار داریم این سه سطر دیده شوند:

```text
   patient_id  age  temperature
0           1   24         36.8
1           2   51         37.2
2           3   38         38.1
```

شماره‌های ۰،۱،۲ در سمت چپ، شمارهٔ سطرهای جدول‌اند؛ ستون patient_id شمارهٔ افراد را نگه داشته است. سن ۵۱ کنار فرد شمارهٔ ۲ نشسته، هرچند شمارهٔ سطر او ۱ است. این همان تفاوتی است که در فهرست دیدیم.

## کارمان چگونه برای فردا می‌ماند؟

با ذخیرهٔ `first_table.py`، نوشتهٔ فرمان‌ها نگه داشته می‌شود. اجرای دوبارهٔ این نوشته، جدول را دوباره می‌سازد. با این کار روش ساخت داده هم همراه ما می‌ماند.

<details>
<summary>یک گام بیشتر: ذخیره و بازخوانی خود جدول</summary>

جدول را می‌توان در فایل CSV هم نگه داشت:

```python
patients.to_csv("my_first_table.csv", index=False)  # نوشتن جدول در فایل
```

`index=False` یعنی شماره‌های سطر ۰،۱،۲ به ستون تازهٔ فایل تبدیل نشوند؛ شناسهٔ افراد را از پیش داریم. فایل در پوشهٔ کاری Python نوشته می‌شود. برای دیدن نشانی آن پوشه:

```python
from pathlib import Path  # ابزار نشانی پوشه
print(Path.cwd())         # پوشه‌ای که فایل در آن نوشته شد
```

همان فایل را دوباره می‌خوانیم:

```python
again = pd.read_csv("my_first_table.csv")  # خواندن جدول ذخیره‌شده
print(again)                             # دیدن نتیجهٔ بازخوانی
```

`read_csv` به معنی خواندن فایل CSV است. نام again یادآوری می‌کند این جدول را دوباره از فایل خوانده‌ایم. سه سطر و سه ستون باید همان‌هایی باشند که ساختیم.

</details>

## اگر پاسخ مورد انتظار را ندیدیم

پیام `NameError` بیشتر وقت‌ها به نامی اشاره می‌کند که هنوز ساخته نشده یا جور دیگری نوشته شده است. برای نمونه، Ages و ages دو نام جدا هستند. پیام `ModuleNotFoundError: pandas` می‌گوید ابزار جدول در Python برگزیده پیدا نشده؛ به بخش آماده‌کردن pandas برمی‌گردیم. این پیام‌ها به شناخت چند نشانه و نام مربوط‌اند؛ قرار نیست آن‌ها را از بر بدانیم.

تا همین‌جا، یک فهرست را خوانده‌ایم و از آن به یک جدول رسیده‌ایم. دانستن همین اندازه برای ورود به درس نخست کافی است.
