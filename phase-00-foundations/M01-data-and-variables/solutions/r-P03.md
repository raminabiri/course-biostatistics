```r
mean(uti$crp)  # به‌دست‌آوردن میانگین
uti$crp[uti$crp == -99] <- NA  # نگه‌داشتن مقدار با یک نام
sum(!is.na(uti$crp))  # شناخت خانه‌های گمشده
round(mean(uti$crp, na.rm = TRUE), 2)  # به‌دست‌آوردن میانگین
sum(is.na(uti$wbc))  # شناخت خانه‌های گمشده
```
```
[1] 35.1
[1] 28
[1] 44.68
[1] 1
```

- `is.na()` برای هر مقدار TRUE/FALSE می‌دهد؛ `!` آن را برعکس می‌کند؛ `sum()` تعداد TRUE ها را می‌شمارد.
- **جواب:** میانگین از **35.10** (غلط) به **44.68** (درست) رسید. CRP **۲۸** و WBC **۲۹** مقدار معتبر دارند (۳۰ − ۱).
