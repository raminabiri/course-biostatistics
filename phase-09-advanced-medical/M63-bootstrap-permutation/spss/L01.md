# SPSS | توزیع دقیق بازنمونه‌ها

از File، New، Syntax پنجرهٔ دستور را باز و متن زیر را اجرا کنید. سه حلقه همهٔ سه‌تایی‌های مرتب را می‌سازند. END CASE هر سه‌تایی را یک ردیف می‌کند. واریانس کامل توزیع از میانگین مربع فاصله‌ها از ۴ محاسبه می‌شود.

```spss
INPUT PROGRAM.
LOOP #i=1 TO 3.
 LOOP #j=1 TO 3.
  LOOP #k=1 TO 3.
   COMPUTE avg=2*(#i+#j+#k)/3.
   COMPUTE squared=(avg-4)**2.
   END CASE.
  END LOOP.
 END LOOP.
END LOOP.
END FILE.
END INPUT PROGRAM.
AGGREGATE OUTFILE=* /BREAK= /grand=MEAN(avg) /v=MEAN(squared) /n=N(avg).
COMPUTE se=SQRT(v).
LIST VARIABLES=n grand se.
```

در Output باید ۲۷، ۴ و حدود ۰٫۹۴۳ را ببینید. فایل ورودی را قبل از اجرای یک برنامهٔ تولید داده ذخیره کنید.
