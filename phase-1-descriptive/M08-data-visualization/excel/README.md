# رسم در Excel

CSV را وارد کنید. ستون day0 را برای Histogram و ستون‌های جداگانهٔ day0 در A و B را برای Box & Whisker به کار ببرید. برای نمودار پراکنش، age و day0 را به ترتیب X و Y بگذارید. برای نمودار زمانی، هر فرد را یک Series بگیرید و خانهٔ خالی را به شکل شکاف نمایش دهید. جدول ۱ را با AVERAGE و STDEV.S برای هر گروه بسازید. برای ویولن از خروجی R یا Python کمک بگیرید.

## مسیر گام‌به‌گام Excel

برای واردکردن CSV، ساخت شکل، کنترل عددها و ذخیرهٔ خروجی، بخش همین نرم‌افزار را در [کارگاه M08](../software-workshop.md) باز کنید. نخست جدول فراوانی درس ۸٫۱ و شمار کل ۱۶ را کنترل کنید. بعد یک فرد را در نمودار پراکنش و در مسیر زمانی با شناسه‌اش پیدا کنید.
