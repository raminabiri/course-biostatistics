# Excel | درس عملی 2 — واریانس و مرکز گروه

## آماده‌سازی

کارپوشهٔ تازه را باز کنید. فرمول‌ها با = شروع می‌شوند و با Enter اجرا می‌شوند. نتیجه را در خانهٔ همان فرمول بخوانید.

## اجرا و معنی نتیجه

در برگهٔ داده، در E2 بنویسید `=ABS(A2-MEDIAN($A$2:$A$13))` و در F2 همین فرمول را با B2 و محدودهٔ B وارد کنید. تا سطر ۱۳ بکشید. در Data → Data Analysis، گزینهٔ ANOVA: Single Factor را روی E2:F13 با Grouped by Columns اجرا کنید. اگر Data Analysis نیست در File → Options → Add-ins، Analysis ToolPak را فعال کنید.

### آزمون را از فاصلهٔ هر فرد تا میانه بازسازی کنید

[دادهٔ پهن](../data/M16_groups.csv) برای هر گروه ۱۲ مقدار دارد. میانه‌ها در A و B برابر ۵۳ و ۵۰ هستند. نخستین انحراف مطلق A برابر |۴۸−۵۳|=۵ و نخستین انحراف B برابر |۴۳−۵۰|=۷ است. میانگین انحراف‌ها به‌ترتیب ۳٫۱۶۷ و ۴٫۹۱۷ است. ANOVA تک‌عاملی روی همین انحراف‌ها F≈۱٫۲۸۵ و P≈۰٫۲۶۹ می‌دهد.

CSV را با سرستون در A و B وارد کنید. C2 را `=ABS(A2-MEDIAN($A$2:$A$13))` و D2 را `=ABS(B2-MEDIAN($B$2:$B$13))` بگذارید و هر دو را تا سطر ۱۳ بکشید. از Data → Data Analysis → ANOVA: Single Factor برای C و D کمک بگیرید و گروه‌بندی Columns را بزنید.

**خروجی برای مقایسه.** Brown–Forsythe حدود F=۱٫۲۸۵ و P=۰٫۲۶۹.

**خودآزمایی.** اگر P بزرگ شد، آیا می‌توان برابری واریانس را قطعی دانست؟
