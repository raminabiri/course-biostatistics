# M03 در Python

از پوشهٔ ماژول اجرا کنید `python3 python/M03_module.py`. هر سطر به شکل دیکشنری با نام ستون خوانده می‌شود. `sort_key` برای هر سطر یک جفت عدد می‌سازد. `sorted(..., key=sort_key)` نخست بر u و هنگام تساوی بر id مرتب می‌کند. `[:10]` ده ردیف نخست را نگه می‌دارد. تبدیل float مهم است تا عددها به شکل متن مرتب نشوند. در خروجی ۰٫۲۷۵، ۰٫۴ و ۱۲٫۵ و ترتیب دو بازو را کنترل کنید.
