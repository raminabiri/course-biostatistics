# M01 — نخستین گام با داده‌های پزشکی و زیستی

**[شروع از صفر ←](START.md)**

اگر آمار یا کدنویسی نمی‌دانید، از همین پیوند آغاز کنید. تنها یکی از پنج نرم‌افزار را دنبال کنید؛ خواندن همهٔ مسیرها لازم نیست.

## مسیر این ماژول

۱. ساخت جدول سه‌نفری در نرم‌افزار خود  
۲. درس ۱: داده، سطر و ستون  
۳. درس ۲: نوع داده و مقیاس  
۴. درس ۳: چیدن جدول و نوبت‌های پیگیری  
۵. درس ۴: خانهٔ خالی و خطای سنجش  
۶. مرور آموخته‌ها

در پایان هر درس، تمرین، خواندنی و فیلم هم‌سطح همان درس آمده است. برای رفتن میان درس‌ها تنها «درس پیش» و «درس بعد» را دنبال کنید.

تازه‌کارها بار نخست بخش مقدماتی و پنج تمرین نخست هر درس را انجام دهند. بخش متوسط و پیشرفته برای بازگشت بعدی است. هر پاسخ در صفحهٔ جدا باز می‌شود و راه بازگشت به همان پرسش دارد.

همهٔ داده‌ها ساختگی‌اند. راهنماهای SPSS، Excel و Prism هنوز به بررسی روی نرم‌افزار نصب‌شدهٔ نویسنده نیاز دارند.
