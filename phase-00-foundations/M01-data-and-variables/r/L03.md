# R | درس عملی 3 — فرد و نوبت در جدول پهن و بلند

پیش از اجرا، جدول نمونهٔ درس مفهومی را یک بار با دست بخوانید. [راهنمای شروع این نرم‌افزار](START.md) · [درس مفهومی](../lessons/L3-dataset-structure.md) · [درس عملی پیش](L02.md) · [درس عملی بعد](L04.md)

جدول کوچک همین درس را wide می‌نامیم. دو ستون دما داریم؛ یکی برای روز صفر و دیگری برای روز سه:

```r
wide <- data.frame(
  patient_id = c(1, 2, 3),
  temp_d0 = c(36.8, 37.2, 38.1),
  temp_d3 = c(36.7, 37.0, 37.6))  # جدول پهن سه‌نفری
```

reshape نام ابزار جابه‌جایی چیدمان در R پایه است. در این فرمان، نام فرد، ستون‌های دما و روز واقعی هر ستون را به آن می‌گوییم:

```r
long <- reshape(wide, direction = "long",
                varying = c("temp_d0", "temp_d3"),
                v.names = "temperature", timevar = "day",
                times = c(0, 3), idvar = "patient_id")  # پهن به بلند
nrow(long)  # شمار سطرهای تازه
```

پاسخ ۶ است. varying دو ستون جابه‌جاشونده را نام می‌برد، times روزهای واقعی را می‌دهد و idvar شناسه را نگه می‌دارد. همهٔ این گزینه‌ها پاسخ همان پرسش‌اند: هر مقدار از کدام فرد و کدام روز آمده است؟

**فیلم اجرای همین گام — متوسط؛ دیدن ساختار جدول:** [Statistics Globe — Reshape Data Frame from Wide to Long Format](https://www.youtube.com/watch?v=eLCKL7BNIAk)

**دامنهٔ دیدن:** فقط جدول آغازین و جدول بلندِ نمونهٔ نخست را برای شناخت جابه‌جایی سطر و ستون ببینید. کد فیلم از melt و بستهٔ افزوده کمک می‌گیرد؛ کد این درس با reshape در R پایه است. برای تمرین، همان کد درس را اجرا کنید؛ نصب بسته و نمونهٔ gather لازم نیست.
