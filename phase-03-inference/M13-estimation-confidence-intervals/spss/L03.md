# SPSS | درس عملی 3 — تفاضل و جهت

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

روی یک ردیف فعال، به‌ترتیب df را با `7.2**2/(4**2/24+3.2**2/19)` و h را با `IDF.T(.975,df)*SQRT(7.2)` بسازید. با دو Compute دیگر ۴ منهای h و ۴ به‌علاوهٔ h را ذخیره کنید.

**خروجی برای مقایسه.** فاصلهٔ Welch حدود [−۱٫۴۱، ۹٫۴۱] دقیقه.
