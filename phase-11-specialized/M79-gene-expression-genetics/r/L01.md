# R | بیان تفاضلی، آزمون‌های چندگانه و ژنتیک جمعیت

ترمینال را در پوشهٔ ماژول باز کنید و دستور زیر را اجرا کنید. فایل داده باید در پوشهٔ data بماند.

```bash
Rscript --vanilla r/M79_L1.R
```

`p.adjust` تعدیل را اجرا می‌کند و ترتیب اصلی داده را نگه می‌دارد. `c` سه شمار مورد انتظار را به شکل بردار کنار هم می‌گذارد.
