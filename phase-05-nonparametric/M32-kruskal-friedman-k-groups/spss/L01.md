# SPSS | درس عملی 1 — رتبه‌بندی کلی گروه‌ها

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین practice.csv](../data/practice.csv)

Nonparametric Tests → Independent Samples را باز کنید. value را متغیر و group را گروه‌بندی بگذارید. در Settings روش Kruskal–Wallis و در صورت وجود مقایسهٔ جفتی را انتخاب کنید. نام روش تعدیل SPSS را ثبت کنید.

**خروجی مرجع R و Python.** H≈۴٫۵۲۶۳۱۶ و P≈۰٫۱۰۴۰۲۱.

**خودآزمایی.** آیا از نتیجهٔ کلی می‌توان فهمید کدام جفت متفاوت است؟
