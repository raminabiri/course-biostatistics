# SPSS | درس عملی 3 — فرض جهت‌دار و گزارش فاصله

## آماده‌سازی

SPSS را در یک جلسهٔ تازه باز کنید. متغیرها در Variable View تعریف و مقدارها در Data View نوشته می‌شوند. برای کد از File → New → Syntax و سپس Run → All کمک بگیرید.

## اجرا و معنی نتیجه

[دادهٔ تمرین values.csv](../data/values.csv)

[دادهٔ تمرین long.csv](../data/long.csv)

در خروجی Welch اختلاف A−B را از Mean Difference و بازه را از Lower و Upper بخوانید. برای جهت از P یک‌طرفهٔ متناظر استفاده کنید.

**خروجی مرجع R و Python.** Welch: P راست=0.049610 و CI [−0.834001, 8.584001].

**خودآزمایی.** اگر جهت از پیش A>B بوده ولی t منفی شود، آیا نصف P دوطرفه پاسخ است؟
