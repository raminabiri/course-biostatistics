# R | درس 1 — از دادهٔ خام تا جدول چهارخانه

## فایل را پیدا و اولین جدول را بسازید

در RStudio پوشهٔ M09 را با **Session → Set Working Directory → Choose Directory** انتخاب کنید. در Console، `file.exists("data/M09_individuals.csv")` باید TRUE دهد. خطوط زیر را به‌ترتیب در Console بزنید:

```r
d <- read.csv("data/M09_individuals.csv")
nrow(d)
base <- subset(d, population == "baseline")
tab <- with(base, table(reference, test))
tab
```

`<-` نامی برای نگه‌داشتن نتیجه می‌سازد. `subset` فقط سطرهای واجد شرط را برمی‌دارد، و `==` برابری را می‌سنجد. `with(base,...)` می‌گوید نام ستون‌ها را از base بخوان. `table(reference,test)` معیار مرجع را در سطر و آزمون را در ستون قرار می‌دهد. nrow(d) باید ۱۱٬۰۰۰ و sum(tab) برابر ۱۰۰۰ باشد.

در `tab["negative","negative"]` ابتدا نام سطر و سپس نام ستون را می‌دهیم. این خانه ۸۱۰ است. با `1-tab["negative","negative"]/sum(tab)` احتمال اجتماع ۰٫۱۹ را به دست آورید. R ممکن است برچسب منفی را اول چاپ کند. با برچسب خانه را انتخاب کنید، نه با تصور جای ثابت.
