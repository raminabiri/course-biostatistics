# Prism | درس عملی 3 — غربال و بررسی نقطهٔ دور

## آماده‌سازی

برای شروع از File → New Project استفاده کنید. در جدول XY، X محل نقطه و Y ورودی تبدیل است. پس از اجرا از نوار کناری به Results بروید.

## اجرا و معنی نتیجه

در Column، Analyze → Identify outliers را بزنید. Grubbs را با α=۰٫۰۵ برای A اجرا کنید. برای مقایسه، روی همان داده تحلیل جدا با ROUT و Q=۱٪ انجام دهید. جدول پرت‌ها و دادهٔ اصلی را نگه دارید. خروجی دو روش را جدا تفسیر کنید.

**خروجی برای مقایسه.** G≈۲٫۷۴۶، آستانه≈۲٫۴۱۲.

**خودآزمایی.** اگر فایلی سه مقدار دور داشته باشد، می‌توان Grubbs را پی‌درپی اجرا و هر بار حذف کرد؟

<details>
<summary>حل تشریحی</summary>
