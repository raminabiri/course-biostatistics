# spss | آلفا و تحلیل گویه

## اجرا

[فایل تمرین](../data/M44_scale.csv) را باز کنید. هر سطر یک فرد است. [کدبوک](../data/README.md) را برای جهت گویه و بازهٔ کدها ببینید. کدهای R و Python با نام M44_workshop از پوشهٔ ماژول اجرا می‌شوند.

در Transform → Compute، `i4=6-i4_reverse` را بسازید. از Analyze → Scale → Reliability Analysis پنج گویهٔ هم‌جهت را انتخاب و Model=Alpha را بزنید. در Statistics، Item، Scale و Scale if item deleted را مشخص کنید. Corrected Item-Total Correlation گویهٔ ۴ را کنترل کنید.
